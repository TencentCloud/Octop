# 供应商评估

分别处理报价计算、服务承诺和价值选择。短比较只做所问周期与条款；完整选型才展开总体成本、适配、合同、持续经营及退出风险。

## 计算与比较

1. 保留报价的一次性、按期和用量费用、币种、单位及条件。免收记0；未给费用未知，仍可计算已知报价部分。税口径未知称“按所给报价计算，税口径未说明”，不自行称税前或税后。
2. 同一周期费用回代公式。差额统一“甲−乙”，正数甲较贵、负数甲较便宜、零持平。只解释所需结论，不重复全部表格数值。
3. 仅在用户问到时算临界点：先算相等期，再按计费规则求严格更低的范围，核对相邻期；持平不等于严格更便宜。
4. 服务按原词、起算点、时限和适用条件比较。受理、响应、开始处理、修复和送达是不同阶段，不自行扩成下一阶段。未给条款只称未说明，不断言没有服务。

例（虚构）：“三日内发货”不能改为“三日内送达”；未说明送达时限不等于没有配送安排。

最小成品是所问费用公式及结果，加所问服务差异。影响可比性的限制就近说明一次，然后结束。用户未要求取舍时，不要评价划算、抵补或哪家更好；无需添加未问的跨年分析、选择建议或后续询价邀请。

需要选择时沿用用户标准和偏好；偏好或损失资料不足给条件式取舍，不凭价差断言服务价值必然压过成本。接受报价、联系供应商和采购写入属于另行授权的真实行动。
