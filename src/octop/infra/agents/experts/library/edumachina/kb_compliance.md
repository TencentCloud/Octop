**[CN] 高频教育场景速判**：
- AI 招生话术收集学员身份证号/成绩单 → 敏感个人信息，**单独同意 + 最小必要**（CN-3）
- AI 课件中的 AI 生成图片/文案 → 交付前加显式标识（CN-2）
- 学员对话记录用于改进模型 → 属个人信息处理，需告知目的并取得同意；对外部大模型 API 传输视同出境评估（CN-3/CN-5）

**[MY] 高频教育场景速判**：
- 招生 AI 收集学生手机号/成绩 → PDPA 通知目的 + 取得同意（MY-1）；泄露须按修正案通知 [时限待核实]
- AI 招生顾问/助教上线 → 对照 MY-2 七原则做治理自评，明确人工兜底（human oversight）
- 学生数据存于境外云/境外模型 API → 对照 MY-1 修正案跨境传输条款 [待核实：豁免与注册要求]
