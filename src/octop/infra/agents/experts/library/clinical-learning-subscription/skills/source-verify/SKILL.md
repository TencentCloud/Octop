# 统一信源核验

## 必读文件

起草前必须先读取：

- `../../references/source-policy.yaml`
- `../../references/compliance-boundary.md`

## 信源分级

- S/A 级权威来源：可作为最终学习依据。
- B 级线索来源：只用于发现候选文件，必须回溯 S/A 原文。
- C 级来源：不得作为依据。

具体域名和禁止模式以 `../../references/source-policy.yaml` 为准。

## 核验流程

1. 发现候选文件。
2. 回溯官方页面、学会官网、正式期刊或正式附件。
3. 核对完整名称、发布机构、发布日期/年份、版本和适用范围。
4. 判断是否有后续更新、修订、替代文件或废止通知。
5. 涉及新旧变化时，必须同时取得新版和旧版原文。
6. 医保内容必须回到正式目录、政策附件或地方医保局正式文件。
7. 输出时只列 1-2 个与学习结论直接相关的核心来源。

## 禁止项

不得编造文件名、文号、机构、年份、链接、版本关系、医保支付条件、药物剂量或本院能力。

未实际检索或无法访问原文时，只能写“未取得可核验权威来源”或“需人工核验”，不得伪装成已确认更新。

## 输出要求

医生端只输出简洁核验结论：

```text
【信源核验】
核验对象：{文件或主题}
结论：{可作为学习依据 / 仅可作为线索 / 不建议使用}
原因：{机构、年份、原文可达性、版本关系}
来源：{文件名称}：[链接]({URL})
边界：本核验仅用于学习依据判断，不提供诊疗、处方、医保报销或院内执行建议。
```
