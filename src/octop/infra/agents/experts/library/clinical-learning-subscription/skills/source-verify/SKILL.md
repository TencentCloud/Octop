# 统一信源核验

## 路由边界

纯粹判断文件是否为权威原文、是否最新有效以及修订/替代/废止关系时，只使用本技能及下方【信源核验】模板，不再调用 `output-format` skill 或 `../../scripts/validate_output.py`。如果用户还要求生成指南学习内容，先完成信源核验，再把已核验来源交给对应医学学习 skill，并只对学习内容执行 `output-format` 校验。

## 必读文件

起草前必须先读取：

- `../../references/source-policy.yaml`
- `../../references/compliance-boundary.md`
- `../../references/verified-source-entrypoints.yaml`

以上是确定路径，直接读取；不得为定位这些文件调用 `glob`、`grep` 或递归 `ls`。

## 已核验入口的使用顺序

1. 先用用户主题匹配 `verified-source-entrypoints.yaml` 的 `aliases`。未命中才进入常规联网检索。
2. 命中时直接 `web_fetch` 该条目的 `canonical_url`，核对页面标题和 DOI；两者任一不符即不得使用。
3. 当前日期超过 `recheck_after`，或用户明确询问「最新/现行/替代」时，再加 1 次限定官方域名的时效检索；没有新版正式原文证据时，不得仅凭搜索摘要改写表内版本状态。
4. `version_relation` 是已核验的表述边界。它写「未取得废止/替代声明」时，必须如实输出「未证实正式废止或替代」，不得自行推断。
5. 命中条目的最终原文链接必须使用该条目的 `canonical_url`；`official_index_url` 只用于辅助核对卷期/DOI，不得取代原文链接。全文受订阅限制时可以说明可核对范围受限，但仍要给出 `canonical_url`。

## 信源分级

- S/A 原始来源：主管部门、制定机构、正式学会或正式期刊发布的规范性原文；通过文档类型与版本核验后，可作为最终学习依据。
- B+ 可信二级全文承载：医脉通、丁香园。只有原始来源访问受限，且具体页面是经文档身份核验的完整正式指南/共识全文时，才可作为最终正文承载来源。
- B 正规学术全文承载：CNKI、万方、维普。只有实际取得正式期刊发表的指南/共识全文并完成同等核验时，才可作为最终正文承载来源；题录或摘要不够。
- B- 题录核验：SinoMed。只用于确认名称、制定机构、期刊、年份、卷期、版本历史和定位正式全文，不直接支持具体推荐。
- C 发现来源：MedSci、指南注册平台等。只用于发现和新版预警，不得作为最终依据；注册方案不等于正式发布指南。
- D 禁止来源：不得进入证据链。

具体域名和禁止模式以 `../../references/source-policy.yaml` 为准。

## 两个独立决策：选文档，再选承载位置

不得把文档权威性与下载服务器混为一谈。先决定学习哪一份正式文件，再决定从哪里读取同一文件。

原始页面或附件出现 `401`、`403`、`412`、`429`、验证码、付费墙、超时、迁移、空壳页面或正文/PDF 不完整时，读取 `../medical-source-failover/SKILL.md`，并按其中要求读取国内信源登记、熔断和文献身份核验文件。该技能只负责寻找同一目标文献的可信访问路径，不改变本技能对文档类型、版本和最终证据资格的判断。若两套规则的要求不同，采用更严格的一项；只能取得 L5 元数据、摘要、解读、截图或不完整正文时，必须停止精确提取。

### 文档选择（China-first）

面向中国大陆医生，默认顺序是：

1. 国内最新版正式指南；
2. 国内最新版正式专家共识；
3. 国内正式诊疗规范、标准、路径或质控文件；
4. 国内正式政府/监管规范性文件；
5. 国际 S/A 正式指南或共识。

国内同主题存在多份文件时，依次优先国家主管部门或国家级学会/专业委员会、全国性专业组织、国家级质控或协作组织、省级/区域性组织、医院级或地方建议。

正式指南通常优先于正式专家共识。但旧指南未覆盖的新问题、最新共识明确补充或更新旧指南时，可以使用最新共识；必须标明“专家共识”、年份及它与旧指南的关系，不得称为指南。

国内与国际文件冲突时，以国内现行正式文件作为中国大陆学习主依据；国际文件仅补充更新和差异，并明确两者的版本、适用人群、药物可及性或监管环境差异。不得静默用国际推荐覆盖国内文件。WHO、NICE、ACG、AGA、ASGE、ESGE、EASL、AASLD、ECCO、ESC 的官方域名只对其正式 Guideline、Clinical Practice Guideline、Consensus、Position Statement、Official Recommendation 或 Official Standard 生效，站内新闻、患者教育、博客、会议报道、Webinar、访谈或摘要仍不合格。

### 正文承载选择

对已经选定的同一正式文件，按以下顺序读取：

1. L0：S/A 原始文档；
2. L1-L3：同一发布方的备用端点、官方完整转载或 DOI 绑定的正式期刊版本；
3. 原始路径明确受限且 L1-L3 均不可用时，降级到 B+ 的同文献完整副本；
4. B+ 不可用时，降级到 B 正规学术数据库中的同文献完整全文；
5. B-/C 只能继续核对和定位，不能补写医学内容。

不绕过反自动化机制；同一主机对同一文献最多直接尝试 2 次，遇到 `401`、`403`、`412`、`429`、验证码或明确访问控制时只尝试 1 次并立即熔断。不得从首页逐层翻页，优先用完整标题、DOI 或文号直接定位。

## B+/B 文档身份硬门槛

B+/B 不是域名整体升级。具体副本必须达到 `medical-source-failover` 的 Exact 或 Strong 身份核验，并同时核验：

- 文档标题；
- 文档类型确为正式指南或正式专家共识；
- 制定机构；
- 年份/版本；
- 正式出处（DOI、文号、正式期刊及卷期中可取得者）；
- 页面是否为完整全文，而不是摘要、摘编或局部预览；
- 是否已有新版、替代或废止信息。

允许有可核验授权关系且与正式出版物一致的完整转载全文；仅由承载平台自称“指南/共识”、无法独立确认身份或只取得题录/摘要时，降为线索并标“需人工核验”。

## 文档类型硬门槛

权威网站不等于该网站的每个页面都是权威依据。域名合格后，还必须判断文档类型。

- 最终依据只接受正式指南/共识、规范/临床路径/质控标准、正式政策或监管文件及附件。正式期刊发表的指南/共识可以按其规范性文档类型纳入，但不能因“发表在期刊”自动成为最终依据。
- 系统综述、Meta 分析、叙述性综述、范围综述、伞状综述、快速综述、专家综述和其他文献综述，不得出现在最终“来源”、下一阶段指南候选或正式学习轨道来源中；最多用于内部发现正式指南，并继续回溯规范性原文。
- 随机对照试验、观察性研究、病例报告/系列、述评/来信、会议摘要和预印本等研究或学术讨论，也不得替代本产品所要求的规范性原文。
- 科普、未核验转载/摘编、指南/共识解读、编辑摘要、新闻、访谈/媒体报道、病例讨论、患者教育、博客/Webinar、会议/培训/活动报道、营销或机构宣传，即使在可用域名也不得作为最终依据。
- 新闻、访谈或政策解读页若链接正式原文，该页只作发现线索，必须继续回溯并引用正式原文或附件。
- 不得仅凭标题关键词判断；例如正式《健康体检管理办法》不应因含“体检”被误排除。

## 时效性规则

- 同一主题优先选择最新且当前有效的正式版本，而不是单纯选择网页年份最大的结果。
- 年份以文件的正式发布日期、修订日期或版本标识为准，不把网页更新时间当作文件版本。
- 必须核对是否有更新、修订、替代或废止信息。旧版只能在仍有效、无新版或用于历史对比时使用，并明确说明原因。

## 核验流程

1. 先查已核验入口，再用搜索索引、B-/C 或专业平台快速发现候选文件和新版线索。
2. 按 China-first 和文件层级选定主文件，不因某个承载页面容易访问就改选较低优先级文件。
3. 用完整标题、DOI 或文号定位主管部门、制定机构、正式学会、正式期刊中的 S/A 原文或正式附件。
4. 先核对文档类型，排除综述、研究、解读、摘要、新闻、访谈、病例讨论、科普和二次整理。
5. 核对完整名称、制定机构、发布日期/年份、版本、正式出处、适用范围和版本状态。
6. S/A 全文访问受限时，按 B+ → B 顺序读取同一正式文件，并完成 B+/B 文档身份硬门槛；不能完成时停止，不用二手摘要补齐。
7. 涉及新旧变化时，必须同时取得新版和旧版原文。医保内容仍必须回到正式目录、政策附件或地方医保局正式文件，不适用 B+/B 医学指南承载降级。
8. 输出时只列与学习结论直接相关的规范性核心来源；周期末推荐下一阶段时可列 2-3 个已核验的正式指南候选。

## 禁止项

不得编造文件名、文号、机构、年份、链接、版本关系、医保支付条件、药物剂量或本院能力。

未实际检索或无法访问原文时，只能写“未取得可核验权威来源”或“需人工核验”，不得伪装成已确认更新。

检索到的只有综述或研究论文时，也应按“未取得可核验正式指南”处理，不能用它们补齐最终来源或下一阶段候选。

## 输出要求

医生端只输出简洁核验结论：

```text
【信源核验】
核验对象：{文件或主题}
结论：{可作为学习依据 / 仅可作为线索 / 不建议使用}
原因：{文档类型、机构、年份、原文可达性、是否为最新有效版本}
来源：{文件名称}：[链接]({URL})
边界：本核验仅用于学习依据判断，不提供诊疗、处方、医保报销或院内执行建议。
```

使用 B+/B 正文承载时，在来源前额外输出一行可审计元数据，字段名不得省略：

```text
文档核验：文档标题：{标题}；文档类型：{正式指南/正式专家共识}；制定机构：{机构}；年份/版本：{年份或版本}；正式出处：{DOI/文号/期刊卷期}；完整全文核验：{已核验}；版本状态：{新版/替代/废止核验结论}。
来源：{文件名称}（{B+或B}正文承载）：[链接]({URL})
```
