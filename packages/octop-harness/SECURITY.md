# Security Policy

## Supported versions

| Version | Supported |
|---------|-----------|
| latest release on `main` | ✅ |
| older releases | best effort |

## Reporting a vulnerability

**Please do not open a public GitHub issue for security vulnerabilities.**

- **GitHub Security Advisory:** [Create advisory](https://github.com/TencentCloud/octop-harness/security/advisories/new)
Include:

- Description of the vulnerability
- Steps to reproduce
- Impact assessment
- Suggested fix (if any)

We aim to acknowledge reports within **3 business days** and provide a fix timeline within **7 business days** for confirmed issues.

## Scope

This policy covers the octop-harness Python package (`octop-harness`) and its official examples. Downstream deployments (custom agents, API keys, IM channel credentials) remain the operator's responsibility — follow least-privilege practices for production deployments.
