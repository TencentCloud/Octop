首次 Python 下载停滞已解决。四个较大的 wheel 使用官方包源下载并核对 `uv.lock` 中的 SHA-256 后安装，其他依赖由 uv 同步；`UV_NO_SYNC=1` 防止重新下载相同版本，不跳过任何检查。可选本地嵌入依赖已安装。此前 `e473dd3` 的中断检查不作为当前绿色证据。

原快照上的失效测试契约做了最小修复：保留部分 API mocks 的真实辅助导出、匹配 refresh 请求体、避免纯文本测试加载 PDF 的 DOMMatrix 环境。开发基线的新聊天工具栏测试保留原样。`chatStore` 仅去掉冗余 Boolean 包装，流式条件语义未变。

## 独立实例的真实浏览器联调

新建验收实例使用临时目录 `/private/tmp/octop-workbuddy-ui-acceptance-20261004`、后端端口 18089、前端端口 5194，连接真实 HTTP/SQLite；没有使用模拟业务响应。初始化密码只在该临时实例关闭，模型配置留空。没有操作既有业务实例、绕过其认证或验证码，也没有配置真实外部服务。

浏览器工具已执行以下有限路径，详见 [real-browser-checks.json](evidence/real-browser-checks.json) 和 [real-http-checks.json](evidence/real-http-checks.json)：

1. 通过真实初始化表单保存 SQLite 配置、创建测试管理员、跳过模型配置并进入已认证主界面。
2. 用户名称草稿在设置页切换面板后保留；保存后刷新，从后端重新读取更新名称。
3. 创建停用的 Cron 文本任务，编辑标题，刷新后读取同一任务；启用后编辑/删除菜单不可用，再停用。没有立即执行任务；任务最终保持停用。
4. 未配置模型时显示真实失败原因，发送按钮禁用；这不代表聊天生成验收通过。
5. 真实项目页显示“未接入”，新建与搜索均禁用，没有临时项目或伪造保存结果。
6. 稳定动画后的设置框为 880×720、导航 200px、内容 680px。真实自动化页在 1440×900 下顶栏为 56px；390×844 下为 48px。检查的自动化/项目手机页面横向溢出为 0。

`operation-inventory.json` 仅为这些操作登记 `partial-browser-verified`，仍未计作全部角色、失败路径和平台均已验收。初始化向导部分请求位于 `wizardClient`，不冒充已被 51 模块静态扫描完整覆盖。

`evidence/` 的截图均为 JPEG 展示记录，包含开发样例及标记为 `real-*` 的独立实例画面；**不是 WorkBuddy 原版基准，也不用于 ≤1% 的 PNG 像素差异验收**。截图名称对应实际像素尺寸；设置框动画中的暂态截图已重新采集。`viewport-checks.json` 是样例尺寸记录，真实尺寸另存于 `real-browser-checks.json`。
