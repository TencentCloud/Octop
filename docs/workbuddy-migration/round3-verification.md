**状态：统一市场、设置中心及本轮入口整理已落地；工程检查和分项真实业务验收通过，整体验收未完成。** 未提交、推送、发布或移除旧界面。保留 `VITE_UI_VARIANT=legacy|workbuddy`，默认及最终内置构建仍为 `legacy`。

## 已落地内容

- 一个生产统一市场主壳：原版图标、28px/14px/4px 三页签；专家目录为默认，右上搜索及我的专家；独立技能发现/安装/详情返回；连接器目录、独立详情与原有配置/授权流程。
- 已访问市场页保留控制器、筛选及位置，URL、浏览器历史、刷新和旧入口兼容；菜单/页签按同一权限及自定义导航来源显示。没有混入第二套专家侧栏。
- 880×720、200px 导航设置窗口，27 分类，模块权限过滤，按需加载并保留已访问内容；作用于 Agent 的配置明确对象并隔离草稿。移动端提供全屏分类/内容/返回。
- 低频配置、外观、用量和管理入口收进设置；更多只有文件、知识库、控制台。只有远程桌面/手机权限时，控制台入口落到已有授权控制页；其他控制入口由二级导航提供。
- 首页桌面/移动低频工具收起；主题、表单与浮层继续使用 WorkBuddy 外观。开发样例复用生产顶栏、卡片、主壳和设置窗口，样例按钮移到开发标识栏。
- API、DTO、数据库、认证、流式状态、队列和控制台生命周期保持现有契约。没有接入原版私有客户端或新增虚构服务。

详见 [导航与功能映射](round3-navigation.md)、[逐屏差异记录](round3-screen-differences.md)。
