# 知识库 Excel 公式重算

上传仍保存原始文件，并创建一条知识库文档记录。后台索引任务检查 `.xlsx`、`.xlsm` 的公式单元格，以及 `.xls` 的 BIFF FORMULA 记录；没有公式的表格直接交给原解析器，不启动 LibreOffice。

含公式的文件通过服务器上的 `soffice` 或 `libreoffice` 重算，保存为同一文档旁的 `<document_id>.recalculated.xlsx`。独立临时配置强制重新计算，禁用宏、活动内容和外部链接更新。每次重算最多 120 秒；沿用现有单进程索引并发限制（1）。无需新服务、数据库迁移或额外文档记录。

重算后检查工作表、公式是否保留，以及结果是否缺少缓存或包含 Excel 错误；零和公式返回的空字符串均有效。成功后的文本抽取、索引、文本预览和表格预览共用副本。下载始终返回原件。表格解析成功前，预览返回 409 和可读提示；失败不会悄悄回退到缺失金额的原文件。

重新解析会重新生成副本；删除文档会一起删除副本。部署前已经索引的含公式文件需重新解析，才能生成副本。原件的字节、文件名和知识库记录不改变；LibreOffice 可能调整副本中的样式或公式表示。

服务器需要 LibreOffice Calc（官方 Docker 镜像已安装；其他安装方式需自行安装）。无法使用 LibreOffice、超时、转换失败或公式结果校验失败时，文档标记为解析失败，保留原件并提示原因。依赖宏、外部工作簿或 Excel 专有函数的文件不保证能够重算；外部数据不会自动刷新。旧 `.xls` 使用公式记录数量校验，`.xlsx`/`.xlsm` 同时校验公式坐标。
