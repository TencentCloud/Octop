# 简单主题

简洁、中性的控制台主题，为对话、侧栏、设置页与管理页面提供一致的视觉体验。支持浅色、深色和移动端，不改变应用数据及业务交互。

## 特点

- 统一卡片圆角、柔和阴影与滚动容器内侧留白。
- 保留模型品牌 SVG 原始结构和图标上游署名，模型名识别数据不作主题标识替换。
- 删除确认使用舒适留白、中性提示图标与黑底白字操作按钮；风险说明完整保留。
- 取消、禁用、验证错误及非删除警告保持原有语义。
- 已置顶状态常驻可见；触屏操作拥有清晰的点击区域。
- 专家详情卡片仅保留单层外框，避免嵌套描边。

## 安装和构建

将发布包导入控制台的插件管理页面，启用后即可生效。

ZIP 可以直接包含插件文件，也可以包含一层 `simple-theme/` 目录。包内只保留插件根目录的 `plugin.yaml`。

本插件需要宿主支持插件 UI 清理回调及 `host.requestBlob()`。控制台登录后统一加载插件 UI；禁用、卸载或退出登录时执行清理。插件不修改服务端页面函数。接口和字体请求使用宿主能力，兼容子路径部署及两种登录凭据存储方式。

宿主在页面布局挂载时调用 `setup()`，卸载、禁用、重载或退出登录时恰好调用一次它返回的清理函数；主题在这里移除样式、监听器、定时器和字体，并中止请求。

开发时，在项目目录执行：

```sh
python3 build.py
```

构建将 `ui/theme.css` 与 `ui/model-icons.js` 内联至 `ui/index.js`。图标生成脚本位于 `tools/`；构建后的图标展示不需要额外联网。

## 插件标识迁移

从旧插件标识完整迁移为 `simple-theme`。安装时会先把旧安装目录移出插件扫描路径并保留备份，再安装新标识。浏览器首次运行只迁移一次旧的可调整正文宽度偏好到新存储键，并删除旧键；不再依赖旧插件 ID。

## 兼容性与实现边界

插件 ID、样式根标识、主题自有钩子、CSS 变量和工具名均使用 `simple-theme` 命名。合法模型名称与品牌映射仅作为模型数据保留。合法模型名称和品牌映射不做文字替换。

删除样式在有限的按钮标签、无障碍名称及确认标题上设置展示属性，不移动 React 节点，不更改事件处理，也不会自动确认删除。未识别的自定义控件保留应用原样。

输入框上方的模型条只读：图标和名称随当前会话模型更新，宿主原生「+」菜单仍是唯一开关，已选模型仍由宿主自带标签移除。自动模式只显示「自动选择」。窄屏用末段短名，悬停/读屏可取得全名。

## 升级宿主（1.0.4 起）

本版本依赖两项宿主能力，缺一即降级：

1. **插件 UI 生命周期**：`setup(host)` 的返回值被当作 cleanup 登记，`resetPluginUiLoader()` 会中止在途 fetch、二次校验 generation，并把晚到的异步 cleanup 立刻执行。旧宿主调用 `setup()` 后丢弃返回值，登出/禁用/热重载后样式、监听器、轮询会残留（401 轮询继续跑）。
2. **`host.requestBlob()`**：插件静态资源要带 `Authorization` 头取回，`FontFace` 才能注册 Inter。旧宿主没有这个方法，字体加载抛错并被捕获，回退系统字体，其余功能正常。

检查当前宿主是否具备：

```sh
grep -c requestBlob <dashboard>/assets/index.*.js          # >0 才算有
grep -o 'reloadPluginToolUis\|resetPluginUiLoader' <dashboard>/assets/ensureBuiltins.*.js
```

判定：

- 有 `requestBlob` 且 `setup()` 返回值被登记 → 全功能。
- 只有 `setup()` 返回值登记、无 `requestBlob` → 仅字体回退，其余正常。
- 两者都没有 → **能装、能看，但生命周期是旧语义**：不要宣称已完全生效，需升级宿主前端后重新登录。
