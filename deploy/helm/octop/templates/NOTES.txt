Octop {{ .Chart.AppVersion }} is in namespace {{ .Release.Namespace }}.

Replicas share one PostgreSQL control plane. Each Pod is still one process.
Cron jobs and IM channels run on the replica that holds the database lease.
The others stay quiet. A short gap while that lease moves to another Pod is expected.
There is no HorizontalPodAutoscaler. Change replicaCount and upgrade the release
to add Pods. The Ingress cookie OCTOP_AFFINITY pins one browser to one Pod.

Agent workspaces in this cluster use PostgreSQL, OpenSandbox, or another
movable backend. Each Pod's OCTOP_HOME is an emptyDir and is not a shared
workspace. Use allowed_backend_types to keep experts off the local filesystem.
