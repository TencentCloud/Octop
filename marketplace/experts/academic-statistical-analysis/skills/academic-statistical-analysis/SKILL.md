# 统计分析工作流

你现在要完成一项科研数据的统计分析任务。你已安装以下 Skill，请按步骤串联使用：

## 步骤 1：统计方法选择与建模（获取层）
使用 **R Stats — 82 Statistical Methods** 完成：
- 根据研究设计和数据类型选择合适的统计方法
- 覆盖回归分析、生存分析、贝叶斯统计、荟萃分析等 82 种方法
- 执行因果推断、结构方程模型等高级分析
- 进行项目反应理论和临床试验设计相关统计
- 输出统计建模的初步结果和模型参数

输出统计方法选择方案和初步建模结果。

## 步骤 2：高级统计建模与模拟（获取层）
使用 **Biostatistics: Actuarial-Level Statistical Analysis** 完成：
- 执行贝叶斯推断和后验概率估计
- 运行蒙特卡洛模拟评估模型稳健性
- 构建生存模型和风险评估框架
- 结合机器学习方法进行特征筛选和预测
- 对复杂数据进行多层次统计建模

输出高级统计模型和模拟分析报告。

## 步骤 3：标准化数据分析流程（分析层）
使用 **Data Analysis Workflow** 完成：
- 按标准化工作流执行数据清洗和预处理
- 进行描述性统计和探索性数据分析
- 执行核心统计分析并记录分析过程
- 生成科学可视化图表辅助理解
- 确保分析流程可复现、结果可追溯

输出标准化分析流程文档和中间结果。

## 步骤 4：统计检验与模型诊断（分析层）
使用 **Pywayne Statistics** 完成：
- 执行正态性检验验证数据分布假设
- 进行位置检验和相关性检验
- 运行时间序列检验评估数据时序特征
- 执行模型诊断检验评估拟合质量
- 覆盖 37 种以上统计检验方法确保结论稳健

输出统计检验结果汇总和模型诊断报告。

## 步骤 5：中文数据分析报告（输出层）
使用 **Data Analyst Cn** 完成：
- 将统计分析结果整理为中文分析报告
- 提供数据可视化建议和图表方案
- 进行趋势检测和异常值识别
- 用通俗语言解读统计结论
- 给出基于数据的决策建议

输出中文数据分析报告和可视化方案。

## 步骤 6：统计图表生成与验证（输出层）
使用 **Math & Statistics Graphing Engine** 完成：
- 绘制统计分析所需的各类专业图表
- 生成回归图、箱线图、分布图、热力图等
- 对计算结果进行图形化验证
- 确保图表符合学术发表规范
- 输出可直接用于论文的高质量统计图表

输出学术级统计图表集。

## 最终输出
将以上步骤的结果整合为完整的统计分析成果包，交付以下文件：
1. **统计方法方案**：方法选择、初步建模、参数估计
2. **高级模型报告**：贝叶斯推断、蒙特卡洛模拟、生存模型
3. **标准化流程文档**：数据清洗、探索性分析、过程记录
4. **检验诊断报告**：37+ 统计检验、模型诊断、稳健性评估
5. **中文分析报告**：结果解读、趋势检测、决策建议
6. **统计图表集**：专业绘图、图形验证、学术发表级图表
