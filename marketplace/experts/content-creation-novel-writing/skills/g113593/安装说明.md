# 安装说明

技能名 `tomato-novelist`。DSH 只识别 `<目录名>/SKILL.md` 这一层，**多套一层或直接平铺在 `.agents\skills\` 下都不会被发现**。

## 方式一：手动复制（最稳）

把 `tomato-novelist` 整个目录放到：

```
%USERPROFILE%\.agents\skills\tomato-novelist\SKILL.md
```

## 方式二：PowerShell 一条命令

在解压出来的目录（`tomato-novelist` 的同级）执行下面整段：

```powershell
$src = '.\tomato-novelist'                                  # 解压出来的技能目录
$dst = Join-Path $env:USERPROFILE '.agents\skills\tomato-novelist'

if (-not (Test-Path (Join-Path $src 'SKILL.md'))) { throw "源目录缺少 SKILL.md: $src" }
if (Test-Path $dst) {
    # 只在目标目录确实带 SKILL.md 时才清理，避免误删你手工堆放的其他内容
    if (-not (Test-Path (Join-Path $dst 'SKILL.md'))) { throw "目标已存在且不是本技能，已停止: $dst" }
    Remove-Item -LiteralPath $dst -Recurse -Force
}
New-Item -ItemType Directory -Force (Split-Path $dst) | Out-Null
Copy-Item -LiteralPath $src -Destination $dst -Recurse -Force
Test-Path (Join-Path $dst 'SKILL.md')                       # 应输出 True
```

若提示脚本被禁用，先执行 `Set-ExecutionPolicy -Scope Process Bypass`。

## 生效与触发

数秒内 DSH 技能表会刷新。之后直接说：

> 用番茄小说助手写一本悬疑题材的小说

## 环境要求

- 字数与 AI 味检查脚本需要 Python 3（DSH 自带运行时，无需另装）。
- 脚本用法见 `SKILL.md` 第 10 步；它只统计 `## 正文` 小节的**汉字**（不含标点），是平台字数的下界。
