# 番茄情绪曲线

## 核心公式：每 3 章一个情绪单元「压 → 小扬 → 压（章末放爆预告）」

> 3 章装不下 4 个动作：第 3 章的落点是**爆预告**，真正的爆点放在下一个单元的开头。

| 章 | 情绪 | 读者心理 | 写作任务 |
|---|---|---|---|
| 1 | 压 | “太憋屈了，我要看他翻身” | 建立同情、展示困境、暗示主角有独特优点 |
| 2 | 小扬 | “果然有反转！我就知道！” | 给一次小胜利或一条关键信息，**不解决根本问题** |
| 3 | 压 → 爆预告 | “又被打压？下章必须打脸！” | 反派加码，主角拿到筹码，章末暗示反击 |

第 4-6 章进入下一单元「小扬-压-爆」，把上一单元预告的爆点放出来；此后单元交替推进（压-小扬-压 / 小扬-压-爆）。**每一轮的爆点规模逐轮放大**——指每个单元末端的爆点，不是每一章递增。连续 3 章没有“爆”的预期，追读就会掉。

## 六大情绪标签的 3 章模板

| 标签 | 第 1 章（压） | 第 2 章（小扬） | 第 3 章（压 → 爆预告） |
|---|---|---|---|
| 打脸爽文 | 因隐藏身份被嘲讽欺负 | 不经意露实力，被当成运气 | 遇更强对手，暗示即将当众揭身份 |
| 极致虐恋 | 女主被虐心、被忽视 | 女主觉醒，决定离开 | 男主追悔莫及，章末出现后悔画面 |
| 爆笑反套路 | 主角陷入经典套路剧情 | 用清奇脑回路破解套路 | 系统试图纠正剧情，留“这也能行？” |
| 悬疑惊悚 | 遭遇无法解释的诡异事件 | 找到一点线索或规律 | 发现规律本身是陷阱，留细思极恐钩子 |
| 治愈甜宠 | 主角处于孤独缺爱状态 | 与 CP 产生温暖互动 | 出现小误会，章末 CP 做出心动举动 |
| 脑洞大开 | 得金手指但面临生存危机 | 用金手指解决小危机 | 发现金手指有代价，出现更大机遇 |

## 单章内部：至少 3 次情绪变化

- **开头（前 5-10%）**：延续或急转，定下本章情绪基调
- **中间（约 55-65%）**：情绪逐步升级，至少一次小起伏
- **结尾（约 15-20%）**：冲到本章峰值后急转，留下钩子

> 按默认档 2200-2500 字折算：开头约 110-250 字 / 中间约 1200-1600 字 / 结尾约 330-500 字。男频 2500-3000 字同比放大。

**拐点句式库**

- 憋屈 → 暗爽：他低着头，嘴角却微微上扬——他们还不知道，自己惹了谁。
- 震惊 → 愤怒：看到那张照片，她才发现，这三年的眼泪都流给了骗子。
- 绝望 → 希望：门锁转动时她握紧了水果刀。但进来的，是那张熟悉的脸。
- 得意 → 恐惧：他以为自己赢了，直到转身看见那个人的眼睛。
- 平静 → 震惊：我像往常一样打开门，然后看见了这辈子最不想看见的人。

## 评论区诱导（刻意留白，制造立场分裂）

1. **两难选择**：两个选项都有道理，章末不写决定。
2. **信息差**：让读者比主角多知道一点，但不全知道。
3. **误解不解释**：主角被误解时不立刻澄清。
4. **配角高光**：给反派或配角一个令人同情的瞬间。
5. **道德灰区**：主角做出灰色选择，作者不评价对错。
