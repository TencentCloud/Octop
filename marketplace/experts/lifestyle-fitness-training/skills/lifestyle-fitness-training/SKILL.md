# 健身训练计划工作流

你现在要为用户制定并落地一份个性化健身训练计划（覆盖增肌/减脂/耐力/纠偏/周期化等目标）。你已安装以下 Skill，请按步骤串联使用：

## 步骤 1：信息收集与训练目标确认（处理层）
使用 **Kaiji Fitness Coach** 完成：
- 收集用户基础信息：年龄、性别、身高体重、体脂率、训练经验、伤病史、可用器材、每周训练频次
- 明确训练目标：增肌 / 减脂 / 耐力 / 体态纠偏 / 备赛
- 给出初版个性化训练计划框架（每周拆分、动作选择、强度区间）
- 把信息整理为标准化用户档案

输出用户档案 + 训练目标 + 初版周训练计划。

## 步骤 2：耐力专项计划（处理层 / 跑步/铁三/马拉松）
若目标是耐力专项（跑步/马拉松/铁三/超耐力），使用 **Endurance Coach** 完成：
- 输入比赛日期、当前 5K/10K 配速、历史最高里程
- 生成周期化训练计划（基础期 → 强化期 → 赛前减量）
- 含专项训练日：长距离慢跑、间歇跑、节奏跑、交叉训练
- 给出训练区间（心率区间 / 配速区间）与赛事日策略
- 同步 Strava 历史数据校准计划

输出周期化耐力计划 + 训练区间 + 赛事日策略。

## 步骤 3：力量/居家专项（处理层 / 器材有限）
若用户器材有限或主要目标是居家增肌，使用 **Fitness Support** 完成：
- 基于双哑铃 + 自重设计居家增肌方案
- 安排渐进超负荷计划（每周/每两周提升重量或次数）
- 给出每个动作的标准设置、组数、次数、组间休息
- 配套居家备份方案（出差日/无器材日）

输出居家力量训练日程 + 渐进超负荷追踪表。

## 步骤 4：周期化与体态纠偏（处理层 / 进阶/久坐人群）
对进阶用户或办公室体态问题（圆肩、骨盆前倾、腰背痛），使用 **Gymbuddy** 完成：
- 估算 TDEE / BMR，给出热量与营养目标
- 体态评估：识别紧张肌群与弱化肌群
- 输出周期化训练（积累期 → 转化期 → 竞技期 → 减载期）
- 周期内嵌入体态修复模块（松解 + 激活 + 强化三阶段）

输出 12-16 周周期化方案 + 体态修复阶段计划 + TDEE 报告。

## 步骤 5：动作纠正与执行指导（输出层）
使用 **Exercise Form** 对前序计划中的关键动作完成：
- 标准设置（站姿、握距、轨迹、呼吸）
- 常见错误清单与自检要点
- 退阶动作（动作太难时的简化版本）
- 安全提示与受伤预防（特别是深蹲/硬拉/卧推）

输出关键动作的标准动作教学 + 退阶版本 + 安全清单。

## 步骤 6：训练打卡与历史追踪（输出层）
使用 **Workout（workout-cli）** 完成：
- 创建用户档案与本次训练计划的动作模板
- 每次训练记录：动作 / 组数 / 次数 / 重量 / 休息时间
- 自动生成训练历史与 1RM 估算曲线
- 多用户档案支持（教练带多名学员场景）

输出训练打卡日志 + 力量增长曲线 + 计划完成度统计。

## 最终输出
将以上步骤的结果整合为完整的健身训练成果包，交付以下文件：
1. **用户档案与目标**：基础信息、目标、伤病/器材清单
2. **训练计划**：通用计划 + 耐力专项（按需）+ 居家方案（按需）+ 周期化方案（按需）
3. **体态评估报告**（按需）：紧张/弱化肌群评估 + 修复阶段计划
4. **动作教学**：关键动作的标准设置 + 退阶版本 + 安全清单
5. **打卡日志**：训练历史 + 1RM 曲线 + 计划完成度
