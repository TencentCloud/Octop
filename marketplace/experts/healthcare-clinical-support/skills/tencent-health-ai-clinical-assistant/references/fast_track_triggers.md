# 急症提示触发规则

**用途**：第一步输入解析阶段执行的关键词/阈值检测。命中任一条 → **仅输出急症提示报告**，跳过已知历史信息 / 疑似诊断 / 鉴别诊断 / 误诊漏诊 / 缺失信息等所有常规分支。

**术语说明**：本文件在内部规则库中沿用文件名 `fast_track_triggers.md`，但**面向医生的所有可见输出一律称"急症提示"**，不出现 Fast-Track / Time-Critical Alert 等英文/技术术语。

**设计原则**：
- 触发词/阈值必须**高特异性**——宁可漏触发，不可假触发。
- 卡片只提示**疾病类别 + 时间窗 + 3 条立即动作 + 需通知团队**，不给具体药物剂量（越界）。
- **命中即独占输出**：报告只呈现急症卡片，不再输出其他任何段落。理由：命中 = 90 分钟内需处置的时间敏感疾病，医生必须立即启动救治通路，不是通读一份鉴别分析；同屏多余信息 = 偷走救治时间。
- 一次输入可命中多条 → 按严重度排序全部展示（最多 3 条，超出合并为"多重危急表现，需立即多学科评估"）。
- 报告末尾附一行提示："急症处置启动后如需完整鉴别/缺失信息分析，请回复『继续常规分析』"——医生显式请求时才在下一轮补出常规报告。

## 卡片输出模板

命中即输出急症提示报告：

```
⏱ 急症提示 — [疾病类别名称]
├─ 时间窗：[对应窗口，如 D2W ≤ 90 min]
├─ 立即动作：
│  ① [动作 1]
│  ② [动作 2]
│  ③ [动作 3]
└─ 必须通知：[对应团队]

（多条命中时依次追加卡片，最多 3 张，每张之间空一行）

——
稳定患者后如需完整鉴别 / 缺失信息分析，请回复「继续常规分析」

⚕️ 以上分析仅供临床决策辅助参考，不构成最终医学诊断。最终诊断须由执业医师结合临床实际做出。
```

**关键约束**：
- 报告**仅**包含以上内容，**不输出**：🧾 已知历史信息、模板 A（疑似诊断）、模板 B（鉴别诊断）、模板 C（误诊漏诊）、模板 D（缺失信息）
- 多条命中按上表 # 顺序（严重度参考）依次列出，超过 3 条合并为"多重危急表现，需立即多学科评估"
- 医生显式回复「继续常规分析」→ 下一轮再补出对应常规分支报告

## 注意事项

1. **不给具体药物剂量**——立即动作里只写"启动溶栓评估""静脉降压"这类**动作类描述**，不写"tPA 100 mg 90 min 内静滴"这种剂量表达（越界，属 clinical-rounds-copilot）。
2. **触发词模糊时倾向漏触发**——避免"胸闷 3 天"这种非急性表现假触发 STEMI 卡片。急性 = 数小时内新发或急剧加重。
3. **触发规则允许扩展**，但每条新增必须满足：**高特异性 + 明确时间窗 + 3 条可执行动作 + 需通知团队**。
