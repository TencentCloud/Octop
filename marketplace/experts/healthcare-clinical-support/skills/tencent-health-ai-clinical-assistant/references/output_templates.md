## 通用规则：可读性视觉锚点（v2.2 新增）

统一视觉符号约定，帮助医生快速扫读：

| 场景 | 符号 | 用法 |
|------|------|------|
| 急症提示卡片 | ⏱ | 报告最顶端时间敏感卡片专用 |
| 已知历史信息 | 🧾 | 已知历史信息行前缀 |
| 疑似诊断（模板 A） | 🔍 | 报告主标题 |
| 鉴别诊断（模板 B） | 🔬 | 报告主标题 |
| 误诊/漏诊评估（模板 C） | ⚠️ | 报告主标题 |
| 缺失信息（模板 D） | 📋 | 报告主标题 |
| 优先追问区 | 🎯 | 模板 D 追问区标题 |
| 边界拦截 | ⛔ | 越界请求返回时使用 |
| 危急鉴别 | 🚨 | 需排除的危急情况段前缀 |
| 支持依据 | ✅ | 依据分层标签后可选前缀（表格里已够，可省） |
| 反对/矛盾依据 | ❌ | 不完全符合项前缀（可选） |
| 评分提示 | 📊 | 评分应用提示行前缀（见 `clinical_scores.md`） |
| 安全声明 | ⚕️ | 报告末尾声明前缀 |

**可能性分级视觉锚点（模板 A / C）**：

| 可能性 / 风险等级 | 建议视觉 |
|-------------------|--------|
| 高 | 🟥 高 |
| 中 | 🟨 中 |
| 低 | 🟩 低 |

**使用原则**：
- 视觉符号服务于**扫读效率**，不替代文字描述
- 一份报告内同一场景符号必须一致
- 避免符号堆砌（同一行不超过 1-2 个）

## 通用规则：依据分层标签（v2.2 新增）

模板 A / B / C 内所有"诊断依据""相似点""排除依据"条目**必须**在每条前加一个类型标签，帮助医生一眼分辨证据强度：

| 标签 | 含义 | 使用场景 |
|------|------|---------|
| `[指南标准]` | 命中现行临床诊断阈值（如 cTn 升高 + ST 抬高 ≥ 0.1 mV → STEMI 定义；FPG ≥ 7.0 mmol/L + 症状 → DM） | 高强度硬证据 |
| `[高特异体征]` | 与病理机制强关联的特异性体征（脑膜刺激征、Murphy 征、Cushing 三联征、脉压差、腹膜刺激征） | 高强度体征证据 |
| `[病理生理相关]` | 症状可用假设机制解释（放射痛部位、体位相关性、发作诱因） | 中等强度机制证据 |
| `[流行病学支持]` | 年龄、性别、暴露史、危险因素支持 | 低-中强度先验概率证据 |
| `[非特异]` | 支持但可见于多种疾病（发热、白细胞升高、CRP 升高、乏力） | 低强度证据 |
| `[待验证]` | 患者主观描述、家属转述、既往病历未核实项 → 建议现场复核 | 需二次确认 |

**格式要求**：`• [标签] 具体依据内容`

**示例**：
```
| **诊断依据** | • [指南标准] cTn I 8.5 ng/mL 显著升高 + V1-V4 ST 抬高 0.3 mV<br>• [病理生理相关] 压榨性胸痛向左肩放射 + 大汗<br>• [流行病学支持] 男性 45 岁属 STEMI 高发人群 |
```

**明确不做的事**：
- 不写"来自 XX 指南 202X 年版本"——大模型对具体指南名称/年份/编号的记忆不可靠，避免制造错误权威感
- 不给具体循证等级 (LOE-A/B/C)——同理，避免虚构评级
- 依据分层**只表达证据类型**，不表达置信数字

## 模板 A：疑似诊断报告（无当前诊断 + 最高可能性为"高"）

> **前置条件**：至少 1 条疑似诊断的可能性为"高"。若不满足，禁止使用此模板，强制使用模板 D。

```markdown
## 🔍 疑似诊断分析

### 临床信息摘要
- **主诉**：[提取的主诉]
- **关键阳性发现**：[列出核心阳性症状/体征/检查]
- **关键阴性发现**：[有鉴别意义的阴性结果]

---

### 疑似诊断列表（仅列出高可能性诊断）

#### 1. [诊断名称]（可能性：高）

| 项目 | 内容 |
|------|------|
| **诊断依据** | • [支持依据1]<br>• [支持依据2]<br>• [支持依据3] |
| **不完全符合之处** | • [不支持的发现（如有）] |
| **建议进一步检查** | • [确诊所需的关键检查] |

#### 2. [诊断名称]（可能性：高）
...

### ⚠️ 需排除的危急情况
```

## 模板 D：缺失信息报告（信息不足 / 置信度不足）

> **触发条件**（满足任一）：
> 1. 原始输入明显不完整
> 2. 所有疑似诊断的最高可能性仅为"中"或"低"（R08 置信度门控触发）

**v2.2 改造要点**：报告主体从"长清单"改为"聚焦追问 + 完整清单"两段式。医生在门急诊场景通常先看聚焦追问区（3 条最有诊断价值的问题），无空时才展开完整清单。

```markdown
## 📋 诊断信息缺失分析

### 当前可用信息摘要
- [已有信息概要]

### 诊断困难原因
[简述为何无法明确诊断。若因置信度不足触发，说明：
"当前信息仅支持中/低置信度的诊断假设，准确度不足以作为诊断输出，需补充关键信息后重新评估。"]

---

### 🎯 优先补充这 3 项（按诊断价值排序）

> 若您希望我先聚焦追问、逐步收敛，请回答以下 3 个问题。回答任一即可帮助我更新诊断方向。

**问题 1（最高优先级）**：[最关键的一个问题]
- **诊断价值**：可区分 [方向 A] vs [方向 B]，或直接筛掉一个危急鉴别 [名称]
- **期望获取的形式**：[症状描述 / 具体数值 / 是否/否 …]

**问题 2**：[次优先问题]
- **诊断价值**：[缩小疾病谱 / 排除某类机制]

**问题 3**：[第三优先问题]
- **诊断价值**：[影响下一步检查选择]

---

<details>
<summary>展开完整缺失信息清单</summary>

| # | 缺失类型 | 缺失内容 | 理由 | 依据路径 |
|---|---------|---------|------|---------|
| 1 | 实验室指标 | [具体缺什么] | [为什么需要] | `症状A + 体征B → 疑似C → 确诊需D` |
| 2 | 影像学病灶 | [具体缺什么] | [为什么需要] | `指标E异常 → 定位需F检查` |
| 3 | 症状 | [具体缺什么] | [为什么需要] | `现有表现不足以区分G和H` |

**缺失类型说明**：
- **症状**：病史中未采集或未明确的症状信息
- **实验室指标**：未完成或未提供的化验检查
- **体征**：未执行或未记录的体格检查发现
- **影像学病灶**：未完成的影像学检查或未明确描述的病灶
- **解剖部位**：病变定位不明确

</details>

---

### 建议下一步
1. [优先级最高的补充检查/采集]
2. [次优先级]
3. [其他建议]

---

### 初步方向提示（仅当最高可能性为"中"时出现）

> ⚠️ **以下仅为初步方向提示，非诊断结论，需补充上述缺失信息后重新评估。**
>
> 当前信息初步提示 [方向描述]，但置信度不足以作为诊断输出。

[若最高可能性为"低"，删除此段，不提供方向提示]

---

> **声明**：以上分析仅供临床决策参考，不替代执业医师诊断。
```

### 模板 D 追问问题选取规则

从缺失信息清单中挑选**诊断价值最高**的 3 条作为聚焦追问：

1. **优先选能一次性排除危急鉴别的问题**（如"是否伴撕裂样后背痛"能排/证主动脉夹层）
2. **优先选能区分不同机制的问题**（如"发作与进食关系"能区分胆道 vs 胃肠 vs 心源性）
3. **优先选医生现场即可获取的问题**（追问 / 床旁体检 / 简单化验 > 复杂影像学）
4. **避免选并列同质问题**（不要 3 个都是化验项目）——覆盖症状/体征/化验各 1 条更均衡

若缺失清单少于 3 项，输出全部；若聚焦追问后仍需影像学，在"建议下一步"里给出。

## 输出选择逻辑图

```
输入信息
  │
  ├── 命中急症提示触发规则？
  │     └── 是 → 只输出【急症提示报告】(⏱ 卡片，可 1-3 张)
  │              ⛔ 不输出已知历史信息 / 模板 A / B / C / D
  │              末尾附一行："稳定患者后如需完整分析，请回复『继续常规分析』"
  │
  ├── 未命中急症 → 进入常规分支：
  │
  ├── 有当前诊断？
  │     ├── 是 → 输出模板B（鉴别诊断）+ 模板C（误诊/漏诊风险）
  │     │
  │     └── 否 → 第二步推理后，评估最高疑似诊断的可能性
  │              │
  │              ├── 最高 = 高 → 输出模板A（疑似诊断，仅高可能性条目）
  │              │
  │              ├── 最高 = 中 → 输出模板D（缺失信息 + 方向提示）
  │              │               ⛔ 禁止输出模板A
  │              │
  │              └── 最高 = 低 → 输出模板D（仅缺失信息，不附方向提示）
  │                              ⛔ 禁止输出模板A
  │
  └── 医生显式回复「继续常规分析」→ 补出对应常规分支报告
```

**急症独占输出的设计理由**：命中即代表存在 90 分钟内需处置的时间敏感疾病，此时医生要立即执行救治动作（叫会诊、开血管通路、送导管室），不是通读一份 2000 字鉴别分析。同屏多余信息 = 偷走救治时间。

## v2.2 修订日志

| 变更项 | 说明 |
|-------|------|
| **模板 D 改造为两段式** | 顶部加"🎯 优先补充 3 项"聚焦追问区；完整清单折叠到 `<details>` |

| **追问问题选取规则** | 从缺失清单挑诊断价值最高的 3 条，覆盖症状/体征/化验，且优先排除危急鉴别 |

| **临床评分提示** | 鉴别命中相关疾病时提示应用对应评分（Wells/Alvarado/CURB-65/qSOFA/GRACE 等 15 项），列出覆盖项与缺失项，**不代算总分**（见 `clinical_scores.md`） |
| **可读性视觉锚点** | 统一 ⏱🧾🔍🔬⚠️📋🎯⛔🚨📊⚕️ 符号使用；可能性/风险等级配 🟥🟨🟩 视觉锚点 |
