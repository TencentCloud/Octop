## 1. 接口描述

<strong><font color="blue">此接口被设置为 产品内部展示 。</font></strong>

<strong><font color="blue">此文档展示的是开发联调环境的接口文档 。</font></strong>

接口请求域名： aca.dev.tencentcloudapi.com 。

将用药频次文本标准化为标准频次编码

## 2. 输入参数

以下请求参数列表仅列出了接口请求参数和部分公共参数，完整公共参数列表见 [公共请求参数](/document/product/1522/14881?!preview&preview_docmenu=1&lang=cn&!document=1)。

| 参数名称 | 必选 | 类型 | 描述 |
|---------|---------|---------|---------|
| Action | 是 | String | [公共参数](/document/product/1522/14881?!preview&preview_docmenu=1&lang=cn&!document=1)，本接口取值：MatchFrequency。 |
| Version | 是 | String | [公共参数](/document/product/1522/14881?!preview&preview_docmenu=1&lang=cn&!document=1)，本接口取值：2021-03-23。 |
| Region | 是 | String | [公共参数](/document/product/1522/14881?!preview&preview_docmenu=1&lang=cn&!document=1)，详见产品支持的 [地域列表](/document/product/1522/14881?!preview&preview_docmenu=1&lang=cn&!document=1#.E5.9C.B0.E5.9F.9F.E5.88.97.E8.A1.A8)。 |
| Frequencies.N | 是 | Array of [MatchFrequencyInfo](/document/product/1522/56529?!preview&preview_docmenu=1&lang=cn&!document=1#MatchFrequencyInfo) | 待匹配频次列表 |

## 3. 输出参数

| 参数名称 | 类型 | 描述 |
|---------|---------|---------|
| Code | Integer | 错误码<br/>示例值：100|
| Message | String | 错误信息<br/>示例值：success|
| Data | [MatchFrequencyResponseData](/document/product/1522/56529?!preview&preview_docmenu=1&lang=cn&!document=1#MatchFrequencyResponseData) | 用药频次匹配结果|
| RequestId | String | 唯一请求 ID，由服务端生成，每次请求都会返回（若请求因其他原因未能抵达服务端，则该次请求不会获得 RequestId）。定位问题时需要提供该次请求的 RequestId。|

## 4. 示例

### 示例1 匹配用药频次示例

匹配用药频次

#### 输入示例

```
POST / HTTP/1.1
Host: aca.tencentcloudapi.com
Content-Type: application/json
X-TC-Action: MatchFrequency
<公共请求参数>

{
  "Frequencies": [
    {
      "FreqName": "tid"
    },
    {
      "FreqName": "一天三次"
    }
  ]
}
```

#### 输出示例

```json
{
    "Response": {
        "RequestId": "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx",
        "Code": 0,
        "Message": "success",
        "Data": {
            "Results": [
                {
                    "FreqName": "tid",
                    "StandardCode": "tid",
                    "StandardName": "一天三次",
                    "DailyTimes": "3",
                    "DailyTimesDenominator": "1",
                    "Comment": "",
                    "Similarity": 1.0
                }
            ]
        }
    }
}
```
