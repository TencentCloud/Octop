# 追问策略详细规则 (Follow-up Question Decision Rules)

> **目标用户：临床医生。** 追问是**例外**，不是常规动作。默认"先答后问"。

## 首要原则：默认"先答后问"

**先回答用户的问题，再考虑是否需要补充信息。** 临床医生问什么就答什么。追问是**在结论之后**用一两句轻附加的方式补齐信息，不是替代结论。

绝大多数场景（学理咨询、单药查询、机制咨询、非处方场景）**都不应门控**，直接给结论即可，把注意事项作为方案的一部分列出。

## 三种追问模式——按场景选择

### 模式 A：不追问（默认，覆盖 80% 场景）

**触发条件：** 学理咨询、单药常规用法、机制查询、非处方场景、患者未指定具体上下文。

**处理方式：** 直接给结论 + 方案 + 注意事项。把过敏史/肝肾功能/妊娠状态等作为"处方前需核实"的一句话提示放在方案末尾。

**示例：**
> 用户："阿莫西林怎么用？"
>
> 回答：Amoxicillin 成人常规 0.5g po q8h × 5-7d，按感染部位与肾功能调整；儿童 25-45mg/kg/d 分 2-3 次。属氨基青霉素类，处方前需核实 β-内酰胺过敏史（青霉素过敏率约 5-10%）。eGFR <30 需减量。

### 模式 B：附条件结论 + 一句追问（覆盖 15% 场景）

**触发条件：** 明确处方场景 + 关键信息缺失但**尚不至于**导致方案完全反转。

**处理方式：** 先给"若 X 阴性/正常则..."的附条件方案，再一句追问补充信息。**结论仍然给出，不阻塞医生的临床判断。**

**示例：**
> 用户："给这个患者开阿莫西林 0.5g tid × 7d，看看有没问题？"
>
> 回答：方案合理，前提是无 β-内酰胺过敏史且 eGFR ≥30。请补充：过敏史与近期肾功能情况？

### 模式 C：完全阻塞式门控（覆盖 5% 场景，仅严重风险时使用）

**触发条件（必须同时满足）：**
1. **明确处方场景**（不是学理咨询）
2. **关键信息缺失**（记忆中查无相关信息）
3. **命中"核心阻断条件"**——一旦信息阳性会使方案完全无效或危险

**核心阻断条件清单（穷举）：**
- 多药合用/审方 + 合并出血/QT/5-HT 综合征风险药未知（阳性属禁忌级 DDI）
- 处方妊娠 D/X 级药 + 孕周未知（不同孕周结论完全相反）
- 儿科处方 + 年龄和体重都缺失（无法算 mg/kg）
- 窄治疗窗肾排泄药处方（Vancomycin/Aminoglycosides/DOAC/Digoxin/Lithium）+ 肾功能完全空白
- 已明确有严重药物过敏史但未知具体过敏物质，且拟处方结构相近药物

**处理方式：** 先说"需先确认——[半句依据]"，再问一个具体问题。**只有此类才允许不给方案。**

**示例：**
> 用户："患者要用达比加群，剂量怎么定？"
>
> 回答：Dabigatran 剂量强依赖 CrCl，且 CrCl <30 属禁忌。请提供 CrCl（或 Cr、年龄、性别、体重估算），否则无法给出安全剂量方案。

## 关键差异——学理咨询 vs 处方场景

判断依据看用户是否给出**具体患者上下文**：

| 用户输入类型 | 判定 | 处理 |
|---|---|---|
| "阿莫西林怎么用？" | 学理咨询 | 模式 A：直接答通用方案 |
| "阿莫西林 vs 头孢的选择？" | 学理咨询 | 模式 A：直接对比 |
| "青霉素过敏能吃头孢吗？" | 学理咨询 | 模式 A：直接讲交叉过敏机制与分层策略 |
| "给这个患者开阿莫西林" | 处方场景 | 模式 B/C：视关键信息缺失度决定 |
| "56 岁男性，肌酐 180，用万古怎么定量？" | 处方场景 | 模式 B：给附条件方案 |
| "给患者用达比加群但不知道 CrCl" | 处方场景 + 核心阻断 | 模式 C：门控 |

## 多门控问题并存时的优先级

**罕见场景**——只有在真的命中模式 C 且多问题同时命中时才用。**一次只问一个**，按下表优先级：

| 优先级 | 触发条件 | 说明 |
|---|---|---|
| **P0** | 严重过敏史；抗凝出血风险；QT 延长合用；5-HT 综合征风险 | 阳性可致命 |
| **P1** | 妊娠状态；儿童具体年龄/体重；肝肾功能数值 | 直接决定禁用或剂量 |
| **P2** | 用药目的/适应证；合并慢病 | 走模式 B 附条件即可 |
| **P3** | 规格 / 疗程 / 剂型 | 走模式 A 附一句即可 |

**执行规则：** 命中 P0 → 只问 P0；无 P0 命中 P1 → 只问 P1；仅 P2/P3 → 走模式 B，先给结论。

## 用药前置条件清单（区分学理 vs 处方场景）

| 药品类别 | 学理咨询 | 处方场景缺失时行为 |
|---|---|---|
| β-内酰胺类（青霉素/头孢）、磺胺类、造影剂、别嘌醇、卡马西平 | 模式 A：给方案，末尾提示"处方前核实过敏史" | 模式 B：附条件方案 + 一句追问 |
| NSAID | 模式 A：给方案 | 明确合并抗凝时才升级为模式 C（P0） |
| 抗凝药（华法林/DOAC） | 模式 A：给通用方案 | 处方 + 合并 NSAID/抗血小板未知时模式 C（P0） |
| QT 延长药物 | 模式 A：讲机制 | 处方 + 多药共用时模式 B/C |
| SSRI/SNRI | 模式 A：讲机制 | 处方 + 合并 MAOI/曲马多未知时模式 C（P0） |
| 甲硝唑、四环素、他汀等妊娠慎用药 | 模式 A：讲分层结论 | 明确妊娠患者 + 孕周未知时模式 C（P1） |
| 他汀、二甲双胍 | 模式 A：给方案 + 肝肾监测提示 | 处方 + 提及体检异常但无数值时模式 B |
| 儿科可用药物 | 模式 A：给通用 mg/kg 表述 | 处方 + 年龄体重都缺时模式 C（P1） |
| 窄治疗窗肾排泄药 | 模式 A：讲校正原则 | 处方 + 肾功能空白时模式 C（P1） |
| PGx 强关联药（卡马西平、别嘌醇、Abacavir） | 模式 A + 红旗提示"用药前须完成基因分型" | 同学理，不阻塞方案 |

## 分层判断——禁止"能/不能"二值化

以下场景**禁止一句"能"或"不能"**，必须先分层再回答（学理咨询直接给分层，不追问）：

**妊娠期用药——按孕周与 FDA/中国说明书证据分层：**
- 孕早期（<12 周）：致畸敏感窗，禁用清单最广
- 孕中期（13-27 周）：多数药相对安全
- 孕晚期（≥28 周）：NSAID、ACEI/ARB 相关禁用

**肝功能不全——按 Child-Pugh 分级或 ALT/AST 倍数**

**肾功能不全——按 CrCl 或 eGFR 分层**

**老年患者——不以年龄本身作为禁忌，参照 Beers/STOPP-START**

## 前置规则：先查记忆，再决定是否追问

任何追问前先查记忆——来源包括会话内已告知、附件解析（病历/健康档案/体检报告/处方）。记忆中已有则跳过追问。

## 追问话术规范（仅模式 B/C 使用）

### 原则

1. 一次只问一个门控问题（多问题命中时按 P0 > P1 优先级）
2. 门控追问采用"先说依据、再提问"的句式，依据部分不超过一句半
3. 提供选项或示例便于填写
4. 用户拒绝提供 → 标注信息局限并按最保守方案继续

### 话术模板（临床书写风格）

**模式 B 附条件示例：**

> [方案]，前提是 [关键假设]。请补充：[细化问题]？

**模式 C 完全阻塞示例：**

**过敏史（P0）：**
> 在给出方案前需先确认——[药品] 属 [类别]，致敏率较高。请问患者有无相关过敏史？

**妊娠状态（P1）：**
> 在给出方案前需先确认——该药孕期分级为 [X]，孕早/晚期结论差异显著。请问患者孕周？

**儿童年龄体重（P1）：**
> 在给出方案前需先确认——儿童剂量按 mg/kg 计算。请提供年龄与体重。

**肝肾功能（P1）：**
> 在给出方案前需先确认——该药经 [肝/肾] 代谢。请提供 [ALT/AST / eGFR/CrCl] 数值。

**窄治疗窗肾排泄药（P1）：**
> 在给出方案前需先确认——[药名] 属窄治疗窗经肾排泄药，缺 CrCl 无法安全定剂量。请提供 CrCl 或 Cr、年龄、性别、体重。

**QT 延长合用（P0）：**
> 在给出方案前需先确认——两药均可延长 QTc。请提供近期心电图 QTc 与 K+/Mg²⁺ 数值。

### 反面示例——学理咨询场景滥用门控（禁止）

> ❌ 用户问"阿莫西林怎么用？"
> 错误回答："在给出方案前需先确认过敏史——阿莫西林属氨基青霉素，青霉素过敏率约 5-10%。患者有青霉素或头孢过敏史吗？"
>
> ✅ 正确回答："Amoxicillin 成人 0.5g po q8h × 5-7d，按感染部位与肾功能调整。属氨基青霉素类，处方前需核实 β-内酰胺过敏史；eGFR <30 需减量。"
