# 八字命理工作流

你现在要完成一份完整的八字命理分析任务。你已安装以下 Skill，请按步骤串联使用：

## 步骤 1：高精度排盘（输入层）

使用 **Bazi Paipan** 完成：

- 接收用户出生信息（公历/农历、年月日时、出生地）
- 应用 VSOP87 节气算法 + 真太阳时修正，计算四柱
- 输出完整命盘字段：天干地支、藏干、十神、十二长生、空亡、纳音、刑冲合害、神煞、大运十步、流年

输出物：结构化命盘原始数据。

## 步骤 2：主驱动通排（通用解读）

使用 **Cantian Bazi** 完成：

- 在步骤 1 命盘基础上，叠加黄历信息与大运/流年/流月/流日/流时区间查询
- 输出标准命盘解读基线（五行旺衰、十神格局、用神喜忌、大运走势）
- 标记关键时间窗口（大运转折点、流年应期）

输出物：标准命盘通排报告。

## 步骤 3：子平真诠体系深读

使用 **Bazi Fortune** 完成：

- 以子平真诠体系为标尺，对步骤 2 输出的格局进行正统化复核
- 用确定性算法计算格局成败、用神救应、调候喜忌
- LLM 综合解读：日主强弱、格局清浊、富贵贫贱定盘

输出物：正统体系格局判定文档。

## 步骤 4：多维度命理咨询

使用 **Bazi Fortune Analysis** 完成：

- 在格局已定的前提下，针对用户关心的具体维度逐项咨询：
  - 性格特质 / 事业方向 / 婚姻配偶 / 财运起伏 / 健康预警 / 子女缘分 / 学业前途
- 每个维度给出现状判断 + 大运流年应期 + 趋避建议

输出物：多维度命理咨询报告。

## 步骤 5：跨术对照交叉验证

使用 **Tianjicesuan** 完成：

- 对步骤 4 的关键结论用其他术数交叉验证：
  - 袁天罡称骨：与八字格局对照
  - 紫微斗数：宫位主星与八字十神交叉
  - 三才五格姓名学：现有姓名与命局是否相协
  - 合盘评分：婚恋配对辅助判断

输出物：跨术对照差异说明 + 一致性结论。

## 步骤 6：八字起名（按需，输出层）

使用 **Bazi Name Master** 完成：

- 当用户为新生儿起名或考虑改名时，基于步骤 1-3 的命盘喜忌
- 输出符合用神补救的字库筛选 + 多个候选名字 + 每个名字的命理解释
- 给出三才五格、音形义、避讳字的综合评分

输出物：八字喜用神起名建议书。

## 最终输出

将以上步骤的结果整合为完整的八字命理咨询包，交付以下文件：

1. **命盘原始数据**：四柱八字 + 神煞 + 大运流年完整字段
2. **通排报告**：标准命盘解读基线
3. **格局判定文档**：子平真诠体系下的格局成败定盘
4. **多维度咨询报告**：性格 / 事业 / 婚姻 / 财运 / 健康 / 子女 / 学业
5. **跨术对照说明**：八字 + 紫微 + 称骨 + 三才五格的一致性结论
6. **起名建议书**（按需）：用神补救方向 + 候选名字 + 评分依据
