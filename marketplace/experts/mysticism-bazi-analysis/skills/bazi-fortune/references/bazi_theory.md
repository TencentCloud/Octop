# 八字判读规则手册

排盘数据由 `scripts/bazi.py` 提供；本文件用于把数据翻译成命理判读。撰写「命局总评 / 性格天赋 / 喜用神」前阅读。

## 1. 四柱宫位与人生对应

| 柱 | 宫位 | 覆盖年龄 | 对应人事 |
|---|---|---|---|
| 年柱 | 祖上 / 根 | 1–16 岁 | 祖辈荫庇、家族底色、童年环境、父母早年状态 |
| 月柱 | 父母 / 兄弟 | 17–32 岁 | 父母能力、家庭条件、学业、事业起步、同辈助力 |
| 日柱 | 自己 / 配偶 | 33–48 岁 | 日干＝本人，日支＝配偶宫，主体性格与婚姻质量 |
| 时柱 | 子女 / 门户 | 49 岁后 | 子女、晚年、下属、成果归宿、对外输出 |

宫位被冲：该柱对应的人事领域易生动荡；被合：易有牵绊或贵人；空亡：该领域缘分偏薄或"看淡"。

## 3. 日主强弱与扶抑取用

脚本已给出 `strength.verdict`（身旺/中和/身弱 + 得令/失令）、`ratio`、喜忌五行。判读时按下列顺序校准：

1. **得令优先**：月支本气同我或生我即为得令，是强弱第一权重。
2. **得地**：四支中见日主之比劫本气/中气（尤其日支、月支）为通根有力。
3. **得势**：天干透比劫、印星贴身。
4. 三者得其二即偏强，只得其一或全无即偏弱。

取用原则：
- **身旺**：宜克、泄、耗 → 用神取官杀、食伤、财星；忌印比。
- **身弱**：宜生、扶 → 用神取印星、比劫；忌财官食伤。
- **中和**：扶抑两可，重点在**调候**与**通关**。
- **调候**（寒暖燥湿优先于扶抑）：冬月（亥子丑）生者多需丙火暖局；夏月（巳午未）生者多需壬癸水解炎；初春需火暖、仲春需金裁、秋月需火制金。
- **通关**：两行交战（如金木相战、水火相冲）时取中间五行为用（金木战用水，水火战用木）。
- **专旺 / 从格**：若某一行占绝对优势（五行占比 > 六成且得令），可论从强、从财、从官杀等，用神反从旺神，**不可再用扶抑常法**。判读时须显式说明并谨慎措辞。

## 4. 格局速判（透出优先）

看月支本气透干与否定格：
- 月令本气透出，且为：官杀→正官格/七杀格；财→正财格/偏财格；食伤→食神格/伤官格；印→正印格/偏印格。
- 月令本气未透，取月支中透出且有力者定格。
- 月令无用神可取的：看全局最旺之十神定格。

格局成败要点：
- **正官格**：喜印护、财生，忌伤官克破、七杀混杂。
- **七杀格**：喜食伤制、印化、羊刃合，忌杀重无制。
- **财格**：身旺可任财，身弱财旺为"财多身弱"反为累。
- **食伤格**：喜生财或配印（伤官佩印），身弱食伤重则泄气太过。
- **印格**：喜官杀生印，忌财破印。

## 5. 神煞用法

脚本已列出命局神煞及其落宫。要点：
- 神煞只是**辅助象**，不能压过五行生克与格局。吉煞被冲克减力，凶煞有制化反不为凶。
- 常用吉煞：天乙贵人（解危）、太极贵人（玄学悟性）、文昌（学业）、禄神（福禄）、将星（统领）、金舆（安稳）。
- 常用凶煞：羊刃（刚烈血光）、劫煞（争夺损耗）、亡神（隐忧）、孤辰寡宿（缘分薄）、天罗地网（困滞）。
- 桃花、驿马中性：桃花主缘与才艺，驿马主走动与远方发展。

## 6. 大运与流年

- **起运**：脚本已给出起运年数，`forward` 表示顺排（阳年男/阴年女）或逆排。
- **大运干支**：管十年，天干管前五年、地支管后五年，合参。
- **流年**：以流年干支对日主定十神，再与命局四支论冲合刑害。
- **应期判断优先级**：
  1. 流年支冲命局某支 → 该支宫位有变动（冲年支：长辈/迁居；冲月支：父母/事业环境；冲日支：婚姻/自身；冲时支：子女/门户）。
  2. 流年支与命局三合/半合 → 合出喜神则吉，合出忌神则滞。
  3. 流年干十神定事件性质（见第 2 节表格）。
  4. 本命年（值太岁）与冲太岁之年，宜守不宜攻，重大决策慎之。
- **伏吟反吟**：流年干支与命局某柱完全相同为伏吟（主反复、停滞），天克地冲为反吟（主剧变）。

## 7. 常见组合断语（可与断语库交叉使用）

- 财星破印：学业易中断、为财损名、与母亲观念冲突。
- 伤官见官：口舌是非、不服管、职场与上司相左；有印或财通关则化。
- 官杀混杂：事业多头、压力大、女命感情复杂；有制化则成器。
- 食神制杀：以技术能力驾驭压力，宜专业路线或武职、管理。
- 伤官生财：靠创意、表达、技艺变现，宜自营或业务岗。
- 印重身强无泄：书读得多但行动弱，宜强制输出、定截止期限。
- 财多身弱：机会多而担不住，宜合伙、借势，忌单打独斗与担保。
