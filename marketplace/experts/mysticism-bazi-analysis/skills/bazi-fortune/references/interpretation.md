# 分项断语库与定盘方法

撰写「性格 / 事业 / 财运 / 婚姻 / 健康 / 家庭 / 事件复盘」前阅读。断语是**倾向描述**，必须弱化为"偏向、容易、更可能"，不得写成必然结论。

## 1. 性格与天赋

按「日主五行 + 强弱 + 最旺十神」三层叠加描述。

**日主底色**
- 甲：正直有担当，向上生长，不善拐弯；乙：柔韧善协调，适应力强，易优柔。
- 丙：热情外放、感染力足，易三分钟热度；丁：细腻专注、内秀有礼，易内耗。
- 戊：厚重可靠、承载力强，偏固执；己：包容务实、善统筹，易优柔寡断。
- 庚：果断刚毅、讲义气，易粗糙伤人；辛：精致挑剔、审美敏锐，易苛责。
- 壬：通达灵活、格局大，易散漫无定；癸：敏感细腻、洞察力强，易多疑退缩。

**强弱修正**
- 身旺：主见强、行动力足、抗压好；过旺则固执、好胜、难听劝。
- 身弱：感知力强、善配合、贵人缘好；过弱则犹豫、易被动、边界感弱。

**十神主导**
- 食伤旺：表达力、创造力、审美；伤官旺加"不服管"，食神旺加"知足有福气"。
- 财星旺：务实、重结果、对钱敏感、善经营。
- 官杀旺：守规矩、责任心强、有压力感；七杀重则雷厉风行。
- 印星旺：好学、善良、重名誉；偏印重则好冷门、喜独处。

## 2. 事业与财运

- 用神即**最适合的五行行业**（见第 5 节方位行业表）。
- 官杀为用且有力 → 宜体制内、管理、需资质的专业岗。
- 财星为用且身能任 → 宜经商、销售、投资、资源整合。
- 食伤为用 → 宜技术、创作、教育、咨询、内容输出。
- 印星为用 → 宜研究、教育、文职、医疗、需要沉淀的岗位。
- 大运走用神运十年为**事业黄金期**，宜进取、跳槽、创业、置业。
- 大运走忌神运：宜守成、充电、积累人脉、控制负债，忌激进扩张与担保。
- 财星被劫（比劫重重夺财）：不宜合伙、不宜借钱给他人。
- 财库（辰戌丑未）逢冲：财来财去，宜固定资产而非现金投机。

## 3. 婚姻与感情

- 男命看财星（正财为妻、偏财为缘），女命看官杀（正官为夫、七杀为偏缘）。
- 配偶宫＝日支：日支为喜用 → 配偶助力大；为忌 → 关系磨合多。
- 日支逢冲（尤其月日冲、日时冲）→ 婚姻易波动，晚婚或聚少离多可解。
- 日支坐比劫 → 配偶个性强，易争执；坐食伤 → 重感觉、要求高；坐财/官 → 得配偶助。
- 桃花多、财官混杂 → 异性缘旺，需防感情纠葛；孤辰寡宿入命 → 缘分偏薄，宜主动社交、晚婚更稳。
- 女命伤官旺无制 → 对伴侣要求高、易生口舌，宜配性格宽厚或年龄差较大者。

## 4. 健康与养生

健康断语**只作养生提醒，绝不做疾病诊断**，且必须提示以医嘱为准。
- 五行失衡方向：某行过旺或过弱，对应系统易偏弱（木→肝胆筋眼；火→心血管血液；土→脾胃肌肉；金→肺呼吸道皮肤；水→肾泌尿内分泌）。
- 过旺者"亢则害"：火旺易上火炎症、失眠；木旺易肝郁、头痛；土旺易脾胃积滞；金旺易呼吸道敏感；水旺易寒湿、肾气不足。
- 冲克严重处（如金木相战、水火交战）为薄弱环节，逢冲之年尤需注意作息与体检。
- 凡是出现"血光、手术、重病"类字眼时，必须改写为"注意安全/劳逸结合/建议定期体检"，禁止断言疾病与意外。

## 6. 家庭条件与早年环境的参断

用户输入「家庭条件」等背景时，用来**交叉验证与补充**，不要生硬套用。
- 年柱为喜用且不受冲 → 祖上有荫、童年相对稳定；年柱为忌或受冲 → 早年环境变动大、助力少。
- 月柱（父母宫）为喜用 → 父母有力、家庭资源可用；为忌 → 需早独立、靠自己。
- 印星得力 → 母亲影响深、学业有靠；财星（父）得力 → 父亲或家境提供物质支持。
- 年柱空亡或被冲 → 与祖辈缘薄、早年多迁移。
- 若用户提供的事实与参断冲突，**以事实为准**并说明"宫位与事实有出入，可能与时辰/流派差异有关"，不要强行自圆其说。

## 7. 用过往事件定盘（校时）

时辰未知或存疑时的标准做法：

1. 运行 `python bazi.py --datetime "YYYY-MM-DD" --gender ... --place ... --hour-scan`，得到 12 个候选时辰的时柱与日柱。
2. 向用户索取 **3–5 个有明确年份的关键事件**：升学/就业/跳槽、恋爱结婚、生育、大病手术、迁居出国、重大损失、长辈变故。
3. 对每个候选时辰跑一次完整排盘，比对事件年份的**流年十神 + 与命局冲合**：
   - 升学/得奖之年应见印星、食伤或喜用流年；
   - 破财/失业之年应见劫财、忌神流年、冲财星；
   - 婚恋之年应见财/官或合入日支；
   - 迁居远行应见驿马被冲动；
   - 伤病之年应见冲克严重、忌神当道。
4. 命中事件最多、性质最吻合的时辰即为定盘时辰。若多次都吻合度相似，**如实说明时辰存在 2–3 个候选，结论按最可能者给出**。

注意：时柱只影响时柱与大运起运细节之外的宫位判断（子女宫、门户、晚年及部分格局成败），不会改变年/月/日三柱与大运顺逆方向，校时结论应保持谦抑。

## 8. 措辞红线

- 禁止：必然、一定会、注定、必死、必离婚、必破产、命中注定无子、寿命几何。
- 禁止：诊断疾病、预测死亡、断言意外灾祸、断言他人（配偶/父母/子女）的具体遭遇。
- 禁止：以命理替代医疗、法律、投资、择业决策；涉及求职、生育、手术、投资，必须提示咨询专业人士。
- 替代说法："更倾向于…""比较容易…""需要留意…""相对而言…""从命理角度看…"。
- 每份报告结尾必须保留免责声明（模板已内置）。
