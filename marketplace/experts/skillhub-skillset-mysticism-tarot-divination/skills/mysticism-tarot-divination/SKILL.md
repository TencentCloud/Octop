# 塔罗占卜工作流

你现在要完成一次完整的塔罗占卜任务。你已安装以下 Skill，请按步骤串联使用：

## 步骤 1：加密随机抽牌（输入层）

使用 **Tarot Reading New** 完成：

- 接收用户问题，确认问题类型（开放问题 / 是否问题 / 找东西 / 关系 / 决策）
- 用 Python `secrets` 模块进行加密随机抽牌，避免「AI 抽牌不真随机」的信任问题
- 根据问题类型预选基础牌阵：三牌阵 / 凯尔特十字 / 是否问题 / 找东西

输出物：抽出的牌组（含正逆位）+ 牌阵位置标注。

## 步骤 2：牌阵设计与位置释义

使用 **Tarot Spreads** 完成：

- 在步骤 1 的基础牌阵上，针对用户的具体问题做牌阵微调或加阵
- 对每个位置作专业释义（过去/现在/未来 / 内在/外在 / 因/果/建议）
- 标记大小阿卡纳 + 正逆位的基础含义

输出物：牌阵位置含义说明 + 每张牌的初步定位。

## 步骤 3：韦特经典体系解读

使用 **Tarot Reading** 完成：

- 以标准莱德-韦特-史密斯系统为基线，对每张牌做正统体系解读
- 整合大阿卡纳的人生主题 + 小阿卡纳的日常情境
- 给出"事件预测层"的解释（即流派意义上的"会发生什么"）

输出物：韦特体系下的事件预测解读。

## 步骤 4：反思治愈派情感支持

使用 **Tarot** 完成：

- 切换到「以临在为主，非临床非预测」的反思治愈派视角
- 对步骤 3 的预测内容做心理向重述：将"会发生什么"转化为"邀请你看见什么 / 你可以选择什么"
- 给出情感安抚 + 自我反思引导，避免宿命论

输出物：心理向反思解读。

## 步骤 5：牌阵丰富度补全（按需）

使用 **Mysticx Tarot Drawer** 完成：

- 当用户想换牌阵或对结果不满意，从 13 种牌阵中匹配更合适的牌阵
- 重新抽牌并解读，提供"另一个视角"
- 用于深入或多角度验证

输出物：备选牌阵的二次解读（按需）。

## 步骤 6：占星内容创作（输出层，按需）

使用 **Tarot Content** 完成：

- 当用户是塔罗博主/占星创作者，将本次占卜解读转化为社交媒体内容
- 输出每周运势脚本 / 短视频脚本 / 封面图文案 / 配文
- 按平台风格（小红书 / 抖音 / Instagram）做版式适配

输出物：可发布的塔罗内容素材包（按需）。

## 最终输出

将以上步骤的结果整合为完整的塔罗占卜成果包，交付以下文件：

1. **抽牌记录**：加密随机抽牌的牌组 + 牌阵位置
2. **牌阵释义**：每张牌的位置含义 + 大小阿卡纳定位
3. **韦特体系解读**：事件预测层的正统解读
4. **心理向反思**：治愈派视角的情感支持解读
5. **备选牌阵解读**（按需）：另一个角度的二次验证
6. **可发布内容素材**（按需）：每周运势 / 视频脚本 / 封面文案
