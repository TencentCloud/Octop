# 冥想正念工作流

你现在要为用户搭建一份冥想正念练习方案（覆盖习惯养成、日常微练习、即时减压、深度禅修、睡前助眠）。你已安装以下 Skill，请按步骤串联使用：

## 步骤 1：冥想习惯养成与打卡（处理层）
使用 **Mindfulness Meditation** 完成：
- 评估用户冥想经验（0 起步 / 已有基础 / 进阶）、痛点（焦虑/失眠/专注力差/情绪波动）、可用时间
- 给出引导课程（呼吸觉知 / 身体扫描 / 慈心禅 / 内观 / 行禅）
- 安排 7 天 / 21 天 / 30 天打卡挑战 + 正念提醒（晨起、午间、睡前）

输出冥想入门方案 + 打卡日历 + 正念提醒计划。

## 步骤 2：每日 3-5 分钟微练习（处理层）
使用 **Daily Mindful** 在习惯计划上叠加日常微练习：
- 晨间：3-5 分钟呼吸觉知 + 设定当日意图
- 午间：5 分钟引导冥想 / 身体扫描（防止下午精力崩溃）
- 晚间：5 分钟反思（今天三件值得感恩 / 一件可以改进）
- 适合忙碌人群的低门槛形态

输出每日晨/午/晚三段式微练习 SOP。

## 步骤 3：呼吸法工具箱（处理层）
使用 **Breathe** 给用户配齐 5 种主流呼吸法工具箱：
- **方形呼吸（Box）**：4-4-4-4，紧张/焦虑场景
- **4-7-8 呼吸**：吸 4 - 屏 7 - 呼 8，失眠/入睡难
- **维姆·霍夫呼吸法**：增强免疫、提神
- **调息法（Pranayama）**：瑜伽传统，平衡神经系统
- **共振呼吸**：每分钟 5-6 次，提升 HRV、专注力

输出呼吸法选用指南（情境 → 推荐呼吸法）。

## 步骤 4：佛教禅修与东方哲学对话（处理层 / 深度禅修）
对希望深入东方哲学的用户，使用 **Wisdom Claw** 完成：
- 基于中观哲学进行禅修对话
- 阐释缘起、无常、慈悲、空性等核心教义
- 把当日生活/工作场景翻译为禅修练习题
- 配合步骤 1 的内观坐禅引导做深度修学

输出禅修对话记录 + 当日练习题。

## 步骤 5：睡前放松流程（输出层 / 失眠/入睡难）
使用 **Daily Sleep** 完成：
- 选择故事类型：自然风景 / 温馨日常 / 动物伙伴 / 童年回忆 / 奇幻治愈
- 融合心理学技术：渐进式肌肉放松、正念呼吸、可视化想象、安全基地构建、感恩回忆、催眠暗示
- 输出 1000-2500 字纯文本故事，可由 TTS 朗读
- 配合步骤 3 的 4-7-8 呼吸法形成睡前组合

输出助眠故事文本 + 睡前组合 SOP（呼吸 + 故事）。

## 步骤 6：即时压力缓解（输出层 / 工作崩溃时刻）
使用 **Stress Relief** 给用户配置即时压力缓解包：
- 触发场景：工作卡壳、突发情绪、考前/上台前
- 30 秒方块呼吸（吸 4 - 屏 4 - 呼 4 - 屏 4）
- 心理引导：理解并接纳挫败感（而非压抑）
- 设置 5 分钟后的安抚提醒，重新聚焦任务
- 配合长期培养：步骤 2 的晨间微练习预防情绪积累

输出 30 秒压力急救卡片（场景 → 流程 → 自我对话脚本）。

## 最终输出
将以上步骤的结果整合为完整的冥想正念落地方案，交付以下文件：
1. **入门方案**：冥想方案 + 打卡日历 + 正念提醒计划
2. **每日 SOP**：晨/午/晚三段式微练习
3. **呼吸法工具箱**：5 种呼吸法 + 情境对照表
4. **禅修对话**（按需）：佛教智慧对话记录 + 当日练习题
5. **睡前组合**（按需）：呼吸法 + 助眠故事 SOP
6. **压力急救卡**：工作/生活突发场景下的 30 秒急救流程
