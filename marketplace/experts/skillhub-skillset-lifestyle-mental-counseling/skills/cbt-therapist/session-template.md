# 会话记录完整模板与填写指南

## 会话记录的重要性

每次会话后立即填写记录是维持治疗连续性的关键。良好的记录让你能够：
- 追踪来访者的进展和模式
- 记住关键细节，展现专业关怀
- 识别治疗中的关键时刻
- 为下次会话做好铺垫

## 填写指南

### 什么时候填？
✅ **必须**：每次会话结束后立即填写（即使只有10分钟）
✅ **建议**：如果会话中出现重要突破，立刻做简短笔记

### 写得太多还是太少？

**最少包含：**
- 日期、会话次数
- 本次核心议题（一句话）
- 关键自动思维（1-3个）
- 布置的家庭作业
- 下周目标

**越多越好：**
- 具体的来访者语言（引用他们说过的话）
- 认知重构的完整过程
- 你的临床观察和反思

### 如何高效记录？
1. **会话中做标记** — 遇到重要时刻，简单记个词
2. **结束后立即补全** — 记忆最清晰的时候
3. **录音（需同意）** — 事后转写
4. **使用缩写** — 如"AT=自动思维, CT=认知扭曲, RT=替代思维"

- 会话次数：第 3 次

- 上次作业完成情况：完成了认知日记（3天），发现自己在工作中过度担心犯错

| Y-BOCS | - | 未评估 |

### 本周关键事件

|------|---------|------|------|

### 识别的认知扭曲

- [ ] 其他：__

| 步骤 | 内容 |
|------|------|
| 原思维 | "我不能犯任何错误，否则会被裁员" |
| 认知扭曲 | 灾难化 + 全或无思维 |
| 苏格拉底提问要点 | ① 过去工作中犯过小错吗？→ 犯过 ② 每次都被裁员了吗？→ 从未 ③ 同事犯错后都怎样了？→ 大多数继续正常工作 ④ 公司招新人的成本？→ 很高，一般不轻易裁员 |
| 替代思维 | "我无法做到完美，工作中偶尔出错是正常的。多数小错不会被裁员。" |
