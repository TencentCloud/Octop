# 广泛性焦虑障碍（GAD）专项治疗手册

> 基于罗比肖（Robichaud）& 杜加斯（Dugas）《焦虑者自救手册》

---

## 一、GAD核心理解

### 什么是广泛性焦虑障碍？

GAD的核心特征不是担心具体的事情，而是**对"不确定性"的不耐受**。GAD患者的大脑就像一个**"担心生成器"**，不断生产新的担忧来填补旧的担忧消失后留下的空白。

### GAD的认知行为模型

```
        模糊/不确定的情境
                ↓
    核心信念："我必须确定才能安心"
            "不确定性是危险的"
                ↓
    担忧过程：反复思考"如果…怎么办"
            试图通过思考获得控制感
                ↓
    短期效果：担忧带来"我正在做点什么"的错觉
            暂时缓解焦虑
                ↓
    长期后果：担忧强化了对不确定性的恐惧
            形成恶性循环
```

### GAD特有认知扭曲

| 认知扭曲 | 描述 | 示例 |
|---------|------|------|
| **不确定性不耐受** | 无法容忍"不知道会发生什么"的状态 | "我必须知道结果才能安心" |
| **担忧的正性信念** | 认为担忧有帮助 | "担忧能帮助我做好准备"、"担忧能防止坏事发生" |
| **认知回避** | 通过担忧来避免面对真正的恐惧 | 反复思考代替实际行动 |
| **担忧的负性信念** | 认为担忧有害但无法控制 | "我停不下来"、"担忧会让我发疯" |
| **完美主义担忧** | 对"不完美"的过度担忧 | "如果做得不完美，就干脆不做" |

## 二、GAD评估工具

### GAD-7 广泛性焦虑障碍量表

**指导语：** 在过去的两周里，以下问题困扰你的频率如何？

| 问题 | 完全不会(0) | 几天(1) | 一半以上天数(2) | 几乎每天(3) |
|------|------------|--------|----------------|------------|
| 1. 感到紧张、焦虑或急切 | | | | |
| 2. 不能停止或控制担忧 | | | | |
| 3. 对各种事情担忧过多 | | | | |
| 4. 很难放松下来 | | | | |
| 5. 坐立不安，难以静坐 | | | | |
| 6. 变得容易烦恼或急躁 | | | | |
| 7. 感到似乎将有可怕的事情发生而害怕 | | | | |

**计分与解释：**
- 0-4分：无或极轻微焦虑
- 5-9分：轻度焦虑
- 10-14分：中度焦虑
- 15-21分：重度焦虑

### 不确定性不耐受量表（IUS）简版

**指导语：** 请对以下陈述的同意程度打分（1=完全不同意，5=完全同意）

1. 不确定性会让我感到压力、焦虑或痛苦
2. 不确定性会阻止我过上充实的生活
3. 当事情不确定时，我无法正常运作
4. 我应该能够控制生活中发生的一切
5. 不确定性使我变得脆弱、不快乐或沮丧

**计分：** 总分越高，不确定性不耐受程度越高

## 三、GAD核心治疗技术

### 技术1：担忧时间（Worry Time）

**原理：**
打破"随时担忧"的习惯，将担忧限制在特定时间和地点，夺回对生活的控制。

**操作步骤：**

#### 第一步：设定担忧时间
- **选择时间**：每天固定15-20分钟（如下午6:00-6:20）
- **选择地点**：专门用于担忧的地方（不要在床上）
- **设置提醒**：用手机闹钟提醒自己"担忧时间到了"

#### 第二步：延迟担忧
当担忧在其他时间出现时：
1. **识别**："哦，这是一个担忧"
2. **记录**：简要记下担忧内容（1-2句话）
3. **延迟**：告诉自己"我留到6点的担忧时间再处理这个想法"
4. **转移**：将注意力转向当前活动

#### 第三步：应对延迟焦虑
如果延迟让你更焦虑，使用以下语句：
- "这个想法很重要，我会给它应有的关注——在适当的时间"
- "我现在选择不担忧，到6点我有专门的时间来处理"
- "延迟不是逃避，而是更有控制地处理"
- "这个想法不会消失，我可以在担忧时间充分思考它"

#### 第四步：担忧时间处理
在设定的担忧时间内：
- 回顾记录的担忧列表
- 选择1-2个最重要的担忧进行思考
- 问自己："这个担忧有解决方案吗？"
  - 有 → 制定行动计划
  - 没有 → 练习接纳不确定性
- 允许自己尽情担忧（如果还想的话）

**常见困难与解决：**

| 困难 | 解决策略 |
|------|---------|
| "我控制不住，必须现在想" | 从短时间延迟开始（5分钟），逐步延长 |
| "我怕忘记这个想法" | 写下来就不会忘，担忧时间会回顾 |
| "延迟让我更焦虑" | 这是正常的，坚持练习会逐渐减轻 |
| "到了担忧时间不想担忧了" | 很好！说明延迟策略有效 |

### 技术2：担忧记录与分析

**目的：**
检验"担忧的正性信念"，发现担忧的实际效果与预期效果的差距。

**记录模板：**

```
担忧记录表

日期：________

1. 担忧内容：
_________________________________

2. 触发情境：
_________________________________

3. 担忧时的情绪（0-10）：_____

4. 担忧结果预测：
   "我担心会发生的事：____________________"
   "发生的概率（0-100%）：_____"

5. 实际结果：
   "实际发生了什么：______________________"

6. 预测准确率：
   □ 完全准确  □ 部分准确  □ 完全不准确

7. 即使担忧的事发生了，后果有多严重（0-10）：_____

8. 我能否应对这个结果：
   □ 完全可以  □ 基本可以  □ 有点困难  □ 无法应对
```

**分析要点：**

#### 发现1：担忧的预测准确率很低
- 大多数GAD患者的担忧预测准确率低于20%
- 即使担忧的事发生，后果往往没有想象的严重
- 记录数据会证明：担忧≠准确预测

#### 发现2：担忧不能防止坏事发生
- 记录"担忧的事发生了吗？"
- 发现：担忧与结果之间没有因果关系
- 替代：计划 vs 担忧

#### 发现3：即使发生，也能应对
- 记录"我能否应对"
- 发现：大多数时候，即使最坏情况发生，你也有能力应对
- 增强自我效能感

**示例分析：**

| 日期 | 担忧内容 | 预测 | 实际结果 | 准确率 |
|------|---------|------|---------|--------|
| 周一 | 项目汇报会搞砸 | 80%概率被批评 | 汇报顺利，获得肯定 | 0% |
| 周二 | 家人出差会出事 | 60%概率发生意外 | 一切平安 | 0% |
| 周三 | 体检会发现重病 | 70%概率有问题 | 一切正常 | 0% |

**结论：** 3天担忧预测准确率 = 0%

### 技术3：不确定性接纳训练

**核心信念检验：**

#### 信念1："我必须确定才能安心"
**检验问题：**
- 过去有多少事是100%确定的？
- 你是如何度过那些不确定的时刻的？
- "确定"是一种感觉还是一种状态？
- 有没有可能，安心不需要100%确定？

**替代信念：**
- "我不需要100%确定才能行动"
- "不确定性是生活的一部分，我可以学会与它共处"
- "即使不确定，我也可以应对可能发生的事"

#### 信念2："不确定性是危险的"
**检验问题：**
- 生活中哪些不确定性是可以接受的？（如天气、交通）
- 这些不确定性真的危险吗？
- 你是如何接受这些不确定性的？
- 为什么某些不确定性可以接受，而其他的不行？

**替代信念：**
- "不确定性不等于危险"
- "很多美好的事情也来自不确定性"
- "我可以承受不确定性带来的不适"

---

**暴露练习：故意面对不确定性**

**级别1（低难度）：**
- 不查看明天的天气预报
- 让别人选择餐厅，自己不提前查看菜单
- 周末不提前做详细计划

**级别2（中等难度）：**
- 故意做"不完美"的决定（如快速选择衣服）
- 不提前排练即将进行的对话
- 尝试新的路线去上班/上学

**级别3（高难度）：**
- 不检查某些事情（如门是否锁好）
- 在不确定结果的情况下做出重要决定
- 接受"我不知道"作为答案

**练习记录：**

```
不确定性接纳练习记录

练习内容：____________________
预期焦虑（0-10）：_____
实际焦虑（0-10）：_____
发生了什么：____________________
我学到了什么：____________________
下次可以做什么：____________________
```

### 技术4：担忧的正性信念检验

**常见正性信念：**

| 正性信念 | 检验问题 | 可能的真相 |
|---------|---------|-----------|
| "担忧能帮助我做好准备" | 担忧和计划有什么区别？担忧带来了什么具体准备？ | 计划帮助准备，担忧只是反复思考 |
| "担忧能防止坏事发生" | 有多少次担忧真的防止了坏事？不担忧时坏事发生了吗？ | 担忧与结果无因果关系 |
| "担忧说明我负责任" | 负责任的表现是什么？担忧等于负责任吗？ | 行动才是负责任，担忧只是焦虑 |
| "如果我不担忧，坏事就会发生" | 有没有不担忧但一切顺利的时候？ | 这是迷信，不是事实 |
| "担忧能让我控制局面" | 担忧时你感觉有控制感吗？还是更焦虑？ | 担忧增加失控感，不是控制感 |

**区分"建设性担忧"与"非建设性担忧"：**

| 建设性担忧 | 非建设性担忧 |
|-----------|-------------|
| 有具体的解决方案 | 没有解决方案，只是反复思考 |
| 导致行动计划 | 导致更多担忧 |
| 有时间限制 | 持续不断 |
| 解决问题后停止 | 一个问题解决，新的担忧出现 |
| 带来控制感 | 增加焦虑感 |

**将担忧转化为计划：**

```
担忧："项目会失败"
    ↓ 转化为计划
计划：
1. 周一：完成市场调研
2. 周二：撰写方案初稿
3. 周三：请同事审阅
4. 周四：修改完善
5. 周五：提交

担忧："家人会生病"
    ↓ 转化为计划
计划：
1. 提醒家人定期体检
2. 保持健康生活方式
3. 购买医疗保险
4. 之后：放下担忧，专注当下
```

### 技术5：认知重构（针对GAD）

**GAD特有自动思维：**

| 自动思维 | 认知扭曲 | 平衡思维 |
|---------|---------|---------|
| "我必须知道结果才能安心" | 不确定性不耐受 | "我不需要100%确定，我可以学会在不确定中生活" |
| "如果我想得足够多，就能控制结果" | 控制错觉 | "思考不能控制结果，行动才能影响结果" |
| "担忧能防止坏事发生" | 迷信思维 | "担忧与结果无关，我需要的是计划而非担忧" |
| "不确定性意味着危险" | 灾难化 | "不确定性是生活的一部分，不等于危险" |
| "我必须为所有可能性做好准备" | 完美主义 | "我不可能为所有可能性做准备，我可以应对发生时的事" |

**苏格拉底提问（GAD专项）：**

1. **识别自动思维**
   - "当你感到焦虑时，脑海中闪过什么想法？"
   - "你在告诉自己什么？"

2. **检验证据**
   - "有什么证据支持这个想法？"
   - "有什么证据反对这个想法？"
   - "过去类似情况发生了什么？"

3. **探索其他解释**
   - "还有别的可能解释吗？"
   - "如果朋友有同样想法，你会怎么对他说？"

4. **去灾难化**
   - "最坏的情况是什么？"
   - "如果发生了，你能应对吗？"
   - "过去你遇到过困难吗？你是怎么度过的？"

5. **形成平衡思维**
   - "基于以上分析，一个更平衡的想法是什么？"
   - "如果相信这个平衡思维，你的感受会有什么不同？"

### 技术6：正念与接纳练习

**目的：**
学会观察担忧而不被它控制，减少与担忧的"纠缠"。

**正念观察担忧：**

1. **识别**："我注意到我有一个担忧的想法"
2. **命名**："这是一个'如果…怎么办'的担忧"
3. **观察**：像看云一样观察这个想法，不评判
4. **放下**：让想法像云一样飘走
5. **回归**：将注意力带回当下

**接纳语句：**

- "我现在感到焦虑，这是可以的"
- "担忧只是大脑的 activity，不是事实"
- "我不需要消除焦虑，我可以带着它继续生活"
- "这个想法来了，它也会走"
- "我允许自己感到不确定"

**身体扫描（焦虑时）：**

1. 将注意力带到呼吸上
2. 扫描身体，注意焦虑的身体感觉（如胸闷、心跳）
3. 不试图改变这些感觉，只是观察
4. 告诉自己："这些感觉会过去的"
5. 将注意力带回呼吸

## 六、GAD危机应对

### 当担忧失控时

1. **STOP技术**
   - S - Stop：停下来
   - T - Take a breath：深呼吸
   - O - Observe：观察当下（我在哪里？发生了什么？）
   - P - Proceed：继续，选择有建设性的行动

2. **5-4-3-2-1 grounding技术**
   - 说出5个看到的物体
   - 说出4种触摸到的感觉
   - 说出3种听到的声音
   - 说出2种闻到的气味
   - 说出1种尝到的味道

3. **自我对话**
   - "这是焦虑，不是危险"
   - "这个想法会过去的"
   - "我可以承受这种不适"
   - "我已经为担忧安排了时间"

### 何时寻求专业帮助

- GAD-7评分持续≥15分（重度焦虑）
- 担忧严重影响工作、学习或人际关系
- 出现抑郁症状（持续低落、兴趣丧失）
- 有自杀或自伤想法
- 自助练习4-6周后无明显改善
