# 简历结构化输出 Schema（精简版，用户指定字段）

解析简历时按以下 schema 输出。**只填写简历中确实存在的信息，缺失字段输出 null / 空数组**，
严禁编造或根据常识推测补全。

## 输出 JSON 结构

```json
{
  "来源文件": "string",
  "姓名": "string | null",
  "年龄": "string | null（简历写年龄记年龄，写出生年月记出生年月，保留原文）",
  "求职意向": "string | null（期望岗位/方向）",
  "期望城市": "string | null（现居/期望工作城市，保留原文表述）",
  "期望薪资": "string | null（期望薪资，保留原文表述）",
  "教育背景": [
    {
      "时间段": "string | null（如 2018.09-2022.06）",
      "学校": "string",
      "专业": "string | null",
      "学历": "string | null（大专/本科/硕士/博士等）"
    }
  ],
  "工作经历": [
    {
      "时间段": "string | null",
      "公司": "string",
      "岗位": "string | null",
      "工作内容": "string | null（职责/业绩要点合并，保留数字量化成果）"
    }
  ],
  "技能证书": ["string（职业资格、计算机、驾照、普通话等非外语类证书）"],
  "语言证书": ["string（外语类：英语四六级/专四专八/雅思/托福/托业/日语能力考等）"]
}
```

## 字段与解析规则

1. **毕业院校 / 学历（汇总列）**：取最高学历对应条目——`教育背景` 按时间倒序排列后的第一条
   （毕业院校取该条 `学校`）。教育背景为空时两者为 null。
2. **教育经历**：由 `教育背景` 数组合并展示（Excel 中一列多行），倒序排列。
3. **工作经历**：
   - 解析 **时间段、公司、岗位、工作内容** 四个字段。
   - **最多取最近 3 段**（按时间段降序；简历无明确时间时按原文顺序，超出 3 段的丢弃并在备注中说明总段数）。
   - 工作内容为职责/业绩要点合并（换行分隔），保留数字量化成果，过长可精简但不得改变事实。
   - 不足 3 段按实际段数，Excel 对应列留空。
4. **证书分类**：外语类证书（四六级、专四专八、雅思、托福、托业、日语能力考等）归入
   `语言证书`；其余（职业资格、计算机等级、驾照、普通话等级等）归入 `技能证书`。
   无法判断归类时放入 `技能证书`。
5. **缺失即 null / 空数组**，绝不造默认值。
6. **冲突标注**：发现时间重叠、学历矛盾等自洽性问题时，附加字段 `"备注": "string"` 记录。
7. **多简历批量**：输出 JSON 数组，每个对象附 `"来源文件": "文件名"`。
