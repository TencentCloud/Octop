# 简历解析（PDF / Word）

将 PDF/Word 简历（`.pdf`/`.docx`/`.doc`）解析为结构化数据并输出 Excel。核心原则：**忠实原文、缺失不造、时间线可核**。

## 工作流程

### 1. 定位文件

确认要解析的简历路径。简历可能是 **PDF 或 Word** 格式（`.pdf`/`.docx`/`.doc`）。
用户给了目录时，用 Glob 匹配 `*.pdf`、`*.docx`、`*.doc` 找出全部简历并告知用户数量与格式分布。

### 2. 提取文本（优先用脚本）

三种格式统一由内置脚本处理（自动选择引擎，Word 表格自动拍平为 `a | b | c` 行）：

```bash
python "<skill-dir>/scripts/extract_resume.py" "<简历.pdf | 简历.docx | 简历.doc>"
```

- `.pdf`：pdfplumber 优先、pypdf 兜底，输出带 `=== Page N ===` 分页标记。
- `.docx`：python-docx 按文档顺序提取段落与表格，输出带 `=== Content ===` 标记。
- `.doc`：先经 MS Word COM 自动转成 .docx 再提取（Windows；老版 Word 2007 已兼容，
  用 `SaveAs FileFormat=12`，Close/Quit 的偶发 RPC 异常已吞掉、以转换产物为准）。
- 默认输出纯文本直接读取分析；加 `--json` 获取元信息；加 `--out file.txt` 落盘（批量推荐）。

**PDF 扫描件（退出码 3，无文本层）时**：
1. 用 Read 工具直接读取该 PDF（多模态读图）；
2. 若 Read 也无法识别，用 Python（pdf2image/pymupdf）把每页转成 PNG 后用 Read 逐张读取；
3. 在结果的"备注"中标注"来源为扫描件，内容经视觉识别，建议人工核对"。

**.doc 转换失败（退出码 4，无 Word/pywin32）时**：
1. 请求用户将文件另存为 `.docx` 或 `.pdf` 后重试；
2. 或用 WPS/LibreOffice 命令行转换（可用时）；
3. 不硬编码猜测内容。

**依赖缺失时**：向托管 venv 安装 `pip install pdfplumber python-docx pywin32`，不要全局安装、不要要求用户安装。

### 3. 解析为结构化数据

按 `references/schema.md` 中定义的字段与规则解析提取到的文本。**用户指定字段**：
姓名、年龄、求职意向、期望城市、期望薪资、毕业院校、学历、教育经历、工作经历、技能证书、语言证书。要点：

- 先通读全文再填字段，个人信息（姓名/年龄）通常在页首或页脚。
- 求职意向、期望城市、期望薪资保留原文表述，缺失则留空。
- 教育背景按时间倒序；`毕业院校`/`学历` 取最高学历对应条目。
- **工作经历解析时间段、公司、岗位、工作内容**；最多取最近 3 段
  （`export_to_excel.py` 中 `MAX_WORK_SEGMENTS = 3`，用户调整需求时改此常量），超出部分丢弃。
  工作内容保留数字量化成果，过长可精简但不得改变事实。
- 证书分类：外语类（四六级/专四专八/雅思/托福/托业/日语能力考等）归入 `语言证书`，
  其余归入 `技能证书`；无法判断时归入 `技能证书`。
- 缺失字段输出 null 或空数组，**绝不根据常识推测补全**。
- 发现矛盾（时间重叠、学历冲突）写入 `备注`。

### 4. 按需选择输出格式

- **默认最终交付：Excel 文件**（见第 5 步）。
- 用户只要快速看一眼单人简历：Markdown 分节 + 表格直接回复，同时仍落盘 Excel。
- 用户要求纯 JSON / 入库：严格按 schema 输出 JSON，可跳过 Excel（除非用户要求两者都要）。
- 多份简历 + 要求对比：输出对比表格（行=候选人，列=学历/年限/核心技能/亮点/疑点），并生成 Excel。

### 5. 导出 Excel（默认最终交付）

解析完成后，将结构化 JSON 落盘为中间文件，再用导出脚本生成 Excel：

```bash
# 1) 把解析结果（单个对象或对象数组）写入临时 JSON，UTF-8 无 BOM
#    每个对象建议带 "来源文件" 字段
# 2) 运行导出脚本
python "<skill-dir>/scripts/export_to_excel.py" parsed.json -o "简历解析结果.xlsx"
python "<skill-dir>/scripts/export_to_excel.py" ./json_dir -o "简历解析结果.xlsx"   # 目录下所有 .json
```

- 脚本生成单张工作表 `候选人汇总`，列依次为：
  `姓名 | 年龄 | 求职意向 | 期望城市 | 期望薪资 | 毕业院校 | 学历 | 教育经历 | 工作经历1-时间段/公司/岗位/工作内容 | 工作经历2-... | 工作经历3-... | 技能证书 | 语言证书 | 备注 | 来源文件`。
  不足 3 段工作经历的候选人对应列留空。
- 表头已加样式、冻结首行、自动列宽、自动换行；无需再手工排版。
- 缺 openpyxl 时向托管 venv 安装 `pip install openpyxl`，不要全局安装。
- 输出文件默认放在工作区目录，文件名带日期（如 `简历解析结果_2026-10-24.xlsx`）避免覆盖。
- 生成后用 present_files 交付给用户。

### 6. 批量处理

多份简历时：
1. 逐份运行提取脚本（`--out` 各自落盘到临时目录）；
2. 逐份解析为 JSON 对象，附 `来源文件` 字段；
3. 汇总写入中间 JSON（数组形式），运行导出脚本生成一个 Excel，单份失败不中断整体、失败项记录原因；
4. 交付 Excel + 简要文字总结（人数、亮点、疑点）。

## 注意事项

- 中文简历常见两栏排版，纯文本提取可能交错——用分页标记和语义常识重组，不确定时如实标注。
- 简历中的照片、图标无文本价值，忽略即可。
- 解析结果仅供辅助参考，涉及招聘决策时提醒用户以原始简历为准。
