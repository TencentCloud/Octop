# 转正画像基线模板

> 用途：员工转正时，把简历分析阶段的信号层结论迁移成 AGM 员工画像基线。
> 这是「简历 → 画像」的衔接：迁移的是**结论**（层级预判 / 风险项 / 待验证点），
> 不是复制整份简历内容。

## 什么时候触发

候选人入职 → 试用期满，使用者明确说「转正」/「建画像」/「转员工画像」时触发。
**手动触发 + 确认**：AI 先展示要写入画像的基线信息，等使用者确认后再落盘，不自动写。

## 迁移流程

```
① 简历分析档案（resumes/{姓名}-简历分析-{年份}.md）
   └─ 招聘阶段逐步回填（事实底稿/信号层/面试问题/录用建议）
② 试用期补充观察（面试反馈/背调/试用表现）→ 回填到①，不新建
③ 转正 → 使用者说「建画像」
   ├─ 迁移①的信号层结论为画像基线
   ├─ 若已安装 agm-employee-analysis → 按其画像模板建完整画像
   ├─ 未安装 → 先按本模板建「基线画像」，标注待验证
   └─ ① 保留不删（候选历史），画像与档案并存
```

## 基线内容（从简历分析迁移）

| 迁移项 | 来源 | 说明 |
|--------|------|------|
| 基础信息 | 事实底稿 | 姓名 / 学历 / 毕业时间 / 入职日期 |
| 信号层层级预判 | AGM 信号层预判 | 简历阶段判的层级（置信度 ≤55%）|
| 风险项 | 风险信号 | 面试 / 试用要持续验证的点 |
| 待验证维度 | 面试观察 | 简历里「无法判定」、需答题或行为补充的维度 |

## 关键规则

1. **迁移的是结论，不是简历原文**——层级预判、风险项、验证点，不是照抄教育经历
2. **简历信号层置信度 ≤55%**——正式 AGM 答题数据出来后裁决修正（简历可能高估，如简历判 L3、答题判 L2）
3. **简历分析档案永不删除**——是候选历史 + 画像信号层来源，与画像并存
4. **未答题也可先建「基线画像」**——标注「待 AGM 答题验证」，不阻塞
5. **不读他人画像做对比**——候选人是外部人，画像库里不会有他，除非使用者明确要求对比

## 基线画像最小模板

```markdown
# {姓名} · 画像基线（转正）

> {岗位} | 当前能力层级: Lx（简历信号层预判，待答题验证）| 置信度: ≤55%

## 基础信息
- 姓名 / 学历 / 毕业时间 / 入职日期

## 信号层预判（来自简历分析）
- 最强信号：{简历里最硬的证据}
- 预判层级：Lx
- 主要风险项：{1-3 条}

## 待验证维度
- {简历里无法判定的维度，需答题/行为补充}

## 下一步
- 待补：AGM Gate / 正式题答题数据 → 裁决修正层级
```
