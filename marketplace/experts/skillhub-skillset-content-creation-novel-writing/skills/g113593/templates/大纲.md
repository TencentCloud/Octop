## 1. 作品基因（防跑偏锚点）

- **目标总字数 / 章节数**：**总字数 ÷ 单章字数的区间上限** = 章节数（默认 ÷2500，男频 ÷3000）。番茄长篇首签门槛较低（2 万字量级），但要进入平台正常分发需要更多字数，2-8 万之间基本拿不到量——别停在分发洼地。具体门槛以作家助手后台当前规则为准。
- **情绪标签**：[打脸爽文 / 极致虐恋 / 爆笑反套路 / 悬疑惊悚 / 治愈甜宠 / 脑洞大开]
- **一句话卖点**：用抖音标题体写，如“老公出轨后我嫁给他残疾小叔”
- **主角一句话人设**：[身份] + [反差点] + [欲望]
- **黄金开篇 50 字**：取自 `03-黄金开篇.md` 选中的版本
- **终极钩子**：读者追到最后想知道的那个答案，必须是具体画面或台词

## 3. 节奏蓝图（每 3 章一个情绪单元）

| 章节区间 | 情绪任务 | 必须完成的功能 | 章末落点要求 |
|---|---|---|---|
| 1-3 | 压-小扬-压 | 共情困境 / 第一个打破日常的事件 / 展示独特优点 | 窒息感或好奇感，暗示即将反击 |
| 4-6 | 小扬-压-爆 | 被迫行动 / 展示能力 / 拿到具体收益 / 引爆第一个雷 | 出现“更大的麻烦”或“神秘助力” |
| 7-9 | 压-小扬-压 | 明确对立方 / 出现有魅力配角 / 主角做出主动选择 | 抛出中期谜题，不解答 |
| 10-12 | 小扬-压-爆 | 引爆前期埋的雷 / 当众胜利 / 代价随之而来 | 旧平衡彻底打破 |
| 后续 | 按此循环 | | |

> 单元起点交替（1-3 以「压」开头，4-6 以「小扬」开头），因为上一单元预告的爆点在这一单元开头释放。“爆点逐轮放大”指**每个单元末端的爆点**规模变大，不是每一章递增——7-9 回到「压」是正常的情绪回撤。

## 4. 章节细纲（每章答四问）

1. **核心动作**（20 字以内，要具体，如“主角当众揭穿假千金身份”）
2. **情绪曲线**（😡 → 😤 → 😈 → 😱 → 😎，至少 3 个情绪点）
