# 药品分类参考 (Drug Categories Reference)

## 1. 高过敏风险药品 (High Allergy Risk Drugs)

### 一级高风险（必须追问过敏史）

| 类别 | 代表药物 | 过敏发生率 | 常见过敏表现 |
|------|---------|-----------|------------|
| 青霉素类 | 阿莫西林、氨苄西林、哌拉西林 | 1-10% | 皮疹、过敏性休克 |
| 头孢菌素类 | 头孢克洛、头孢呋辛、头孢曲松 | 1-3% | 皮疹、血清病样反应 |
| 碳青霉烯类 | 美罗培南、亚胺培南 | <1% | 皮疹 |
| 磺胺类 | 复方磺胺甲噁唑 | 3-6% | 皮疹、Stevens-Johnson |
| 别嘌醇 | 别嘌醇 | 2-3% | 严重皮肤反应(HLA-B*5801相关) |
| 卡马西平 | 卡马西平 | 5-10% | SJS/TEN(HLA-B*1502相关) |
| 造影剂 | 碘海醇、碘佛醇 | 1-3% | 类过敏反应 |
| 生物制剂 | 英夫利昔单抗等 | 变异大 | 输注反应、过敏 |

### 交叉过敏对照表

| 已知过敏药物 | 可能交叉过敏药物 | 交叉率 |
|------------|----------------|--------|
| 青霉素 | 头孢菌素（尤其一代） | 1-10% |
| 青霉素 | 碳青霉烯类 | <1% |
| 磺胺抗生素 | 含磺胺基团药物(呋塞米等) | 低但需注意 |
| 阿司匹林 | 其他 NSAIDs | 交叉反应常见 |
| 一种头孢 | 侧链相似的另一种头孢 | 需个案评估 |

## 2. 特殊人群注意药品

### 妊娠期禁用/慎用药品 (FDA Category D/X 或中国药监局标注)

| 类别 | 禁用/慎用药物示例 | 风险说明 |
|------|----------------|---------|
| 绝对禁用(X) | 甲氨蝶呤、华法林、异维A酸、米索前列醇、沙利度胺 | 致畸/流产 |
| 禁用(D级) | ACE抑制剂/ARB(中晚期)、他汀类、四环素类 | 胎儿毒性 |
| 慎用 | 抗癫痫药(丙戊酸钠)、某些抗抑郁药 | 需权衡利弊 |

### 哺乳期注意药品

| 类别 | 注意药物 | 说明 |
|------|---------|------|
| 避免使用 | 细胞毒药物、放射性药物、麦角生物碱 | 乳汁分泌、婴儿毒性 |
| 谨慎使用 | 苯二氮卓类、锂盐、甲硝唑 | 监测婴儿 |

### 儿童禁用/慎用药品

| 类别 | 药物 | 年龄限制 | 原因 |
|------|------|---------|------|
| 禁用 | 喹诺酮类 | <18岁 | 影响软骨发育 |
| 禁用 | 四环素类 | <8岁 | 牙齿着色、骨骼影响 |
| 慎用 | 阿司匹林 | <16岁(发热时) | Reye综合征 |
| 禁用 | 氯霉素 | 新生儿 | 灰婴综合征 |

### 老年人剂量调整药品

| 类别 | 代表药物 | 调整原因 |
|------|---------|---------|
| 肾排泄药物 | 地高辛、氨基糖苷类、万古霉素 | 肾功能减退 |
| 中枢神经药物 | 苯二氮卓类、阿片类 | 敏感性增加 |
| 抗凝药 | 华法林 | 出血风险增加 |

## 3. 常见药品禁忌症对照

| 禁忌疾病/状态 | 禁用/慎用药物 |
|--------------|-------------|
| 消化道溃疡/出血 | NSAIDs、阿司匹林、糖皮质激素 |
| 严重肝功能不全 | 对乙酰氨基酚(大剂量)、甲氨蝶呤、他汀类 |
| 严重肾功能不全 | NSAIDs、氨基糖苷类、万古霉素、两性霉素B |
| 哮喘(阿司匹林敏感) | 阿司匹林、NSAIDs |
| QT延长 | 大环内酯类、氟喹诺酮类、某些抗精神病药 |
| 重症肌无力 | 氨基糖苷类、氟喹诺酮类、β受体阻滞剂 |
| 青光眼(闭角型) | 抗胆碱药、某些抗抑郁药 |
| 前列腺增生 | 抗胆碱药 |
| 癫痫 | 降低癫痫阈值的药物(氟喹诺酮等) |
| G6PD缺乏 | 伯氨喹、呋喃妥因、磺胺类 |

## 4. 常见用药间隔影响的相互作用

| 药物A | 药物B | 推荐间隔 | 原因 |
|-------|-------|---------|------|
| 抗酸药/铝镁制剂 | 喹诺酮类 | ≥2小时 | 影响吸收 |
| 抗酸药/铝镁制剂 | 四环素类 | ≥2小时 | 影响吸收 |
| 铁剂 | 喹诺酮/四环素 | ≥2小时 | 螯合降低吸收 |
| 钙剂 | 甲状腺激素 | ≥4小时 | 影响吸收 |
| 质子泵抑制剂 | 氯吡格雷 | 需特殊管理 | 降低氯吡格雷活性 |
| 甲氧氯普胺 | 左旋多巴 | 避免合用 | 药效拮抗 |

## 5. 体检异常指标对用药的影响

| 异常指标 | 判断标准 | 影响的药物类别 | 用药建议 |
|---------|---------|-------------|---------|
| ALT/AST↑ | ALT>40 或 AST>40 U/L | 经肝代谢药物（对乙酰氨基酚、他汀类、甲氨蝶呤、抗真菌药） | 需减量或避免使用，监测肝功能 |
| Cr↑/eGFR↓ | Cr>104μmol/L 或 eGFR<60 | 经肾排泄药物（氨基糖苷类、万古霉素、NSAIDs、ACEI/ARB） | 根据 eGFR 调整剂量或换药 |
| WBC↓ | WBC<4.0×10⁹/L | 可能引起粒缺的药物（甲巯咪唑、氯氮平、某些化疗药） | 慎用或禁用可抑制骨髓的药物 |
| PLT↓ | PLT<100×10⁹/L | 抗凝药、抗血小板药（华法林、阿司匹林、氯吡格雷）、NSAIDs | 出血风险增大，需评估是否可用 |
| 血糖↑ | 空腹血糖>6.1mmol/L | 可升高血糖的药物（糖皮质激素、噻嗪类利尿剂、部分β受体阻滞剂） | 慎用可升高血糖的药物，需监测血糖 |
| 血脂异常 | TC/LDL-C 升高 | 他汀类等调脂药 | 可作为用药依据，注意合用药物的相互作用 |
| 低钾 | K<3.5mmol/L | 可引起低钾的药物（呋塞米、氢氯噻嗪）、地高辛（低钾增毒性） | 纠正低钾前慎用相关药物 |
| 高钾 | K>5.5mmol/L | ACEI/ARB、螺内酯、补钾制剂 | 禁用或慎用可升高血钾的药物 |
| INR↑ | INR>3.0 | 抗凝药（华法林）、与华法林相互作用的药物 | 抗凝过度，需调整抗凝药剂量 |
| 甲功异常 | TSH↑/↓，FT3/FT4异常 | 甲状腺激素、抗甲状腺药、胺碘酮、锂盐 | 影响甲状腺药物选择和剂量 |
| Hb↓ | Hb<120(男)/110(女) g/L | 可能加重贫血的药物（NSAIDs 致消化道出血、甲氨蝶呤） | 慎用可能引起失血或抑制造血的药物 |

## 6. 不予响应的话题识别

### 明确拒绝的话题关键词

| 话题类别 | 识别关键词 |
|---------|-----------|
| 药品价格 | 多少钱、价格、费用、医保报销比例、自费 |
| 药品库存 | 有没有货、库存、缺货、断货、能买到吗 |
| 药品采购 | 哪里买、购买渠道、网上购药、代购 |
| 药品消耗 | 消耗量、用量统计、采购量、进货 |
| 非医学用途 | 减肥药推荐(无医学指征)、美容注射 |
