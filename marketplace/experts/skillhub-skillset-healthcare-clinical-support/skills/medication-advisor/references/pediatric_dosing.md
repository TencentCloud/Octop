# 儿科体重剂量换算参考（内部工具，不直接输出模板给用户）

**用途**：作为 skill 底层判断依据。当用户咨询儿科用药且提供年龄或体重时，静默按本表算出目标剂量，直接给出处方式方案（如"Amoxicillin 30mg/kg po q12h × 7d，按体重 12kg 计 = 360mg（约 350-400mg）po q12h"）。**不向用户暴露"计算公式表"本体**，只输出计算结果。

---

## 通用换算原则

### 1. 剂量计算公式

**mg/kg 剂量**：`单次剂量 = 体重(kg) × mg/kg`
**mg/m² 剂量**（肿瘤药、糖皮质激素等）：`剂量 = BSA(m²) × mg/m²`

**体表面积（BSA）估算**（Mosteller 公式，最常用）：
```
BSA(m²) = √[身高(cm) × 体重(kg) / 3600]
```

**简化年龄→体重估算**（仅用于紧急场景，非精确）：
- <1 岁：体重(kg) ≈ (月龄 + 9) / 2
- 1-5 岁：体重(kg) ≈ 2 × 年龄 + 8
- 6-12 岁：体重(kg) ≈ (年龄 × 7 - 5) / 2

### 2. 单次剂量上限规则

儿童单次剂量按 mg/kg 计算后，**不得超过成人常规剂量**——即使按公式算出更高值。

### 3. 剂型可行性检查

- **片剂**：能否掰分？（划痕线的可分半，无划痕的建议改剂型）
- **胶囊**：能否拆开？（缓释、肠溶胶囊禁止拆开）
- **口服液/悬浮液**：优选，能精确到 0.1mL
- **注射剂**：需按毫升数换算浓度

### 4. 早产儿/新生儿特殊规则

- **矫正胎龄 <44 周**：多数药物 CL 下降，剂量降低或延长间隔
- **新生儿（<28d）**：肝酶未成熟（CYP3A4、UGT），代谢药需减量或改用其他类别
- **早产儿**：肾功能不成熟，经肾排泄药需按矫正胎龄分层

## Skill 内部使用规则

### 触发时机

- 用户明确提及儿科患者（年龄 <18 岁，或"孩子/儿童/婴儿"等称谓）
- 用户提供了体重或年龄，且咨询儿科可用药物

### 静默计算流程

1. **提取变量**：从用户消息/记忆中取年龄、体重（缺体重时用年龄推算式，标注"估算"）
2. **查表**：命中本表则按 mg/kg 或 mg/m² 计算
3. **上限校验**：单次剂量不得超过成人常规上限
4. **剂型可行性**：优选口服液/悬浮液；片剂需确认可分/可磨
5. **输出**：处方式表达 + 简要计算依据

### 输出格式示例

**有体重时**：
> Amoxicillin 25-45mg/kg/d 分 2-3 次，患儿 12kg 计 = 100-180mg q8h（普通感染）或 240-360mg q8h（AOM）。建议使用口服悬浮液（125mg/5mL 或 250mg/5mL），按具体规格换算 mL 数。以上依据 2021 AAP/IDSA 儿科感染指南。

**仅有年龄需估算体重时**（明确标注估算）：
> 3 岁患儿，体重估算约 14kg（按 2×年龄+8）。Amoxicillin 30mg/kg/次 q8h ≈ 420mg q8h。**实际处方前请核实体重**，肥胖或消瘦儿童估算偏差可达 ±30%。

**触发 PGx 联动提示**（如卡马西平场景）：
> Carbamazepine 儿童起始 10mg/kg/d 分 2-3 次，患儿 20kg 计 = 100mg bid，2 周内滴定至维持量。**⚠️ 用药前须完成 HLA-B\*15:02 检测**——东亚人群 SJS/TEN 风险显著升高。阴性可用，阳性者改用左乙拉西坦或丙戊酸（<2 岁除外）。

### 拒绝场景

- 缺关键信息（体重、年龄都缺）→ 门控追问："请提供患儿体重与年龄（缺体重时最少提供年龄用于估算），儿科剂量按 mg/kg 精确计算。"
- 剂量表未收录的药物 → 走 L3 大模型兜底 + 明确标注"未在标准剂量表核实"
