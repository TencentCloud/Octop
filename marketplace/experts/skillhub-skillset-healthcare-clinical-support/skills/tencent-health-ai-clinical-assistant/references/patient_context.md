# 已知历史信息累积规则

**用途**：同一会话多轮追加临床信息时，抽取并锁定"稳定型历史信息"，让后续每次推理自动纳入这些信息做**风险修饰**——避免建议不安全检查、避免忽略高风险修饰因素。

**术语说明**：本文件在内部规则库中沿用文件名 `patient_context.md`，但**面向医生的所有可见输出一律称"已知历史信息"**，不出现"patient_context""上下文"等技术术语。

**适用场景**：独立医生使用本 skill 分析同一患者的多轮输入。

---

## 一、稳定型历史信息字段清单

首次输入及后续每次输入时，扫描并抽取以下字段进入本轮会话的内部状态（不必输出结构化数据）：

| 字段 | 抽取来源 | 影响的推理修饰 |
|------|---------|--------------|
| 年龄 | 主诉/病史起首 | 疾病谱先验概率、影像学辐射考量 |
| 性别 | 主诉/病史起首 | 特殊人群规则触发 |
| 妊娠状态 | 现病史 / 月经史 | 药物/影像/放射禁忌 |
| 育龄女性未提供 β-hCG | 年龄 + 性别推断 + 未见 β-hCG | 强制补 β-hCG 到追问首位 |
| 肌酐 / eGFR | 化验 | 造影剂使用、肾排泄药物 |
| 肝功能（ALT/AST/胆红素/白蛋白） | 化验 | 肝代谢药物、肝性脑病风险 |
| 血小板 | 化验 | 出血风险、抗栓禁忌 |
| INR / PT | 化验 | 抗凝相关出血鉴别 |
| 抗凝 / 抗血小板用药史 | 既往史 / 用药史 | 出血性事件优先鉴别 |
| 免疫抑制状态 | 既往史（HIV/移植/化疗/长期激素） | 机会性感染必查 |
| 心功能 / EF | 既往超声或"心衰"病史 | 液体复苏、造影剂 |
| 药物过敏 | 过敏史 | 建议进一步检查时的造影剂/抗生素规避 |
| 主要基础病 | 既往史（DM / HTN / CKD / COPD / 冠心病 / 恶性肿瘤 / 肝硬化） | 鉴别谱先验修饰 |

---

## 二、已知历史信息摘要显示

每次输出报告时（**仅限未命中急症提示的常规分支**），在报告顶端、模板 A/B/C/D 之前显示一行"已知历史信息"，仅列本轮已积累的关键项：

> **命中急症提示时不显示此行**——急症报告只保留急症卡片，其他所有段落（含已知历史信息）均短路。历史信息在急症报告内部通过修饰规则**隐性生效**（例如抗凝史 → 出血鉴别写入必须通知；肌酐高 → 造影替代提示），但不再作为独立段落展示，避免抢占医生救治注意力。

```
🧾 已知历史信息：65 岁男性 · 肌酐 168 μmol/L（CKD-3期）· 华法林抗凝 · 磺胺过敏
```

若本轮无累积信息（首次输入且未提供任何稳定字段），省略该行。

---

## 三、已知历史信息驱动的推理修饰

历史信息抽取完成后，在第二步推理和输出建议时**自动应用**以下修饰规则：

### 3.1 肾功能相关

| 触发条件 | 修饰规则 |
|---------|---------|
| 肌酐 ≥ 133 μmol/L 或 eGFR < 60 | 建议 CT 造影 / DSA 时**必须**附加"造影剂肾病风险，需评估水化 + 或考虑替代影像（超声 / MR 非增强 / 平扫）" |
| 肌酐 ≥ 265 μmol/L 或透析患者 | 完全回避常规碘造影剂，改推荐替代影像 |
| eGFR < 30 | 建议进一步检查时**规避**肾排泄药物相关检查（如维生素/矿物质等外源负荷试验） |

### 3.2 抗凝 / 抗血小板

| 触发条件 | 修饰规则 |
|---------|---------|
| 华法林 / DOAC / 双抗 | 任何头痛/腹痛/关节肿胀鉴别中，**优先列入**出血性事件（颅内出血 / 消化道出血 / 关节积血） |
| 华法林用药 + INR 未查 | 强制补 INR 到追问清单首位 |
| 抗凝 + 突发神经症状 | 强制触发急症提示 #14（抗凝相关出血）卡片 |

### 3.3 育龄女性

| 触发条件 | 修饰规则 |
|---------|---------|
| 女性 + 15-49 岁 + 未提供 β-hCG | 任何下腹痛 / 阴道流血 / 晕厥鉴别，**必须**列入异位妊娠，追问清单首位放 β-hCG + 末次月经 |
| 女性 + 疑似妊娠 | 建议进一步检查时**规避**含辐射的影像（腹盆 CT / X 线），优先超声 / MR |

### 3.4 免疫抑制

| 触发条件 | 修饰规则 |
|---------|---------|
| HIV / 移植后 / 化疗中 / 长期激素 ≥ 20 mg/d prednisone 或等效 | 任何发热鉴别中**必须**扩展至机会性感染（PJP / CMV / 侵袭性真菌 / 结核） |
| 中性粒细胞 < 0.5 × 10⁹/L | 发热按发热性中性粒细胞减少症处理，急症提示触发经验性抗生素 1h 内 |

### 3.5 肝功能

| 触发条件 | 修饰规则 |
|---------|---------|
| 白蛋白 < 30 + PT 延长 或肝硬化史 | 消化道出血鉴别优先食管胃底静脉曲张；建议加做腹部超声评估门静脉高压 |
| 明显黄疸 / 凝血异常 | 建议进一步检查时规避肝代谢药物的负荷试验 |

### 3.6 药物过敏

| 触发条件 | 修饰规则 |
|---------|---------|
| 碘造影剂过敏 | 建议 CTA / 增强 CT 时明确注明"该患者碘过敏，需改用 MR / 非增强影像 / 术前预防用药方案（由主管医师决定）" |
| 抗生素类过敏 | 建议进一步检查时不推荐相关药物皮试外的经验性用药 |

## 四、已知历史信息冲突处理

多轮输入间历史信息出现冲突时：

1. **后覆盖前**：明确纠正型描述（"实际肌酐是 90，之前的化验单是别的患者"）→ 用新值覆盖，旧值废弃。
2. **补充而非覆盖**：新增字段不冲突时并入。
3. **时间戳提示**：数值型指标（肌酐、Hb 等）若两次输入均给出且不同，输出时提示"本轮已知历史信息中 [字段] 前后值不一致（X → Y），已采用最新值 Y；若为同一患者不同时间点动态变化，请核对"。

---

## 五、边界

- 已知历史信息是**内部推理状态**，不作为独立"结构化字段块"输出（避免变成 JSON 冗余）。
- 只以"🧾 已知历史信息"一行 + 修饰体现在建议文本里的方式呈现。
- 会话结束或明确切换新患者（用户说"换一个患者"/"新病例"）→ 内部状态清零。

## 六、示例

**首次输入**：男，65岁，肌酐 168 μmol/L，长期华法林抗凝，突发头痛 2 小时。

内部抽取到的历史信息：`{age: 65, sex: M, creatinine: 168, ckd_stage: 3, anticoag: warfarin}`

**输出报告顶部**：
```
⏱ 急症提示 — 抗凝相关出血 / 蛛网膜下腔出血
├─ 时间窗：立即 / SAH 6h 内 CT
├─ 立即动作：
│  ① 立即头颅平扫 CT
│  ② 查 INR + 血常规 + 肝肾功
│  ③ 备拮抗剂（Vit K + PCC）待神外评估
└─ 必须通知：神经外科 / 血液

🧾 已知历史信息：65 岁男性 · 肌酐 168 μmol/L（CKD-3期）· 华法林抗凝

🔍 疑似诊断分析
...
| **建议进一步检查** | • 头颅 CT 平扫（首选，避免造影剂）<br>• 若需 CTA 明确血管病变：**该患者 CKD-3 期，需评估水化方案 + 造影剂剂量最小化，或改 MRA 替代**<br>• INR / 凝血四项 |
```

---

## 七、注意事项

1. 已知历史信息抽取只针对**用户明确提供**的信息，不做临床推断（例如不会因为"老年男性"就臆测有 CKD）。
2. 修饰规则只影响**建议措辞和优先级**，不改变疾病谱本身——避免"因为患者有 CKD 就不考虑心梗"这种荒谬修饰。
3. 若某条修饰规则的触发依赖被 R01（依据溯源）判定为无效（如引用了不存在的化验），则该修饰不生效。
