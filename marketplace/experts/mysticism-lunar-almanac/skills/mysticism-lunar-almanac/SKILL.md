# 黄历择吉工作流

你现在要完成一份黄历择吉/择日任务。你已安装以下 Skill，请按步骤串联使用：

## 步骤 1：公农历转换与黄历主驱动

使用 **中国农历黄历吉凶查询** 完成：

- 将用户输入的公历日期（含特殊日期/未来日期）转换为农历，处理闰月
- 输出该日的基础黄历字段：天干地支、生肖、宜忌、24 节气精确到秒级
- 作为整个流程的主驱动数据源

输出物：基础黄历字段表。

## 步骤 2：黄道吉日与传统节日补全

使用 **Chinese Calendar Cn** 完成：

- 在步骤 1 基础上叠加黄道吉日判定 + 传统节日标识
- 对中外用户提供双语描述，覆盖节气 / 生肖 / 黄道吉日 / 传统节日 / 天干地支
- 标记当日是否落在重要传统节日窗口

输出物：黄道吉日与节日补全报告。

## 步骤 3：工程化择日复算

使用 **Lao Huangli** 完成：

- 当用户需要在一段日期区间内挑选最合适的日子（如嫁娶、动土、开市），调用工程化可复现计算流程
- 批量计算区间内每天的择日 / 宜忌 / 冲煞 / 干支 / 节气字段
- 按用户事项类型筛选与排序，输出 Top N 候选日期

输出物：择日候选日期排序表。

## 步骤 4：彭祖百忌与神煞方位深读

使用 **Daily Horoscope** 完成：

- 对步骤 3 的候选日期逐日深读：彭祖百忌 + 神煞方位 + 吉利方位
- 输出当日具体到时辰的吉凶提示
- 给出仪式所宜方位（如喜神/财神/福神方位）

输出物：候选日期的彭祖百忌 + 神煞方位详表。

## 步骤 5：节日民俗与跨文化对照

使用 **Festival Query** 完成：

- 当事项涉及海外华人/跨文化场景，将候选日期与中国农历传统节日 + 24 节气 + 欧美主流节日做对照
- 标记是否与外国节日冲突或重合
- 输出跨文化日期解读

输出物：跨文化节日民俗对照表。

## 步骤 6：佛道多历对照（按需）

使用 **1coos Calendar Cn** 完成：

- 当事项涉及佛事/道教节日（如供佛、斋戒、法会），叠加佛历 + 道历对照
- 标识候选日期在佛历/道历中的特殊属性（如观音诞、佛诞、三元日）
- 给出宗教民俗维度的最终建议

输出物：佛历/道历多历对照说明。

## 最终输出

将以上步骤的结果整合为完整的黄历择吉成果包，交付以下文件：

1. **基础黄历字段表**：当日干支、生肖、宜忌、节气
2. **节日补全报告**：黄道吉日判定 + 传统节日标识
3. **择日候选排序**：区间批量计算后的 Top N 候选
4. **彭祖百忌深读**：候选日期的神煞方位与时辰吉凶
5. **跨文化节日对照**（按需）：中外节日冲突/重合标记
6. **佛道多历说明**（按需）：宗教民俗维度的特殊属性
