# resume-screening · 简历分析器（通用版）

> v1.0.0 | 2026-09-18

把「简历 → 面试 → 转正」串成一条有标准、可复用、可归档的流水线。

## 它做什么

1. **招聘前**：引导你存档岗位诉求（Job Card）——岗位职责 + 硬门槛 + **否决项（完全自定义）**
2. **招聘中**：每份简历对着 Job Card 分析，出「面否/可面」判断 + 线上/线下面试问题清单
3. **转正时**：把简历分析的信号层结论迁移成员工画像基线，衔接 AGM 能力体系

## 快速开始

### 第一次用（会先确认信息，再执行）

1. 对 AI 说「我要招 XX 岗位，帮我搭招聘标准」，或直接丢一份简历说「分析下这个」
2. AI 发现你还没有这个岗位的 Job Card，会先引导你确认：
   - 岗位职责（这个岗位到底要人干什么）
   - 硬门槛（学历/经验/证书）
   - **否决项（你自定义的「一票否决」条件，skill 不预设）**
   - 软要求 + 岗位认知层级
3. 确认后存档，之后每份简历都对着这张卡分析，口径不漂移

### 之后每次分析

直接把简历（PDF/图片/文字/招聘平台截图）丢给 AI 说「分析下这个」，AI 自动读取对应岗位的 Job Card 作为匹配基准。

## 目录结构

```
resume-screening/
├── SKILL.md                        # 主流程（初始化/分析/转正闭环）
├── README.md                       # 本文件
├── references/
│   ├── agf-analysis-logic.md       # AGF 底层分析逻辑（12 格层级/8 维/行为证据）
│   ├── job-card-template.md        # Job Card 模板（岗位诉求 + 自定义否决项）
│   └── profile-baseline-template.md # 转正画像基线模板
├── scripts/
│   └── resume_to_text.py           # 简历 PDF/图片 → 干净文本（含平台水印过滤）

```

## 依赖

- **简历转文字脚本**：`pdfplumber`（纯 Python，PDF 文本层提取 + 水印过滤）
  ```bash
  pip install pdfplumber
  ```
- **扫描版 PDF / 图片 OCR**（可选）：`markitdown`
  ```bash
  pip install 'markitdown[all]'
  ```

## 与 agm-employee-analysis 的衔接（可选）

- 本 skill 独立可用，不强依赖其他 skill
- 如果你也安装了 **agm-employee-analysis**（AGM 员工画像分析），转正时本 skill 会按它的完整画像模板建档
- 没装的话，转正时先建「基线画像」，标注待 AGM 答题验证

## 三个设计要点

1. **Job Card 前置**：没有岗位诉求不分析简历，先确认再动手，口径不漂移
2. **否决项完全自定义**：不预设任何「一票否决」条件（不硬编码学历门槛等），由你定义
3. **转正→画像闭环**：简历分析的结论不会用完即弃，转正时自动迁移成员工画像基线
