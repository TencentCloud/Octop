# 紫微斗数工作流

你现在要完成一次紫微斗数命盘分析任务。你已安装以下 Skill，请按步骤串联使用：

## 步骤 1：标准化排盘（输入层）

使用 **Zwds Openclaw** 完成：

- 通过 zwds-cli（Node + iztro 2.5.0）接收用户出生信息
- 输出结构化 JSON 命盘：十二宫 + 十四主星 + 辅星 + 四化 + 大限/小限
- 作为下游所有解读 skill 的统一数据源（解耦排盘与解读）

输出物：结构化 JSON 命盘数据。

## 步骤 2：紫微主驱动通排

使用 **Ziwei Fortune** 完成：

- 基于步骤 1 的命盘，运行经典体系解读：
  - 命宫主星定盘 / 十二宫格局 / 四化飞星基础走向
- 用确定性算法 + LLM 解读，输出标准化通排基线

输出物：紫微通排报告（基线版）。

## 步骤 3：精美咨询报告导出

使用 **Ziwei Doushu** 完成：

- 在步骤 2 通排基础上，按北京标准排盘规则做交付级精装
- 输出排版友好的咨询报告（适合直接给客户/朋友查看）
- 强调可读性与视觉呈现

输出物：交付级紫微咨询报告。

## 步骤 4：北派飞星派专项

使用 **Ziwei Dou Shu** 完成：

- 切换到北派飞星派视角，对步骤 1 命盘做飞星派专项解读
- 基于 iztro 开源库 + 真太阳时校正，分析来因宫等飞星核心概念
- 输出飞星派独有的命格判定

输出物：北派飞星派专项报告。

## 步骤 5：紫微八字融合校验

使用 **Destiny Fusion Pro** 完成：

- 将紫微斗数结论与八字信息放到同一咨询流程中交叉验证
- 标记跨体系一致结论（高置信度）与差异点（需谨慎解释）
- 输出旗舰级综合咨询视角

输出物：紫微八字融合校验报告。

## 步骤 6：双人合盘配对（输出层，按需）

使用 **Zwds Hepan Openclaw** 完成：

- 当用户需求是婚恋/合伙关系，调入对方出生信息做双人合盘
- 输出 0-100 匹配分 + 维度分项（事业 / 财帛 / 夫妻 / 子女等）+ 命中数
- 给出婚恋决策辅助意见

输出物：双人合盘报告（按需）。

## 最终输出

将以上步骤的结果整合为完整的紫微斗数成果包，交付以下文件：

1. **结构化 JSON 命盘**：十二宫 + 十四主星 + 四化 + 大限
2. **通排基线报告**：经典体系下的命宫主星与格局判定
3. **交付级咨询报告**：精美排版可直接呈现
4. **飞星派专项**：北派飞星派的来因宫与飞星深读
5. **三派对照**：三合 / 飞星 / 占验派的一致与差异
6. **双人合盘**（按需）：匹配分 + 维度分项 + 命中数
