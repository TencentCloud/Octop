# 营养餐规划工作流

你现在要为用户制定并落地一份个性化营养餐方案（覆盖减脂/增肌/控糖/孕期/抗炎/慢病管理）。你已安装以下 Skill，请按步骤串联使用：

## 步骤 1：科学营养目标制定（处理层）
使用 **Nutrition Advisor** 完成：
- 收集用户基础信息：年龄、性别、身高体重、体脂率、活动水平、生理状态（孕期/经期/慢病）、目标（减脂/增肌/控糖/抗炎）
- 计算 TDEE / BMR，给出热量目标
- 分配宏量营养素（蛋白质 / 碳水 / 脂肪），按目标场景调整：
  - 减脂：高蛋白 + 适度赤字
  - 增肌：盈余 + 蛋白 1.6-2.2g/kg
  - 控糖：GI/GL 模式
  - 抗炎：抗炎食材偏向
  - 女性生理周期：按卵泡/排卵/黄体/经期分阶段调整
- 必要时启用碳水循环、间歇性断食、反向饮食

输出营养目标文档（TDEE + 宏量素 + 场景特化策略）。

## 步骤 2：周膳食全流程规划（处理层）
使用 **Feast** 完成：
- 基于步骤 1 的营养目标生成 7 天周菜单（早 + 午 + 晚 + 加餐）
- 自动汇总成本周购物清单（按超市分区组织）
- 同步营养追踪：每餐与每日热量、宏量素、微量元素分布
- 配合烹饪灵感与文化主题（中式 / 日式 / 地中海 / 低碳水等）
- 沉淀膳食历史，形成长期数据库

输出 7 天周菜单 + 购物清单 + 营养追踪表 + 烹饪灵感卡。

## 步骤 3：中式饮食三餐推送（处理层 / 中文用户）
对中文用户，使用 **Healthy Meal Reminder** 在周菜单基础上做本土化：
- 遵循《2022 中国居民膳食指南》八大准则
- 每日三餐 + 下午茶定时推送，每餐给出 ABC 三方案（备选）
- 按餐盘结构标注配比（主食 / 蛋白 / 蔬菜 / 油脂）
- 按季节推送低卡食谱与时令食材
- 含饮水管理、运动搭配建议、周报

输出本土化三餐推送 SOP + ABC 备选方案 + 周报模板。

## 步骤 4：食谱设计与厨师对话优化（处理层）
对周菜单中的具体菜品，使用 **Chef Dialog Recipe** 走对话式食谱生成：
- 厨师视角生成完整食谱（食材 / 步骤 / 时间 / 火候 / 调味）
- AI 分析审查（步骤简化 / 食材替换 / 调味升级 / 营养优化）
- 综合优化为可执行的家庭做法
- 适配用户的厨房条件（有无烤箱/空气炸锅/电饭煲）

输出可执行食谱集 + 厨房适配版本。

## 步骤 5：中式菜谱库匹配（处理层 / 中文用户）
对周菜单中的中式菜品，使用 **China Recipe** 完成：
- 从中国菜谱大全检索匹配（覆盖各菜系家常菜与传统做法）
- 替换用户不爱吃的菜品（如不吃海鲜 → 同等蛋白的禽类）
- 适配中文用户食材习惯与口味偏好
- 给出区域特色版本（川 / 粤 / 鲁 / 淮扬 / 江浙等）

输出中式菜谱推荐清单 + 替换方案。

## 步骤 6：每日卡路里日志与执行追踪（输入层 / 输出层）
使用 **Calorie Tracker** 完成日常追踪：
- 每日记录卡路里、蛋白质摄入、体重
- 数据存储于本地 SQLite，自动生成每日汇总
- 设定目标（减脂赤字 / 增肌盈余 / 控糖区间）
- 周末输出汇总报告：达标率 / 体重曲线 / 蛋白达标率
- 结合步骤 1 的营养目标做偏差预警

输出每日卡路里日志 + 周/月汇总报告 + 偏差预警。

## 最终输出
将以上步骤的结果整合为完整的营养餐规划成果包，交付以下文件：
1. **营养目标文档**：TDEE + 宏量素 + 场景特化策略
2. **周菜单包**：菜单 + 购物清单 + 营养追踪表 + 烹饪灵感
3. **本土化三餐 SOP**（按需）：ABC 备选 + 季节食谱 + 周报
4. **食谱集**：可执行家庭做法 + 厨房适配版
5. **中式菜谱推荐**（按需）：菜系特色版 + 替换方案
6. **执行追踪**：每日卡路里日志 + 周/月汇总 + 偏差预警

> ⚠️ 与「健身训练计划」包联动：增肌期建议把卡路里日志的蛋白达标率与训练计划的渐进超负荷数据交叉看；与「健康数据分析」包联动：把体重/血糖/体脂数据接入综合分析。
