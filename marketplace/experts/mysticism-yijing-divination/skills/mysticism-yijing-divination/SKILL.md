# 易经起卦工作流

你现在要完成一次易经起卦/断卦任务。你已安装以下 Skill，请按步骤串联使用：

## 步骤 1：易经主驱动起卦

使用 **易经起卦** 完成：

- 接收用户问题，按用户问题执行起卦流程，提取卦象、卦名、卦辞、爻位与变爻
- 起出本卦、互卦、变卦的完整结构
- 用 AI Oracle 给出诗性诠释作为初步定调

输出物：本卦/互卦/变卦三层卦象 + 初步诗性诠释。

## 步骤 2：京房纳甲六爻深断（文王卦）

使用 **Liuyao Yijing** 完成：

- 在步骤 1 的卦象基础上，按京房纳甲体系装卦：天干地支 / 世应 / 六亲 / 六神
- 确定用神（与问题相对应的爻）
- 用旺衰生克制化判定吉凶应期

输出物：装卦详细字段 + 用神断卦结论 + 应期推断。

## 步骤 3：梅花易数体用解读

使用 **Meihua Yishu Divination** 完成：

- 同一问题切换到邵雍《梅花易数》体系，按时间/数字/文字三种起卦法重新起卦
- 用体用五行生克判定吉凶
- 与步骤 2 的六爻结论交叉对照

输出物：梅花易数解读 + 与六爻的异同分析。

## 步骤 4：小六壬日常吉凶速断

使用 **Xiaoliuren** 完成：

- 当用户问题偏向"近期日常事项"（出门/见面/找东西），用道传小六壬快速起卦
- 落入大安/留连/速喜/赤口/小吉/空亡六宫之一
- 给出简洁吉凶判断 + 时间窗口

输出物：小六壬六宫断语 + 时间窗口建议。

## 步骤 5：卦象哲学决策辅助

使用 **Yi** 完成：

- 跳出"占卜"层，回到《易经》本经的卦辞、爻辞与彖象传
- 以 64 卦的哲学义理对用户问题做决策辅助而非吉凶预测
- 提炼当下处境的"应当怎么做"的策略层建议

输出物：卦辞爻辞决策建议。

## 步骤 6：多起卦法 + 三层义理融会

使用 **Cyber Iching Master** 完成：

- 综合前几步结论，用三层义理（数字占卜 + 八字排盘融合 + 卦象义理）做最终汇总
- 当步骤 2-5 出现冲突时，提供跨流派对照说明
- 给出最终统一的解读结论

输出物：跨流派融合的最终解读。

## 最终输出

将以上步骤的结果整合为完整的易经起卦成果包，交付以下文件：

1. **主驱动卦象**：本卦/互卦/变卦三层结构
2. **六爻断卦报告**：京房纳甲装卦 + 用神 + 应期
3. **梅花易数解读**：体用生克 + 与六爻的异同
4. **小六壬速断**（按需）：日常事项的六宫断语
5. **卦辞决策建议**：易经本经哲学义理层的策略建议
6. **跨流派融合结论**：三层义理统一的最终解读
