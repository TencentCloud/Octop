# 报告撰写规范

## 1. 交付形式选择

| 场景 | 交付物 |
|---|---|
| 用户只是随口问、想快速看结果 | 直接在对话中给结构化文字结论（四柱 + 日主强弱 + 喜用 + 未来 3–5 年要点） |
| 用户给了完整信息（生辰+姓名+地点+经历） | 生成 HTML 报告并预览 |
| 用户要可保存/转发的成品 | HTML 报告（可再转 PDF） |

## 2. 生成 HTML 报告的标准流程

```bash
PY="C:/Users/hp/.workbuddy/binaries/python/envs/default/Scripts/python.exe"
SK="C:/Users/hp/.workbuddy/skills/bazi-fortune/scripts"
OUT="<用户工作目录>"

# 1) 排盘
"$PY" "$SK/bazi.py" --datetime "1995-06-15 14:30" --gender male --place 武汉 \
     --name 李梓涵 --event "2014:考上大学" --event "2020:跳槽" \
     --family "工薪家庭" --years 30 --out "$OUT/chart.json" --text

# 2) 撰写 narrative.json（键见下表，值为纯文本段落，可含标点与换行）
# 3) 渲染
"$PY" "$SK/render_report.py" "$OUT/chart.json" -n "$OUT/narrative.json" -o "$OUT/八字命理报告.html"
```

narrative.json 键位（全部可选，缺失则该段落留空）：

| 键 | 出现章节 | 内容要求 |
|---|---|---|
| `summary` | 二 · 四柱命盘下 | 命局总评 150–250 字：日主、月令、格局、整体气象 |
| `events` | 一 · 基本信息下 | 结合用户提供的人生事件做复盘与定盘说明 |
| `personality` | 三 · 日主强弱下 | 性格与天赋 150–250 字 |
| `family` | 五 · 神煞与地支关系下 | 家庭条件、早年环境、六亲参断 |
| `career` | 七 · 分项详批 | 事业与财运，含行业方向建议 |
| `love` | 七 · 分项详批 | 婚姻与感情 |
| `health` | 七 · 分项详批 | 健康养生提醒（不得诊断疾病） |
| `forecast` | 六 · 大运流年下 | 未来运势详批，逐年/逐运写，重点写当前运与未来 3–5 年 |
| `name` | 八 · 姓名分析下 | 姓名与八字喜用的配合度点评 |
| `advice` | 九 · 开运建议 | 方位、行业、颜色、时机、注意事项 |

## 3. 未来运势的写法

1. 先明确**当前所处大运**（脚本 `dayun` 中 `start_year <= 今年 <= end_year` 的那一条），指出该运的用忌性质与整体基调。
2. 再逐年写**未来 3 年**（脚本 `liu_nian` 中 `hits` 字段已给出流年支与命局四支的冲合刑害）：
   - 流年十神定事件性质（见 bazi_theory.md 第 2 节）；
   - `hits` 定受影响宫位（冲日支→自身与婚姻，冲月支→事业与父母，冲时支→子女与成果）；
   - `ben_ming_nian` / `fan_taisui` 为真的年份提示"宜守不宜攻"。
3. 最后给**3–10 年中期趋势**，指出下一柱大运切换的年份与切换前后的风格差异。
4. 每条运势后尽量给一条**可执行动作**（如"该年适合考证而非跳槽"），避免只给结论。

## 4. 质量自查清单

- [ ] 四柱与用户提供生辰一致，且已说明真太阳时/夏令时是否校正。
- [ ] 时辰未知时，明确标注并给出 `--hour-scan` 定盘建议，不假装确定。
- [ ] 强弱判定与喜用神有数据支撑（引用 ratio/得令），不是凭感觉。
- [ ] 分项覆盖用户真实关心的问题（用户提到了感情就重点写感情）。
- [ ] 用户提供的成长经历被引用并呼应，不是空泛套话。
- [ ] 无"必然/注定"类绝对化表述；无疾病、死亡、灾祸断言。
- [ ] 结尾保留免责声明。
- [ ] HTML 报告已用 present_files 打开预览。

## 5. 常见失败与处理

| 现象 | 处理 |
|---|---|
| 姓名某字康熙笔画缺失 | 用 `--stroke 字=数字` 补，或在报告中标注该字未参与五格计算 |
| 地点未匹配到坐标 | 用 `--lon 经度` 直接指定；报告中注明按东经 120° 计算 |
| 时间只知道日期不知道时辰 | 先出三柱结论 + `--hour-scan` 表，请用户补充事件或时辰 |
| 用户要求改名/取名 | 依据喜用五行给方向性建议，并提示姓名只是辅助因素 |
| 用户要求合婚/择日 | 说明本技能主要覆盖个人命理，合婚需双方完整八字；择日可另做 |
