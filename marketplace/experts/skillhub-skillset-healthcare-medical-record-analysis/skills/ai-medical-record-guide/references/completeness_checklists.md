## 门诊病历必填清单

| 字段名 | 必填级别 | 默认值 | 缺失处理 |
|--------|----------|--------|---------|
| 就诊时间 | P0 | 当前时间 | 自动填充 |
| 科室 | P0 | — | 必须提供 |
| 主诉 | P0 | — | ⛔ 缺失则阻断，追问 |
| 现病史 | P0 | — | ⛔ 缺失则阻断，追问 |
| 过敏史 | P0 | "否认药物、食物过敏史" | 默认填写但标记需确认 |
| 既往史 | P1 | — | 🟡 缺失则追问 |
| 体格检查（至少含生命体征）| P0 | — | ⛔ 至少T/P/R/BP四项 |
| 辅助检查 | P2 | — | 🔵 无检查则留空 |
| 初步诊断 | P0 | — | ⛔ 必须提供 |
| 处置/处方 | P0 | — | ⛔ 至少一项处置或处方 |
| 医师签名位 | P0 | — | 自动填充占位符 |

### 门诊病历完整性评分参考

- **甲级**（≥95%）：P0全部完成 + P1完成≥80%
- **乙级**（80%-94%）：P0全部完成 + P1完成50-79%
- **丙级**（<80%）：P0有缺失 或 P1完成<50%

## 首次病程记录必填清单

首次病程记录要求**三段式结构**：

### 第一段：病例特点（必填要素）

| 要素 | 级别 | 说明 |
|------|------|------|
| 患者基本信息摘要 | P0 | 姓名/性别/年龄/入院原因 |
| 主诉归纳 | P0 | 简明扼要 |
| 主要阳性体征/检查 | P0 | 支持诊断的关键证据 |
| 重要阴性发现 | P1 | 有鉴别价值的阴性结果 |
| 既往相关病史 | P1 | 与本次入院相关的既往情况 |

### 第二段：拟诊讨论（必填要素）

| 要素 | 级别 | 说明 |
|------|------|------|
| 初步诊断 | P0 | 与入院诊断一致 |
| 诊断依据 | P0 | 逐条列出支持诊断的证据 |
| 鉴别诊断 | P0 | 至列3个需排除的疾病及理由 |
| 鉴别要点 | P1 | 各鉴别的关键区分点 |

### 第三段：诊疗计划（必填要素）

| 要素 | 级别 | 说明 |
|------|------|------|
| 完善检查计划 | P0 | 还需要做什么检查 |
| 治疗方案 | P0 | 药物/手术/护理等 |
| 护理级别 | P1 | 特/一/二/三级 |

## 病案首页必填清单

### 必填区块（按国家卫健委《住院病案首页填写质量规范》）

| 区块 | 必填字段数 | 关键必填项 |
|------|-----------|-----------|
| 患者基本信息 | 12项 | 姓名/性别/年龄/身份证号/出生地/现住址 |
| 门诊/住院信息 | 8项 | 科别/病房/入院日期/出院日期/住院天数 |
| 诊断信息 | ≥3项 | 门诊诊断/入院诊断/出院诊断（主+其他）|
| 手术操作 | 如有则全填 | 手术名称/日期/麻醉/术者/切口愈合 |
| 费用信息 | 12分类 | 总费用+11项分类费用 |
| 质控信息 | 4项 | 质控医师/日期/评分/等级 |

### 病案首页质量控制要点

| 检查项 | 标准 | 不合格后果 |
|--------|------|-----------|
| 主要诊断选择正确 | 符合主要诊断选择原则 | 影响DRG分组 |
| ICD编码准确 | 编码与诊断一致 | 影响医保结算 |
| 手术级别正确 | 一/二/三/四级手术准确归类 | 影响医疗质量统计 |
| 费费分类无误 | 12类费用归入正确类别 | 影响成本核算 |
| 时间逻辑一致 | 入院≤出院，手术在住院期间 | 病历真实性存疑 |
