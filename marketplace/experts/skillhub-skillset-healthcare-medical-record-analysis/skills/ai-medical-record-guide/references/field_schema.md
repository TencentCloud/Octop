## 模块 2: 门诊 — 病史记录

| 字段名 | 英文 Key | 数据类型 | 必填级别 | 校验规则 | 示例值 |
|--------|----------|---------|----------|---------|--------|
| 主诉 | `chief_complaint` | text | P0 | 非空，含症状+时间 | 反复胸痛3天 |
| 现病史 | `present_illness` | text | P0 | 非空≥20字，含起病/演变/伴随症状 | （详见示例）|
| 既往史 | `past_history` | text | P1 | 结构化记录慢性病/手术/输血 | 高血压5年 |
| 过敏史 | `allergy_history` | object[] | P0 | 含过敏原+反应类型 | 见下方子表 |
| 家族史 | `family_history` | text | P2 | 记录遗传/家族聚集性疾病 | 父亲糖尿病 |

### 过敏史子结构
```json
{
  "allergy_history": [
    {
      "allergen": "青霉素",
      "type": "药物",
      "reaction": "皮疹"
    }
  ]
}
```

过敏类型枚举：`药物` / `食物` / `其他`

## 模块 3: 门诊 — 体格检查

| 字段名 | 英文 Key | 数据类型 | 必填级别 | 校验规则 | 示例值 |
|--------|----------|---------|----------|---------|--------|
| 收缩压 | `sbp_mmhg` | number | P0 | 60-300 mmHg | 150 |
| 舒张压 | `dbp_mmhg` | number | P0 | 30-200 mmHg | 95 |
| 心率 | `hr_bpm` | number | P0 | 30-250 bpm | 88 |
| 体温 | `temp_c` | number | P0 | 35.0-42.0°C | 36.5 |
| 呼吸频率 | `rr_bpm` | number | P0 | 8-40 bpm | 18 |
| 身高 | `height_cm` | number | P2 | 50-250 cm | 175 |
| 体重 | `weight_kg` | number | P2 | 3-300 kg | 70 |
| BMI | `bmi` | number | P2 | 10-60 | 22.9 |
| 专科体查 | `specialty_exam` | text | P1 | 按科室可变格式 | 心尖区SM 2/6级杂音 |

### 血压联合校验（P0 规则）
- 收缩压必须 > 舒张压
- 若 SBP ≥140 或 DBP ≥90 → 标注 `[异常]`
- 若 SBP <90 或 DBP <60 → 标注 `[异常]` + 触发低血压警示

### 风险评估子模块

#### 压疮风险（Braden评分）

| 子项 | 分值范围 | 说明 |
|------|---------|------|
| 感觉感知 | 1-4 | 对压力相关不适的感受能力 |
| 潮湿程度 | 1-4 | 皮肤暴露于潮湿的程度 |
| 活动能力 | 1-4 | 身体活动的程度 |
| 移动能力 | 1-4 | 改变和控制体位的能力 |
| 营养摄取 | 1-4 | 进食状态 |
| 摩擦力和剪切力 | 1-3 | 总分6-23分 |

**判定**：≤12分 = 高危；13-14分 = 中危；15-18分 = 低危；19-23分 = 无危

#### 跌倒风险（Morse评分）

| 子项 | 分值 | 说明 |
|------|------|------|
| 跌倒史 | 0/25 | 近3月内有跌倒=25分 |
| 超过1个疾病诊断 | 0/15 | 是=15分 |
| 行走辅助 | 0/30 | 轮椅/卧床=30；拐杖=15；无=0 |
| 静脉输液/肝素锁 | 0/20 | 使用=20分 |
| 步态 | 0/20 | 弱/ impaired =20 |
| 精神状态 | 0/15 | 过高估自己能力=15分 |

**判定**：≥45分 = 高危；25-44分 = 中危；0-24分 = 低危

#### VTE风险（Caprini评分）

包含患者相关因素（年龄/体重/BMI/手术/妊娠等）和疾病相关因素（感染/心衰/卒中/肿瘤等），详见专科 routing matrix。

**判定**：0-1分 = 低危；2分 = 中危；3-4分 = 高危；≥5分 = 极高危

#### 营养风险（NRS2002评分）

| 子项 | 分值 |
|------|------|
| 营养受损 | 0-3分 |
| 疾病严重度 | 0-3分 |
| 年龄调整 | 年龄>70岁加1分 |

**判定**：总分≥3分 = 有营养风险
