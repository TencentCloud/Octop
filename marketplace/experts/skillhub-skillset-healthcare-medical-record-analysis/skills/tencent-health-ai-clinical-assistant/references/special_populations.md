# 特殊人群扩展规则（R04 分支规则集）

**用途**：`references/validation_rules.md` 中 R04（红旗遗漏检测）的**特定人群补充规则**。这些规则在已知历史信息抽取出对应特征时自动生效，扩展 R04 的检测范围。

**核心思想**：某些疾病在通用人群中低频，但在特定人群中是**高频且高危**的鉴别项，必须强制列入。

---

## 一、育龄女性（15-49 岁 女性）

### SP01 — 育龄女性 + 下腹痛 / 阴道流血 / 晕厥

**强制列入鉴别**：
- **异位妊娠**（首位，无论其他表现如何）
- 卵巢囊肿蒂扭转
- 盆腔炎急性发作
- 黄体破裂

**强制追问**：末次月经日期、避孕方式、β-hCG 是否已查

**若 β-hCG 未查** → 追问清单第 1 位固定为 β-hCG + 盆腔超声

**急症提示触发**：如果 + 休克征 / 晕厥 → 触发急症提示 #12（异位妊娠破裂）

---

## 二、老年人（≥ 65 岁）

### SP02 — 老年 + 谵妄 / 意识改变（急性 / 新发）

**强制列入鉴别（四联必查）**：
- **感染**（尿路 / 肺部 / 胆道 / 皮肤软组织 / 中枢）— 老年感染常无高热
- **药物副作用 / 药物相互作用**（尤其抗胆碱能药、苯二氮䓬、阿片类）
- **电解质紊乱**（低钠 / 高钙 / 低血糖 / 尿毒症）
- **急性尿潴留 / 便秘**（老年常被忽视的机械性诱因）

**建议进一步检查**：血常规 + CRP + 电解质 + 血糖 + 肝肾功 + 尿常规 + 胸片 + 用药史全面复核 + 导尿评估残余尿

### SP03 — 老年 + 跌倒 / 骨折

**强制列入鉴别**：
- 心源性晕厥（心律失常 / 心梗静默型）
- 直立性低血压（药物性最常见）
- 卒中 / TIA
- 低血糖

**注意**：老年髋部骨折患者需评估**心梗**（可为主诉，跌倒为结果）。

### SP04 — 老年 + 发热

- 感染表现常不典型（无高热、无白细胞升高）
- 建议**降低体温阈值**：≥ 37.5°C 且伴精神状态改变即需评估感染

---

## 三、孕期患者

### SP05 — 孕期 + 胸痛 / 呼吸困难

**强制列入鉴别（门槛降低）**：
- **肺栓塞**（孕期血栓风险明显升高，是孕产妇死亡首要原因之一）
- **围产期心肌病**
- **主动脉夹层**（孕晚期 / 产褥期）

**影像学建议规避**：优先超声 / MR，如需 CTPA 权衡获益风险

### SP06 — 孕期 + 头痛 / 视力改变 / 上腹痛

**强制列入鉴别**：
- **子痫前期 / 子痫 / HELLP 综合征**
- **可逆性后部脑病综合征（PRES）**
- **脑静脉窦血栓形成**

**必测**：血压、尿蛋白、血小板、肝酶、LDH、外周血涂片

### SP07 — 孕期用药建议规避

- 影像学 CT / X 线尽量替代为超声或 MR（无对比剂）
- 明确写出"孕期建议规避该检查，请与产科会诊后决定"

---

## 四、免疫抑制人群

### SP08 — HIV / 移植后 / 化疗中 / 长期激素

**发热鉴别必须扩展至**：
- 肺孢子菌肺炎（PJP）
- 巨细胞病毒（CMV）
- 侵袭性真菌感染
- 结核（含肺外）
- 弓形虫（脑）
- 隐球菌（脑膜炎）

**建议进一步检查**：淋巴细胞亚群（CD4）、β-D-葡聚糖、GM 试验、结核相关（PPD/IGRA/T-SPOT）、隐球菌抗原（血/CSF）

### SP09 — 中性粒细胞减少（ANC < 0.5 × 10⁹/L）+ 发热

- 按"发热性中性粒细胞减少症"处理
- 急症提示触发：血培养后 1h 内经验性广谱抗生素

---

## 五、儿童

### SP10 — 儿童 + 发热 + 皮疹

**强制列入鉴别（快速进展型）**：
- **脑膜炎球菌血症** — 出血点 / 紫癜 + 精神状态改变 → 立即抗生素
- 川崎病（发热 ≥ 5 天 + 结膜炎 / 口唇变化 / 皮疹 / 颈淋巴结 / 手足肿）
- Stevens-Johnson 综合征 / 中毒性表皮坏死松解症

### SP11 — 儿童 + 呕吐 + 精神差

**强制列入鉴别**：
- 肠套叠（< 2 岁 + 果酱样便）
- 颅内高压 / 脑膜脑炎
- 代谢性疾病急性失代偿（尿素循环障碍 / 有机酸血症）
- 幽门梗阻（婴儿喷射性呕吐）

### SP12 — 婴儿关键红旗

- < 3 月龄发热 → 均按严重细菌感染筛查
- 拒奶 + 哭声异常 + 前囟膨隆 → 立即评估颅内感染
- 儿童"喷射性呕吐" + 意识改变 → 头颅影像

---

## 六、糖尿病 / 高血压 / CKD / 冠心病基础病人群

### SP13 — 糖尿病 + 胸痛

- **心梗症状可不典型**（无痛性心梗多见于 DM）→ 胸闷、气短、上腹不适、恶心均可能是等价物
- 建议直接查 12 导联心电图 + cTn

### SP14 — 冠心病史 + 突发新发症状

- 无论何种主诉，先排除急性冠脉事件
- 心电图 + cTn 应作为基线

### SP15 — CKD 患者的检查建议自动附条件

- 见 `patient_context.md` 3.1 节

---

## 七、精神心理科交界

### SP16 — "焦虑症状" 但年龄 > 50 或有心血管危险因素

- 首诊不得直接归因于焦虑症 / 惊恐发作
- 必须先排除心源性（心电图 + cTn + TSH）
- 排除后再考虑心因性

---

## 触发方式

1. 第一步的"已知历史信息抽取"完成后，比对本文件的人群标签
2. 命中 → 该 SP 规则在本轮生效，扩展 R04 检测范围
3. 该 SP 规则要求列入的鉴别未出现 → R04 判定为不通过，强制补充
4. 该 SP 规则要求追问的项目未在信息中 → 追问清单强制包含

## 注意事项

1. 特殊人群规则**扩展而不替代**通用鉴别谱——不因为触发了 SP01 就删掉其他阑尾炎/尿路结石等常规鉴别
2. 触发依赖已知历史信息抽取的准确性——只有用户明确提供的信息才触发，不做临床推测
3. 若不同 SP 规则产生冲突建议，以"更保守 / 更倾向筛查危急疾病"的一方为准
