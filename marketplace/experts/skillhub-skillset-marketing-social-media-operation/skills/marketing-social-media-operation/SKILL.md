# 社媒运营工作流

你现在要完成一项社交媒体运营任务。你已安装以下 Skill，请按步骤串联使用：

## 步骤 1：热门内容抓取与趋势分析（获取层）
使用 **内容捕手** 完成：
- 抓取小红书、抖音、B站等平台的热门内容
- 分析当前热点话题和流量趋势
- 提取爆款内容的标题结构、标签策略和互动数据
- 分批抓取并生成热门内容汇报
- 为后续内容创作提供选题参考

输出热门内容报告和选题建议。

## 步骤 2：运营策略与涨粉规划（分析层）
使用 **自媒体运营全能助手** 完成：
- 制定小红书/公众号/抖音/私域的运营策略
- 规划内容日历和发布排期
- 设计涨粉策略（内容钩子、互动话术、粉丝活动）
- 分析账号数据，优化内容方向
- 制定私域流量转化路径

输出运营策略方案和内容日历。

## 步骤 3：多平台自媒体文案生成（分析层）
使用 **Content Writer 自媒体内容生成器** 完成：
- 为小红书生成种草笔记（标题+正文+标签）
- 为知乎生成专业回答和文章
- 为微信公众号生成推文初稿
- 为抖音生成短视频文案和脚本
- 确保各平台内容风格适配（小红书活泼/知乎专业/公众号深度）

输出各平台适配的内容文案。

## 步骤 4：内容优化与互动率提升（输出层）
使用 **Social Media Optimizer** 完成：
- 针对微信、小红书、知乎、B站、抖音分别优化内容
- 优化标题吸引力和首图/封面质量
- 优化标签（hashtag）策略和关键词布局
- 提升内容曝光率和互动率的具体建议
- 适配各平台算法推荐机制

输出优化建议和修改后的内容。

## 步骤 5：微信公众号爆文创作（输出层）
使用 **wechat-mp-writer-skill-mxx** 完成：
- 撰写 10 万+潜力的公众号文章
- 设计爆款标题（悬念/数字/情绪/反转）
- 优化文章结构（开头钩子→故事→干货→行动号召）
- 微信 SEO 关键词布局
- 生成订阅号/服务号适配版本

输出微信公众号推文。

## 步骤 6：全链路运营闭环（输出层）
使用 **运营工具skill** 完成：
- 执行行业分析和竞品对标
- 制定账号养号策略和人设定位
- 设计互动钩子（评论区话术/投票/抽奖）
- 违禁词检测和内容合规审查
- 覆盖抖音/视频号/小红书三大平台

## 最终输出
将以上步骤的结果整合为完整的社媒运营包，交付以下文件：
1. **热门趋势报告**：各平台热门内容分析和选题建议
2. **运营策略方案**：涨粉策略、内容日历、私域转化路径
3. **多平台内容集**：小红书笔记/知乎文章/公众号推文/抖音脚本
4. **内容优化报告**：各平台算法适配和互动率提升建议
5. **运营工具配置**：违禁词检测、互动钩子、账号管理方案
