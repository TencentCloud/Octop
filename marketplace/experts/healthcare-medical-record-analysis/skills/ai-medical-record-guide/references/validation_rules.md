# P0 安全红线规则（阻断级）

> **处置动作**：警告阻断，必须人工确认后才允许继续生成。

---

## P0-01: 过敏-药物冲突检测

| 属性 | 说明 |
|------|------|
| **规则编号** | P0-01 |
| **规则描述** | 检测过敏史与处方中药物的冲突关系 |
| **触发条件** | 过敏原类别与处方药物类别匹配时触发 |
| **示例** | 患者"青霉素过敏"，但处方包含阿莫西林（β-内酰胺类）|
| **处置动作** | ⛔ 阻断输出，提示："检测到过敏-用药冲突：患者标记「[过敏原]」过敏，处方中包含「[药物名]」（属于同类）。请确认是否修改处方。" |

### 常见过敏-药物对应关系

| 过敏原 | 冲突药物类别 | 示例药物 |
|--------|------------|---------|
| 青霉素 | β-内酰胺类抗生素 | 阿莫西林、氨苄西林、头孢菌素类(交叉过敏风险)|
| 磺胺 | 磺胺类药物 | 复方新诺明、磺胺嘧啶 |
| 碘 | 含碘造影剂 | 碘海醇、碘帕醇 |
| 鸡蛋/蛋清 | 流感疫苗（部分制剂）| — |
| 乳胶 | 乳胶制品（手套、导管等)| — |

## P0-02: 皮试验证违规

| 属性 | 说明 |
|------|------|
| **规则编号** | P0-02 |
| **规则描述** | 必须做皮试的药物未标记皮试或皮试结果为阴性仍开具 |
| **触发条件** | 青霉素类/头孢菌素类（部分）/破伤风抗毒素等需要皮试的药物，缺少皮试标识或标识为阴性但仍开药 |
| **示例** | 开具青霉素注射剂，未标注皮试结果 |
| **处置动作** | ⛔ 阻断输出，提示：「[药物名]」属于需皮试药物，请补充皮试结果后再继续。" |

### 强制皮试药物列表

- 青霉素类及其衍生物（所有给药途径）
- 部分头孢菌素类（视机构规定）
- 破伤风抗毒素（TAT）
- 碘造影剂（有碘过敏史者）
- 肉毒杆菌毒素

## P0-03: 关键字段完全缺失

| 属性 | 说明 |
|------|------|
| **规则编号** | P0-03 |
| **规则描述** | 核心身份/安全字段完全缺失 |
| **触发条件** | 以下字段全部为空：主诉、性别、年龄（任一缺失即触发）|
| **示例** | 仅提供"帮我写个病历"，无任何临床信息 |
| **处置动作** | ⛔ 阻断输出，提示："[缺失字段列表] 为必填项，请至少提供基础信息后再继续。" |

### P0 必填字段清单

| 场景 | P0 必填字段 |
|------|-----------|
| 所有场景 | 姓名、性别、年龄、主诉 |
| 门诊+处方 | 以上 + 过敏史 + 至少一项处方内容 |
| 住院入院 | 以上 + 入院时间 + 入院诊断 + 病史陈述人 |
| 住院出院 | 以上 + 出院诊断 + 治疗经过摘要 |

## P0-04: 致命性数值异常

| 属性 | 说明 |
|------|------|
| **规则编号** | P0-04 |
| **规则描述** | 生命体征或实验室指标处于危及生命范围且未见处理措施 |
| **触发条件** | 危急值范围内数值出现在病历中，但无对应处理记录 |
| **示例** | 血钾 6.8 mmol/L 记录在体格检查中，但病程中未见补钾/透析等处理 |
| **处置动作** | ⛔ 阻断输出 + 🚨 急症提示："检测到致命性异常值：[指标]=[数值][单位]。请确认是否有遗漏的处理措施记录。" |

### 致命性阈值表（部分）

| 指标 | 致命低限 | 致命中高限 |
|------|---------|-----------|
| 血清钾 (K+) | < 2.5 mmol/L | > 6.5 mmol/L |
| 血清钠 (Na+) | < 120 mmol/L | > 160 mmol/L |
| 血糖（随机）| < 2.8 mmol/L | > 27.8 mmol/L |
| 收缩压 (SBP) | < 70 mmHg | > 250 mmHg |
| 心率 (HR) | < 35 bpm | > 180 bpm |
| SpO2 | < 85% | — |
| pH (动脉) | < 7.20 | > 7.60 |
| 血小板 | < 10×10⁹/L | — |

## P0-05: 妊娠期禁忌药物

| 属性 | 说明 |
|------|------|
| **规则编号** | P0-05 |
| **规则描述** | 孕妇处方包含明确妊娠期禁用药物 |
| **触发条件** | 患者为孕妇（妊娠状态=是），处方含 FDA X 类/AU X 类药物 |
| **示例** | 孕妇处方含华法林、甲氨蝶呤、异维A酸等 |
| **处置动作** | ⛔ 阻断输出，提示："检测到妊娠期禁忌药物「[药物名]」。该药物对胎儿存在严重致畸风险，请确认是否替换。" |

### 常见妊娠期禁忌药物

FDA X 类（绝对禁用）：沙利度胺、异维A酸、华法林（6-12周）、甲氨蝶呤、他汀类药物、ACEI/ARB（孕中期）、四环素类、喹诺酮类（部分）

## P0-06: 年龄-剂量严重不匹配

| 属性 | 说明 |
|------|------|
| **规则编号** | P0-06 |
| **规则描述** | 儿童使用成人剂量，或反之 |
| **触发条件** | 年龄≤12岁且药物剂量≥成人常规剂量上限；或年龄≥65岁且剂量远超老年人推荐剂量 |
| **示例** | 5岁儿童开具阿莫西林 500mg tid（成人剂量）|
| **处置动作** | ⛔ 阻断输出，提示："患者年龄[age]岁，「[药物名]」剂量[dose]可能不适合此年龄段。建议按体重/体表面积调整。" |

---

## P0-07: 时间逻辑致命矛盾

| 属性 | 说明 |
|------|------|
| **规则编号** | P0-07 |
| **规则描述** | 时间线存在不可能的逻辑矛盾 |
| **触发条件** | 出院时间早于入院时间；手术时间早于入院时间；出生日期晚于就诊日期 |
| **示例** | 入院时间2024-01-15，出院时间2024-01-10 |
| **处置动作** | ⛔ 阻断输出，提示："时间逻辑错误：[早的时间点]晚于[晚的时间点]。请核实并修正。" |

# P1 质量问题规则（警告级）

> **处置动作**：警告提示，用户确认后可继续生成。

---

## P1-01: 诊断不一致

| 属性 | 说明 |
|------|------|
| **规则编号** | P1-01 |
| **规则描述** | 入院诊断与出院诊断完全相同但治疗经过暗示诊断变更 |
| **触发条件** | 出院诊断 == 入院诊断（逐字相同），但治疗经过中提到新发现、手术证实了其他疾病、或明确写了"修正诊断为"等内容 |
| **示例** | 入院写"胸痛待查"，治疗后出院仍写"胸痛待查"，但术中确诊为"冠心病" |
| **处置动作** | 🟡 警告："出院诊断与入院诊断完全相同，但治疗经过暗示可能有变更。请确认出院诊断是否需要更新。" |

---

## P1-02: 时间逻辑可疑

| 属性 | 说明 |
|------|------|
| **规则编号** | P1-02 |
| **规则描述** | 主诉时长与现病史中的发病时间不一致 |
| **触发条件** | 主诉说"X天/周/月"，现病史中说"Y天/周/月前起病"，X 与 Y 差距 > 30% |
| **示例** | 主诉"发热3天"，现病史写"1周前开始出现发热" |
| **处置动作** | 🟡 警告："主诉「[主诉时长]」与现病史「[病史时长]」存在时间差异。请确认哪个更准确。" |

---

## P1-03: 必填字段缺失（非P0级）

| 属性 | 说明 |
|------|------|
| **规则编号** | P1-03 |
| **规则描述** | 重要但非安全阻断级别的字段为空 |
| **触发条件** | 以下字段为空：既往史、体格检查关键项、辅助检查结果、初步诊断 |
| **示例** | 住院病历缺少体格检查记录 |
| **处置动作** | 🟡 警告："以下重要信息未填写：[字段列表]。将标注 [信息缺失]。是否补充？" |

---

## P1-04: 剂量超出常规范围（非致死性）

| 属性 | 说明 |
|------|------|
| **规则编号** | P1-04 |
| **规则描述** | 药物剂量超过常规范围但未达到致死程度 |
| **触发条件** | 单次剂量 > 推荐最大剂量的150%，或 < 推荐最小剂量的50%（非特殊适应症说明时）|
| **示例** | 成人阿莫西林 3.0g qid（常规 0.5g tid）|
| **处置动作** | 🟡 警告："「[药物名]」剂量[dose][route]超出了常规范围（通常[freq]）。如为特殊方案请在备注中说明理由。" |

### 常见药物常规剂量参考表

| 药品名称 | 常规单次剂量 | 常规频次 | 日极量 |
|---------|-----------|---------|--------|
| 阿莫西林 | 0.25-0.5g | tid | 4g |
| 头孢克洛 | 0.25g | tid | 2g |
| 左氧氟沙星 | 0.25-0.5g | qd/bid | 0.75g |
| 氨氯地平 | 5mg | qd | 10mg |
| 二甲双胍 | 0.5g | tid | 2.55g |
| 奥美拉唑 | 20mg | qd/bid | 80mg |
| 布洛芬 | 0.2-0.4g | prn | 1.2g |

> 注：以上为成人常规参考，实际应结合患者具体情况和机构规范。

## P1-05: 药物相互作用（非P0级）

| 属性 | 说明 |
|------|------|
| **规则编号** | P1-05 |
| **规则描述** | 处方中存在已知的药物相互作用，但不属于致命级别 |
| **触发条件** | 同一处方中出现以下组合之一（非穷尽）：
- 华法林 + NSAIDs → 出血风险增加
- ACEI/ARB + 保钾利尿剂 → 高血钾
- 氯吡格雷 + PPI（奥美拉唑）→ 抗血小板效应减弱
- 甲氨蝶呤 + NSAIDs → MTX毒性增加
- 他汀类 + 大环内酯类抗生素 → 肌溶解风险 |
| **处置动作** | 🟡 警告："检测到潜在药物相互作用：[药A] + [药B] → [相互作用描述]。建议关注并评估是否需要调整。" |

---

## P1-06: 检查结果与诊断不符

| 属性 | 说明 |
|------|------|
| **规则编号** | P1-06 |
| **规则描述** | 辅助检查结果不支持或不一致于当前诊断 |
| **触发条件** | 诊断中提及某疾病，但相关检查结果正常；或检查结果显示某异常但未被任何诊断涵盖 |
| **示例** | 诊断"细菌性肺炎"，但白细胞计数和CRP均正常范围 |
| **处置动作** | 🟡 警告："辅助检查结果「[检查]:[结果]」与诊断「[诊断]」可能不一致。请确认诊断依据是否充分。" |

---

## P1-07: 现病史与体格检查脱节

| 属性 | 说明 |
|------|------|
| **规则编号** | P1-07 |
| **规则描述** | 现病史中描述的症状在体格检查中无对应体征记录 |
| **触发条件** | 现病史明确提到阳性症状（如腹痛），但体格检查中对应部位（腹部）的检查记录过于简略或缺失 |
| **示例** | 现病史详述"右下腹持续性疼痛6小时"，但体格检查仅写"腹平软，无压痛"（未提麦氏点压痛）|
| **处置动作** | 🟡 警告："现病史中提到的「[症状]」，在体格检查中缺乏对应部位的详细记录。建议补充专科体检。" |

---

## P1-08: 用法用量不规范

| 属性 | 说明 |
|------|------|
| **规则编号** | P1-08 |
| **规则描述** | 处方中药品用法用量表述不规范 |
| **触发条件** | 缺少频次、缺少途径、频次使用非标准缩写（如"每天三次"而非tid）、剂量缺单位 |
| **示例** | "阿莫西林胶囊 每日三次"（缺剂量、缺途径）|
| **处置动作** | 🟡 警告："「[药物名]」用法用量不完整：[具体问题]。建议补全为标准格式。" |

# P2 完善建议规则（提示级）

> **处置动作**：温和提示，不影响病历生成流程。

---

## P2-01: 推荐字段缺失

| 属性 | 说明 |
|------|------|
| **规则编号** | P2-01 |
| **规则描述** | 推荐填写但非必须的字段为空 |
| **触发条件** | 个人史（吸烟饮酒）、家族史、职业、现住址等为空 |
| **示例** | 个人史仅写"[待补充]" |
| **处置动作** | 🔵 提示："以下推荐字段可进一步完善：[字段列表]，有助于完整评估患者背景。" |

---

## P2-02: 文本质量

| 属性 | 说明 |
|------|------|
| **规则编号** | P2-02 |
| **规则描述** | 病历文本存在质量问题 |
| **触发条件**：
- 段落文本过短（<15字）
- 段落文本过长（>2000字，可能需要分段）
- 残留口语化表达（"挺好的"、"不太舒服"等非术语表达）
- 标点符号不规范（连续句号、全角半角混用）|
| **处置动作** | 🔵 提示："文本质量建议：「[段落名]」[具体问题描述]" |

---

## P2-03: 随访计划不完整

| 属性 | 说明 |
|------|------|
| **规则编号** | P2-03 |
| **规则描述** | 出院小结中随访安排信息不足 |
| **触发条件** | 缺少复诊时间、或缺少复查项目、或缺少红线症状列表 |
| **示例** | 出院小结仅有"定期门诊随诊"，无具体时间和内容 |
| **处置动作** | 🔵 提示："出院小结的随访安排可进一步细化，建议补充：[缺失项]" |

---

## P2-04: 家族史/个人史空白

| 属性 | 说明 |
|------|------|
| **规则编号** | P2-04 |
| **规则描述** | 家族史和个人史均未填写任何实质性内容 |
| **触发条件** | 家族史="[待补充]" 或 "否认" 且个人史="[待补充]" 或 "无特殊" |
| **处置动作** | 🔵 提示："家族史和个人史较为简略。对于慢性病患者，建议采集更多背景信息以支持长期管理。" |

---

## P2-05: ICD 编码待补充

| 属性 | 说明 |
|------|------|
| **规则编号** | P2-05 |
| **规则描述** | 所有诊断条目均未附带 ICD 编码 |
| **触发条件** | 输出中所有诊断均标注 `[待编码]` 或无编码位 |
| **处置动作** | 🔵 提示："诊断尚未编码。后续可对接 ICD 编码服务自动填充编码位。" |

---

## P2-06: 专科体查过于简略

| 属性 | 说明 |
|------|------|
| **规则编号** | P2-06 |
| **规则描述** | 体格检查中专科部分过于简单 |
| **触发条件**：根据科室判断：
- 心内科：心脏听诊少于2行描述
- 呼吸科：肺部听诊少于2行描述
- 外科：腹部触诊少于2行描述
- 神经科：神经系统检查少于3行描述 |
| **处置动作** | 🔵 提示："专科体查可更加详细。建议补充：[具体建议的检查项目]" |

---

## P2-07: 出院医嘱缺少注意事项

| 属性 | 说明 |
|------|------|
| **规则编号** | P2-07 |
| **规则描述** | 出院医嘱中缺少重要的注意事项 |
| **触发条件** | 出院带药未注明副作用观察要点；或活动/饮食指导过于笼统（如仅写"注意休息"、"合理饮食"）|
| **示例** | 出院带华法林但未注明出血征象观察要点 |
| **处置动作** | 🔵 提示："出院医嘱建议补充：[具体的注意事项]" |

```markdown
## 📋 病历校验报告

**病历类型**: [门诊/入院/病程/出院]
**校验时间**: [timestamp]
**校验版本**: v2.0
```
