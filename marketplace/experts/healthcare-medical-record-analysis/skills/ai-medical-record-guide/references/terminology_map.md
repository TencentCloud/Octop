## 六、特殊模式处理规则

### 歧义处理总则

| 模式 | 处理方式 | 说明 |
|------|---------|------|
| **明确的口语→术语映射** | 自动替换 | 如"肚子疼"→"腹痛"，无需人工干预 |
| **有潜在歧义的** | 标记 + 追问 | 如"头晕"可能眩晕/头昏/失衡，必须追问澄清 |
| **已经是标准术语** | 保持不变 | 如已使用"腹痛""发热"等标准术语，不做修改 |
| **数值缺失的表达** | 强制追问 | 如"血压高""发烧"等必须获取具体数值 |

### 数值追问清单

以下口语表达**必须在追问中获取具体数值**：

| 表达 | 需获取的数值 | 追问话术 |
|------|-------------|---------|
| 血压高/低 | SBP/DBP具体值，单位mmHg | "最近测的血压是多少？记得最高到过多少吗？" |
| 发烧 | 最高体温，单位°C | "用体温计量的最高多少度？" |
| 血糖高/低 | FPG/2hPG值，单位mmol/L | "空腹血糖测过吗？餐后呢？" |
| 疼痛 | NRS评分（0-10分）或VAS评分 | "如果0完全不痛10最痛，您觉得大概几分？" |
| 体重变化 | 具体公斤数和时间跨度 | "大概掉了多少斤？多长时间掉的？" |
| 时间模糊表达 | "好几天""很久"→具体天数/月数 | "大概是几天前开始的？能回忆起日期吗？" |

### 无法自动转换的高歧义词（必须人工介入）

以下表达**禁止自动替换**，必须追问：

| 表达 | 原因 | 推荐追问方式 |
|------|------|------------|
| 不舒服 | 过于宽泛，可能是任何症状 | "具体是哪个部位不舒服？什么感觉？" |
| 不得劲 | 同上 | 同上 |
| 身体不好 | 过于笼统 | "主要哪里不舒服？从什么时候开始的？" |
| 去医院看过 | 不包含任何医学信息 | "在医院做了什么检查？医生怎么说？" |
| 吃了点药 | 不包含药品信息 | "吃的是什么药？吃了多久？效果如何？" |
| 好像/可能是 | 表达不确定性而非症状本身 | "这个症状是确定的还是您的推测？" |
