# 常用临床评分提示表

**用途**：当鉴别命中相关疾病时，在报告的"建议进一步检查"或"鉴别要点"里**提示应用该评分**，并明确当前信息覆盖了哪几项、缺哪几项。

**核心原则**：**不替医生算分**。大模型对多项求和的数值容易出错；且计算逻辑各评分有细节差异，替算风险高。评分作为**信息完整性检查清单**呈现——医生自行心算或用院内计算器。

---

## 评分提示格式

统一格式：

```
📊 建议应用评分：[评分名称]（[对应疾病 / 场景]）
- 涵盖项：[项 A] / [项 B] / [项 C] …
- 当前信息覆盖：[✅ 项 A、项 B] [❓ 项 C 未提供]
- 缺失项对判定的影响：[简述]
```

## 常用评分表

### 1. Wells 评分 — 肺栓塞先验概率

- **触发时机**：鉴别包含肺栓塞
- **7 项**：
  1. DVT 临床征象（3.0）
  2. PE 比其他诊断更可能（3.0）
  3. 心率 > 100（1.5）
  4. 4 周内制动或手术（1.5）
  5. 既往 DVT/PE（1.5）
  6. 咯血（1.0）
  7. 恶性肿瘤活动期或 6 月内治疗（1.0）
- **阈值参考**：≤ 4 → 低概率（D-dimer 分流）；> 4 → 高概率（直接影像）
- **说明**：**总分由医生自行核算**，本工具仅列出项目和当前覆盖度

### 2. Alvarado 评分 — 急性阑尾炎

- **触发时机**：鉴别包含急性阑尾炎
- **8 项（MANTRELS）**：
  - Migration（转移性右下腹痛）1
  - Anorexia（食欲减退）1
  - Nausea/Vomiting（恶心呕吐）1
  - Tenderness RLQ（右下腹压痛）2
  - Rebound（反跳痛）1
  - Elevated temperature（发热 ≥ 37.3°C）1
  - Leukocytosis（WBC ≥ 10×10⁹）2
  - Shift（中性粒左移）1
- **参考**：≥ 7 高度可能；4-6 需进一步检查；≤ 3 低可能
- **说明**：总分由医生核算

### 3. CURB-65 — 社区获得性肺炎严重度

- **触发时机**：鉴别包含 CAP
- **5 项**：
  - Confusion 意识改变
  - Urea > 7 mmol/L
  - RR ≥ 30
  - BP：SBP < 90 或 DBP ≤ 60
  - Age ≥ 65
- **参考**：0-1 门诊；2 住院考虑；≥ 3 ICU 评估
- **说明**：总分由医生核算

### 4. qSOFA — 脓毒症床旁筛查

- **触发时机**：疑似感染 + 系统性表现
- **3 项**：意识改变（GCS < 15）/ 呼吸 ≥ 22 / SBP ≤ 100
- **参考**：≥ 2 提示不良预后风险，加急评估
- **说明**：总分由医生核算

### 5. GRACE 评分 — ACS 院内死亡风险

- **触发时机**：确诊或高度疑似 ACS
- **8 项**：年龄 / 心率 / 收缩压 / 肌酐 / Killip 分级 / 心脏停搏 / ST 段偏移 / 心肌酶升高
- **说明**：**权重复杂**，本工具不列出具体分值权重，仅提示"建议用 GRACE 评估院内死亡风险，分层决定介入紧迫性" → 医生用院内计算器

### 6. CHA₂DS₂-VASc — 房颤卒中风险

- **触发时机**：诊断 / 鉴别包含房颤或需评估抗凝
- **8 项（含年龄两档）**：CHF 1 / HTN 1 / Age ≥ 75 (2) / DM 1 / Stroke/TIA (2) / Vascular disease 1 / Age 65-74 (1) / Sex (F) 1
- **参考**：男 ≥ 2、女 ≥ 3 → 建议抗凝
- **说明**：**抗凝决策属治疗方案范畴**，本工具仅提示评分和风险分层，具体抗凝方案由 clinical-rounds-copilot 或医生决定

### 7. HAS-BLED — 抗凝出血风险

- **触发时机**：与 CHA₂DS₂-VASc 配对使用
- **7 项**：HTN、异常肝肾、卒中史、出血倾向、INR 不稳定、老年 > 65、药物/酒精
- **说明**：与 CHA₂DS₂-VASc 综合判断，本工具只提示评分

### 8. NIHSS — 卒中严重度

- **触发时机**：疑似急性缺血性卒中
- **15 项体格检查**（意识/视野/凝视/面瘫/上下肢肌力等）
- **说明**：需床旁体格检查逐项完成，本工具仅提示"建议行 NIHSS 评估卒中严重度"

### 9. Glasgow 昏迷评分 (GCS)

- **触发时机**：意识改变
- **3 项**：睁眼 / 语言 / 运动
- **说明**：现场评估，本工具仅提示

### 10. Killip 分级 — 急性心梗心功能

- **触发时机**：疑似急性心梗
- **4 级**：I 无衰竭 / II 肺部啰音 < 50% / III 急性肺水肿 / IV 心源性休克
- **说明**：需听诊 + 血压评估，本工具提示应用

### 11. Ranson 标准 — 急性胰腺炎严重度

- **触发时机**：疑似急性胰腺炎
- **入院时 5 项 + 48h 6 项**
- **说明**：需 48h 动态化验，本工具提示应用

### 12. Child-Pugh — 肝硬化分级

- **触发时机**：诊断 / 鉴别包含肝硬化
- **5 项**：胆红素、白蛋白、PT/INR、腹水、肝性脑病
- **说明**：本工具提示应用及分级 A/B/C 意义

### 13. MELD 评分 — 肝移植分层

- **触发时机**：终末期肝病评估
- **公式复杂（对数运算）** → 本工具**仅提示应用**，不给出数值

### 14. HEART 评分 — 胸痛 30 天 MACE 风险

- **触发时机**：胸痛急诊分诊
- **5 项**：病史、心电图、年龄、危险因素、肌钙蛋白
- **说明**：本工具提示应用及低/中/高危分层意义

### 15. PERC 规则 — 肺栓塞排除

- **触发时机**：低概率 PE 患者需决定是否查 D-dimer
- **8 项全阴 → 可排除 PE**
- **说明**：本工具列出 8 项检查医生现场核对

---

## 使用注意

1. **只提示、不代算**：所有评分总分由医生自行完成或用院内计算器
2. **明确覆盖度**：告诉医生本次输入覆盖了评分中的哪些项，缺哪些
3. **不做剂量决策**：抗凝启动、溶栓选择等治疗决策不由本工具输出——评分只用于**分层与信息完整性**
4. **评分不替代临床判断**：分数低不代表安全（尤其在临床高度怀疑时）
