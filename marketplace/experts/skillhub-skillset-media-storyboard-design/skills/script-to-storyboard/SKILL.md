# 剧本转分镜

把一份已经写完的剧本，翻译成导演能逐镜执行的分镜脚本。核心交付物是**一份分镜脚本文档**，不是图片或视频。

## 核心原则

思维引擎（因果链）：

```
剧本 → 提炼叙事弧（起承转合/钩子反转） → 确定形态与平台 → 切分场次 → 逐镜拆解（景别+运镜+画面+台词+音效+时长） → 每镜附生成提示词 → 静默自检 → 交付分镜文档
```

一句话质量测试：**把分镜文档直接交给一位没读过原剧本的导演，他不需要再问任何"这里发生了什么"的问题，就能开拍。** 若某个镜头删掉后故事依然成立且不损失情绪，说明该镜头是冗余，应删除。

铁律：
1. 分镜必须忠实于剧本，不擅自增删情节、不改人物动机；只做"翻译"，不做"改写"。
2. 台词原样搬运，不润色、不缩写。
3. 每镜都有存在的理由：交代信息、推进情绪或制造节奏，三者必居其一。

## 输入

必需：
- 剧本/故事大纲/小说片段（用户文字、上传文件或引用的画布文本节点，任一形式）

可选（缺失时只追问缺失项，剧本信息里能推断的不要重复问）：
- 画幅与平台：未指定时，先按剧本气质判断——对话密集、强钩子、生活化题材 → 9:16 竖屏短视频；场景宏大、多人物调度、电影感强 → 16:9 横屏影视；判断模糊时询问用户。
- 总时长或集数：未指定时按叙事弧自动规划，单镜头默认 3-8 秒。
- 每镜是否生成参考图：默认不生成，仅用户要求时执行。

## 输入诊断

拆分镜前逐项明确（剧本里已有答案的直接取用，没有的合理假设并在文档开头注明"默认假设"）：

1. 体裁：短剧 / 短视频剧情 / 微电影 / 广告剧情 / MV 叙事
2. 画幅与平台：9:16 竖屏（抖音/快手）或 16:9 横屏（影视感/横屏平台）
3. 叙事弧：钩子（前 3 秒）→ 铺垫 → 冲突/转折 → 高潮 → 结尾状态
4. 场景清单：每个场景的地点、时间、光线条件
5. 人物清单：出场人物、造型关键特征、相互关系（用于跨镜一致性提示词）
6. 情绪曲线：每场戏的情绪温度，决定镜头密度与节奏
7. 预估总时长与镜头总数（时长 ÷ 5 秒 ≈ 镜头数）
8. 声音设计：台词、旁白、音效点、音乐进出
9. 合规敏感点：涉及暴力、医疗、金融等表述在提示词中使用正向护栏措辞

## 工作流

### 第一步：通读与拆弧
通读剧本，提炼：一句话故事、叙事弧五段、场景清单、人物清单、情绪曲线。此步不输出给用户，仅内部完成。

### 第二步：切分场次
按地点或情绪转折切分场次，为每场标注：场景、时间、光线、在场人物、本场任务（信息/情绪/节奏）、预估时长。

### 第三步：逐镜拆解
每场内部按"本场任务"拆到单镜。每个镜头必须包含输出契约的全部字段。拆镜口诀：
- **交代用全景，情绪用特写**：新场景首个镜头给全景定空间关系；情绪峰值给面部或物件特写。
- **一个镜头只干一件事**：不要让一个镜头同时推进两个动作。
- **动作用切分，氛围用长镜**：动作戏短镜头快切（2-4 秒），氛围铺垫可用 5-8 秒长镜。
- **台词配反应**：谁说话给谁镜头，台词的"杀伤力"用听者的反应镜头呈现。

### 第四步：写每镜生成提示词
为每个镜头写可直接用于图片/视频生成的提示词段落（字段见输出契约），要求：
- 画面要素齐全：主体+动作+景别+机位/运镜+光线+色调+场景细节。
- 人物外貌特征在每条提示词中**完整重复**，不写"同上一镜"。
- 提示词中不出现镜头号、时间轴等元信息，只写画面内容。

### 第五步（可选）：生成参考图
仅当用户要求时，用第四步的提示词为关键镜头生成参考图作为分镜示意；默认跳过此步。

### 第六步：静默自检后交付
按"静默自检"逐条核对，弱项直接重写，然后输出分镜文档。

## 输出契约

分镜文档结构（中文，Markdown）：

```markdown
# 《剧作名》分镜脚本

## 概览
- 形态：竖屏短视频 / 横屏影视 | 画幅：9:16 / 16:9
- 预估总时长：XX 秒 | 镜头总数：XX
- 叙事弧：钩子(S1) → 铺垫(S2) → 转折(S3) → 高潮(S4) → 结尾(S5)
- 人物关键特征（供跨镜一致性）：姓名：外貌描述三句内
- 默认假设：此处列出第三步无法从剧本推断、已自行假设的项

## 第 X 场：场景名（地点·时间·光线）
本场任务：一句话 | 情绪：X/10 | 预估 XX 秒

### 镜头 X-1 ｜ 景别 ｜ 运镜 ｜ 时长 X 秒
- 画面：具体可视的画面描述，谁在做什么、镜头怎么动、光线如何
- 台词/旁白：原剧本台词，标注说话人；无台词写"无"
- 音效/音乐：音效点与音乐进出
- 情绪与节奏：本镜在情绪曲线上的位置
- 生成提示词：主体 + 动作 + 景别 + 机位运镜 + 光线色调 + 场景细节（不写元信息，人物特征完整重复）
```

字段硬规则：
- 景别只用五档：远景 / 全景 / 中景 / 近景 / 特写
- 运镜从固定、推、拉、摇、移、跟、环绕、升降中选，一镜最多两种组合
- 竖屏短视频：首镜 3 秒内出现钩子；横屏影视：允许 5-8 秒的空间铺垫开镜
- 时长标注为整数秒，单镜 2-8 秒；总时长 = 各镜时长之和

## 静默自检

交付前逐条核对，不过关就重写，不向用户展示清单：
1. 抽查 3 个镜头做"导演测试"：只看分镜能否还原剧情，不回看剧本。
2. 台词是否与剧本逐字一致。
3. 每镜时长与总时长是否自洽，镜头数是否与预估匹配。
4. 提示词是否可直接使用：无"上一镜""同前"等相对引用，人物特征完整。
5. 竖屏/横屏判断与剧本气质是否匹配，首镜是否符合平台节奏（竖屏 3 秒钩子）。
6. 敏感措辞是否已替换为正向护栏表述。
7. 概览的"默认假设"是否全部列出。
