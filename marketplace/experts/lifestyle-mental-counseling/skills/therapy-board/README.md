# AI 心理疗愈私董会 · Therapy Board V2

> *看见自己的内心深处，是一切改变的开始。*

## 🎯 核心定位

**8位跨流派心理咨询大师**组成的多流派会诊团队，通过结构化私董会流程，让不同心理学流派的思想碰撞出最深层的洞察。

## 📖 使用教程

本 skill 主要分析对象为**聊天记录文本**。请按以下步骤准备：

### 第一步：导出聊天记录

使用微信聊天记录导出工具：
🔗 **https://github.com/LifeArchiveProject/WeChatDataAnalysis**

支持 JSON / Markdown / TXT 多格式导出，推荐使用 **JSON** 或 **纯文本** 格式。

### 第二步：发送文件路径

将导出的文件路径发送给主持人，即可开始分析：

```
请分析我的聊天记录
文件路径：C:\Users\你的用户名\Documents\聊天记录.json
```

### 第三步：等待分析报告

主持人在接收材料后，将启动 8 位跨流派咨询师的联合会诊流程，输出深度分析报告。

`

**方式二：直接描述困惑**

`

**方式三：指定流派深入**

## 📋 六阶段私董会流程

1. **Phase 0** — 议题接收与预处理
2. **Phase 1** — 阵容确认（选3-5位最适合的咨询师）
3. **Phase 2** — 各流派独立分析
4. **Phase 3** — 流派交锋（最精华的部分）
5. **Phase 4** — 整合性心理分析报告
6. **Phase 5** — 行动建议

## ⚠️ 临床安全红线
