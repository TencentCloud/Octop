## 一、核心技术一览

### 1. 向下箭头法（伯恩斯）
**用途：** 揭露核心恐惧
**步骤：** 连续追问"如果那样，最坏会发生什么？"
**示例：**
```
表层："我可能会犯错"
→ "如果犯了错，最坏会发生什么？" → "领导会批评我"
→ "如果被批评，最坏会发生什么？" → "我会被解雇"
→ "如果被解雇，最坏会发生什么？" → "我会失去一切"
```

---

### 2. 苏格拉底提问（贝克）
**用途：** 检验自动化思维
**问题清单：**
- [ ] 有什么证据支持这个想法？
- [ ] 有什么证据反对这个想法？
- [ ] 有没有其他可能的解释？
- [ ] 最坏的情况是什么？最好的？最现实的？
- [ ] 如果朋友有同样的想法，你会怎么对他说？
- [ ] 继续这样想，对你有什么帮助/坏处？

---

### 3. 认知重塑8技巧（汤普金斯）

| 技巧 | 核心问题 | 用途 |
|------|---------|------|
| **1. 识别自动思维** | "刚才脑海中闪过了什么想法？" | 捕捉焦虑源头 |
| **2. 检验证据** | "有什么事实支持/反对？" | 区分事实与解释 |
| **3. 重新归因** | "还有哪些因素可能导致？" | 打破个人化 |
| **4. 去灾难化** | "最坏情况发生的概率？你能承受吗？" | 降低焦虑 |
| **5. 成本-收益分析** | "维持这个想法的好处和代价？" | 促发改变动机 |
| **6. 双重标准** | "如果朋友这样想，你会怎么对他说？" | 自我慈悲 |
| **7. 实验检验** | "设计一个实验来验证？" | 用实践证明 |
| **8. 应对卡片** | "把平衡思维写下来随身携带" | 巩固成果 |

### 4. GAD专项技术（罗比肖 & 杜加斯）

#### 4.1 担忧时间（Worry Time）
**步骤：**
1. 每天设定15-20分钟"担忧时间"（建议傍晚，非睡前）
2. 其他时间出现担忧，告诉自己"留到担忧时间再想"
3. 简单记录担忧，继续当前活动
4. 担忧时间集中处理

#### 4.2 担忧记录与分析
**记录表：**
```
日期 | 担忧内容 | 预测 | 实际结果 | 准确？
-----|---------|------|---------|-------
周一 | 项目延期 | 会被批评 | 顺利推进 | 否
```
**目标：** 发现担忧的预测准确率往往很低

#### 4.3 不确定性接纳训练
**层级暴露（从低到高）：**
1. 不查看明天的天气，直接出门（低）
2. 不提前规划周末活动（低-中）
3. 不提前准备会议发言（中）
4. 不确认朋友是否会准时（中-高）
5. 不做详细计划，即兴旅行（高）

**接纳语句：**
- "我不知道会发生什么，但这没关系"
- "不确定性是生活的一部分，我可以承受它"

## 三、认知扭曲速查

### 伯恩斯的10种认知扭曲

| 扭曲类型 | 识别关键词 | 示例 |
|---------|-----------|------|
| **全有或全无** | "彻底""完全""总是""从不" | "如果我失败了，我就是彻底的失败者" |
| **过度概括** | "永远""每次""所有人" | "这次失败了，我永远都不会成功" |
| **心理过滤** | 只关注负面细节 | 收到10条好评和1条批评，只记住批评 |
| **贬低积极** | "那不算什么""只是运气" | "那不算什么，谁都能做到" |
| **妄下结论** | "肯定""一定"（无证据） | "他们肯定觉得我很无聊" |
| **夸大/缩小** | "太可怕了""太糟糕了" | "这个错误太可怕了" |
| **情绪化推理** | "我感觉…所以…" | "我觉得自己很蠢，所以我一定很蠢" |
| **"应该"陈述** | "应该""必须""不得不" | "我应该总是做得最好" |
| **贴标签** | "我就是个…" | "我就是个失败者" |
| **个人化** | "是因为我" | "他们不开心肯定是因为我" |

## 五、权威引言库

### 解释概念时
> "正如CBT创始人亚伦·贝克博士所指出的，焦虑常常源于对危险的'高估'——我们高估了坏结果发生的概率，低估了自己应对的能力。"

### 鼓励行动时
> "国际焦虑治疗专家瑞德·威尔逊博士有一个著名的观点：康复的关键是'主动走向不适，而非追求舒适'。"

### 肯定进步时
> "贝克认知疗法研究所的朱迪思·贝克博士常说，'识别灾难化思维本身，就能削弱焦虑30%'。你刚才做到了。"

### 共情理解时
> "人本主义心理学创始人卡尔·罗杰斯说过，'当一个人被真正倾听和理解时，他就能够重新审视自己的世界，继续前进。'"

### 提供工具时
> "认知治疗专家迈克尔·汤普金斯博士在《认知重塑》中提出了8种实用技巧。让我们用这些技巧来一起处理这个想法。"

### 处理GAD时
> "广泛性焦虑研究专家罗比肖和杜加斯博士发现，GAD的核心不是担心具体的事情，而是对'不确定性'的不耐受。"
