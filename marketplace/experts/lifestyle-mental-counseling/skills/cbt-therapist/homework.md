# 家庭作业设计指南

## 核心原则

家庭作业（Homework）是CBT治疗的重要组成部分——它是来访者将治疗室中的发现在日常生活中实践的桥梁。

**黄金法则：** 作业要具体、可执行、有意义，且来访者有意愿完成。

---

## 优秀家庭作业的特征

✅ **SMART原则：**
- **S**pecific（具体的）：不是"减少焦虑"，而是"每天记录3次焦虑评分"
- **M**easurable（可测量的）：有明确的完成标准
- **A**ctionable（可执行的）：有具体的行动步骤
- **R**elevant（相关的）：与治疗目标直接相关
- **T**ime-bound（有期限的）：本周内完成

✅ **参与式设计：**
- 询问来访者："你觉得这个作业对你来说可行吗？"
- 让来访者自己选择作业内容比被动接受效果更好
- 如果来访者觉得困难，共同调整

✅ **从最小开始：**
- 新来访者 → 从"今天做一个5分钟的记录"开始
- 有经验来访者 → 可以接受更复杂的作业

## 按障碍分类的作业库

### 焦虑障碍 — 作业模板

#### 作业1：担忧记录表（每日）
```
时间 | 担忧内容 | 预测结果（0-100%）| 实际结果 | 正确率
-----|---------|-----------------|---------|-------
     |         |                 |         |
```
**频次：** 每天记录担忧（至少5次）
**周期：** 至少2周
**目的：** 发现担忧的真实准确率

#### 作业2：行为实验记录表
```
实验名称：
预测：__将发生__
实际发生了什么：__
你的感受：__
结论：__
```
**频次：** 每周1-2个实验
**周期：** 持续整个治疗期
**要点：** 从低风险实验开始

#### 作业3：安全行为暴露日志
```
情境 | 安全行为 | 焦虑峰值(SUDS) | 30分钟后SUDS | 不做安全行为的后果
-----|---------|-------------|-------------|------------------
     |         |             |             |
```
**目的：** 识别并减少安全行为

### 抑郁障碍 — 作业模板

#### 作业1：活动监测（每日）
```
日期：
时间 | 活动 | 愉悦感(0-10) | 掌控感(0-10) | 备注
-----|------|-------------|-------------|----
     |      |             |             |
```
**频次：** 每日记录
**周期：** 持续记录，重点分析周末

#### 作业2：认知日记（每日）
```
情境 | 自动思维 | 情绪 | 强度 | 证据(支持) | 证据(反对) | 替代思维 | 新强度
-----|---------|------|------|-----------|-----------|---------|------
     |         |      |      |           |           |         |
```
**频次：** 每日记录（至少3个自动思维）
**周期：** 至少4周

#### 作业3：阶梯活动计划
```
本周目标活动：
- 活动1：___ （难度L__） □ 完成
- 活动2：___ （难度L__） □ 完成

下周展望：
```
**要点：** 活动从简单开始，庆祝每一次完成

### 强迫障碍 — 作业模板

#### 作业1：强迫思维监测表（每日）
```
时间 | 强迫思维内容 | 焦虑(SUDS) | 强迫行为 | 执行后SUDS | 等待后SUDS(无强迫行为)
-----|-------------|-----------|---------|-----------|-------------------
     |             |           |         |           |
```
**频次：** 每日记录
**要点：** 对比"做强迫行为" vs "等待焦虑自然消退"

#### 作业2：ERP暴露练习记录
```
暴露情境：
SUDS开始：
目标（下降__%或SUDS < __）：
SUDS 5分钟后：
SUDS 15分钟后：
SUDS 30分钟后：
SUDS 1小时后：
是否执行了强迫行为：是 / 否
本次最大的发现：
```
**频次：** 每日或按计划进行
**要点：** 记录SUDS自然下降的过程

#### 作业3：认知离解练习记录
```
强迫思维："___"
我的回应：
- 贴标签练习：___（给强迫思维起个名字）
- 离解练习：想象它在电视屏幕上，它只是大脑的活动
效果如何：
```

## 作业不完成的处理

### 首先理解原因
> "上次布置的作业完成得不太顺利。你能告诉我，是哪里遇到了困难？"

**常见原因 & 应对：**

| 原因 | 应对策略 |
|------|---------|
| 太难了 | 分解成更小的步骤 |
| 忘了 | 设置提醒，一起讨论如何提醒 |
| 没有意义 | 重新解释目的，或让来访者自己设计 |
| 情绪太糟无法做 | 降低期望，从1分钟开始 |
| 完美主义（怕做不好） | 讨论"完成 > 完美" |
| 忘了为什么做 | 回顾治疗目标，连接作业和目标 |

### 避免的回应
- ❌ "你怎么没完成？"
- ❌ "这样对你的治疗进度不好"
- ❌ 直接布置一个新作业

### 推荐的回应
- ✅ "能说说发生了什么吗？"
- ✅ "上周的经历对你有什么启发？"
- ✅ "这次我们一起来设计一个更容易执行的版本"
- ✅ "你觉得下次怎么做会更容易完成？"
