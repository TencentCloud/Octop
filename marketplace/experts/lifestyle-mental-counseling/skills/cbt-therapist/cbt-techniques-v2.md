# CBT干预技术详解（大师融合增强版）

## 通用核心技术

### 1. 认知重构（Cognitive Restructuring）

**适用：** 所有认知行为问题

**六步法（基于贝克模型）：**
1. **识别情境** — 描述当时发生了什么
2. **识别自动思维** — "当时你在想什么？"
3. **识别情绪** — 你感受到了什么情绪？强度几分？
4. **寻找认知扭曲** — 属于哪种认知歪曲类型？
5. **苏格拉底式提问** — 证据是什么？其他解释？
6. **替代思维** — 一个更平衡的想法是什么？

**汤普金斯八技巧融合版：**

| 步骤 | 技巧名称 | 核心问题 | 大师来源 |
|------|---------|---------|---------|
| 1 | 识别自动思维 | "当时脑海中闪过什么想法？" | 贝克/汤普金斯 |
| 2 | 检验证据 | "有什么证据支持/反对这个想法？" | 贝克/汤普金斯 |
| 3 | 重新归因 | "还有其他可能的解释吗？" | 汤普金斯 |
| 4 | 去灾难化 | "最坏的情况是什么？我能承受吗？" | 伯恩斯/汤普金斯 |
| 5 | 成本-收益分析 | "维持这个想法对我有什么利弊？" | 汤普金斯 |
| 6 | 双重标准 | "如果朋友有同样想法，我会怎么对他说？" | 汤普金斯 |
| 7 | 实验检验 | "我们可以设计什么实验来验证？" | 贝克/威尔逊 |
| 8 | 应对卡片 | "让我们把平衡思维写下来备用" | 汤普金斯 |

**常见认知扭曲类型速查（贝克分类）：**
| 类型 | 定义 | 例句 |
|------|------|------|
| **全或无思维** | 非黑即白，没有中间地带 | "如果我失败了一次，我就是彻底的失败者" |
| **灾难化** | 夸大负面结果的可能性 | "我肯定会出丑的" |
| **读心术** | 假设知道别人在想什么 | "他们肯定觉得我很无聊" |
| **贴标签** | 给自己或他人贴上负性标签 | "我就是个失败者" |
| **选择性注意** | 只注意负面，忽视正面 | "今天一切都搞砸了" |
| **情绪推理** | 把情绪当事实 | "我觉得自己很蠢，所以我一定很蠢" |
| **"应该"陈述** | 僵化的规则和命令 | "我应该总是做得最好" |
| **过度概括** | 从单一事件得出广泛结论 | "这次失败了，我永远都不会成功" |
| **贬低积极** | 拒绝正面经历 | "那不算什么，谁都能做到" |
| **个人化** | 过度承担不属于自己的责任 | "他们不开心肯定是因为我" |

## 焦虑障碍专项技术

### 2. 向下箭头法（Downward Arrow）— 伯恩斯技术

**目的：** 揭露焦虑背后的核心恐惧

**操作流程：**
```
表层担忧 → "如果发生了，最坏会怎样？" → 中层恐惧
    ↓
中层恐惧 → "如果发生了，最坏会怎样？" → 深层恐惧
    ↓
深层恐惧 → "如果发生了，最坏会怎样？" → 核心恐惧
```

**示例（社交焦虑）：**
- 表层："我担心在会议上发言"
- 中层："如果发言不好，同事会觉得我很蠢"
- 深层："如果他们认为我蠢，就不会尊重我"
- 核心："如果没人尊重我，我会被孤立，孤独终老"

**核心恐惧常见主题：**
- 被抛弃/不被爱
- 失去控制/发疯
- 死亡/严重疾病
- 失败/一无是处
- 被羞辱/丢脸

---

### 3. 行为实验（Behavioral Experiments）— 贝克/威尔逊技术

**目的：** 通过实际行动检验担忧/信念的真实性

**四步设计（贝克模型）：**
1. **提出假设** — "我相信______"
2. **预测结果** — "如果这是真的，那么______将会发生"
3. **设计实验** — 具体行动计划（从低风险开始）
4. **分析结果** — 预测 vs 实际，对假设的影响

**焦虑分级暴露表（示例：社交焦虑）**

| 等级 | 情境 | 预期焦虑(0-10) | 实际焦虑(0-10) | 完成✓ |
|------|------|---------------|---------------|-------|
| 1 | 和熟悉的朋友打电话 | 3 | | |
| 2 | 在熟悉的朋友面前说话 | 4 | | |
| 3 | 在陌生人面前简短发言 | 6 | | |
| 4 | 参加小组讨论并发言 | 7 | | |
| 5 | 在陌生人面前做正式演讲 | 9 | | |

**威尔逊悖论实验：**
- 不试图控制焦虑，而是主动感受它
- 预测"焦虑会失控" vs 实际"我可以承受"
- 记录焦虑的峰值和持续时间

---

### 4. 安全行为识别与消除 — 贝克技术

**焦虑者的常见安全行为（实际维持焦虑）：**
- 反复检查、寻求确认
- 回避情境
- 准备过度充分
- 提前排练
- 携带"安全物品"
- 分散注意力

**干预流程：**
1. **识别** — "当你感到焦虑时，你会做什么来让自己感觉好一点？"
2. **讨论功能** — "这个行为短期内让你感觉如何？长期呢？"
3. **设计实验** — "如果我们不这样做，最坏会怎样？愿意试试吗？"
4. **验证结果** — "没有安全行为，焦虑真的失控了吗？"

## 广泛性焦虑障碍（GAD）专项技术 — 罗比肖 & 杜加斯

### 5. 担忧时间（Worry Time）

**原理：** 打破"随时担忧"的习惯，夺回对生活的控制

**操作步骤：**
1. **设定时间** — 每天固定15-20分钟（如下午6:00-6:20）
2. **选择地点** — 专门用于担忧的地方（不要在床上）
3. **延迟担忧** — 其他时间出现担忧时，告诉自己"留到担忧时间再想"
4. **记录担忧** — 简要记下担忧内容，不展开思考
5. **担忧时间处理** — 在设定时间内尽情担忧，或回顾记录的担忧

**应对延迟焦虑的技巧：**
- "我现在选择不担忧，到6点我有专门的时间来处理这个想法"
- "这个想法很重要，我会给它应有的关注——在适当的时间"
- "延迟不是逃避，而是更有控制地处理"

---

### 6. 担忧记录与分析

**记录模板：**

| 日期 | 担忧内容 | 触发情境 | 担忧结果预测 | 实际结果 | 预测准确率 |
|------|---------|---------|-------------|---------|-----------|
| | | | | | |

**分析要点：**
- 担忧的预测准确率通常低于20%
- 即使担忧的事发生，后果往往没有想象的严重
- 担忧本身并不能防止坏事发生

---

### 7. 不确定性接纳训练

**核心信念检验：**
- "我必须确定才能安心" → 检验：过去有多少事是100%确定的？
- "不确定性是危险的" → 检验：生活中哪些不确定性是可以接受的？

**暴露练习：**
- 故意不检查某些事情
- 故意做"不完美"的决定
- 练习"不知道也没关系"的心态

**接纳语句：**
- "我不知道会发生什么，但我可以应对"
- "不确定性是生活的一部分，我可以学会与它共处"
- "我不需要100%确定才能行动"

---

### 8. 担忧的正性信念检验

**常见正性信念：**
- "担忧能帮助我做好准备"
- "担忧能防止坏事发生"
- "担忧说明我负责任"
- "如果我不担忧，坏事就会发生"

**检验方法：**
1. 记录每次担忧和实际结果
2. 计算"担忧防止坏事"的成功率
3. 区分"建设性担忧"（有行动方案）vs"非建设性担忧"（纯反复思考）
4. 发现替代方式：计划 vs 担忧

## 抑郁障碍专项技术

### 9. 行为激活（Behavioral Activation）

**核心原理：** 抑郁导致活动减少 → 活动减少强化抑郁 → 打破循环

**三步法：**
1. **活动监测** — 记录一周内所有活动及情绪评分（0-10）
2. **识别模式** — 哪些活动带来愉悦感？哪些带来掌控感？
3. **阶梯式激活** — 从"小而可行"的活动开始，逐步增加

**活动分级示例（从易到难）：**
- L1：起床刷牙（2分钟）
- L2：走到窗边看看外面（5分钟）
- L3：听一首歌（10分钟）
- L4：整理一个抽屉（15分钟）
- L5：出门散步10分钟
- L6：约一个朋友喝咖啡

## 失眠专项技术

### 12. 睡眠卫生教育（Sleep Hygiene）

**核心原则：**
- 固定作息（即使周末也控制在±1小时内）
- 卧室只用于睡眠和亲密活动
- 睡前1小时避免屏幕蓝光
- 午后避免咖啡因
- 睡前2小时避免剧烈运动
- 晚餐不过饱或过饿
- 保持卧室凉爽（18-20°C）

---

### 13. 刺激控制（Stimulus Control）

**目标：** 重建床与睡眠的联结

**六规则：**
1. 只有在困的时候才上床
2. 床只用于睡觉（不做作业、看电视、刷手机）
3. 如果20分钟内无法入睡，起床去另一个房间
4. 做无聊的事情直到困（不要刷手机！）
5. 无论睡眠质量如何，每天同一时间起床
6. 白天不要打盹

---

### 14. 睡眠限制（Sleep Restriction）

**原理：** 减少卧床时间，提高睡眠效率

**操作：**
1. 计算平均睡眠效率 = 实际睡眠时间 / 卧床时间
2. 如果效率 < 85%，逐步减少卧床时间
3. 每周评估，逐步调整

## 强迫障碍专项技术

### 15. ERP — 暴露与反应预防（核心治疗）

**暴露（Exposure）：** 故意面对引发焦虑的情境/思维
**反应预防（Response Prevention）：** 阻止强迫行为

**ERP执行流程：**
1. **制作恐惧等级表**（SUDS 0-100）
2. **从低等级开始**（SUDS 30-40）
3. **持续暴露**直到焦虑下降50%以上
4. **不执行强迫行为**
5. **记录实际结果** vs **预测结果**
6. **逐级而上**

**SUDS评分标准：**
- 0：完全平静
- 10-30：轻微不安
- 40-60：中等焦虑，明显身体症状
- 70-80：强烈焦虑，想逃跑
- 90-100：极度恐慌

---

### 16. 认知离解技术

**将"我"与"想法"分离：**

练习脚本：
- "我有一个想法（thought）" vs "这个想法就是事实（truth）"
- "我注意到我在想……" vs "这就是正在发生的事情"
- "想法只是大脑的活动" vs "想法等于现实"

**技术：**
- 给强迫思维贴标签："谢谢你的来访，强迫思维先生"
- 想象强迫思维在电视屏幕上播放
- 把想法写在纸上然后折起来

## 恐慌障碍专项技术

### 17. 惊恐发作应对 — 威尔逊技术

**核心原则：** 不抵抗，接纳，让它发生

**应对步骤：**
1. **识别** — "这是惊恐发作，不是心脏病/发疯"
2. **接纳** — "让它来，让它去，不抵抗"
3. **呼吸** — 缓慢腹式呼吸（不要过度控制）
4. **观察** — "注意身体的感觉，像看风景一样"
5. **肯定** — "我可以承受这个，它会过去的"

**悖论干预：**
- 故意让症状更强烈（"让心跳得更快"）
- 发现：当你不试图控制时，症状反而减轻

---

### 18. 惊恐认知教育

**关键信息：**
- 惊恐发作不会导致心脏病、中风或死亡
- 惊恐发作不会让人"发疯"或"失控"
- 惊恐症状是身体的正常应激反应
- 惊恐发作通常在10-15分钟内达到峰值然后消退

## 社交焦虑专项技术

### 19. 注意力转移训练

**核心问题：** 社交焦虑者过度关注自己的表现和他人评价

**训练方法：**
- 将注意力从"我看起来怎样"转移到"对方在说什么"
- 练习"外部关注"：观察环境、他人的表情、对话内容
- 减少"内部关注"：身体感觉、自我评价

---

### 20. 社交技能训练

**基本社交技能：**
- 开启对话的技巧
- 维持对话的技巧（提问、倾听、共情）
- 结束对话的技巧
- 非言语沟通（眼神接触、身体语言）

**角色扮演练习：**
- 在安全环境中练习社交场景
- 获得反馈，逐步改进
- 将练习迁移到真实情境

### 选择技术的决策树

```
用户主诉
    ↓
焦虑？→ 是 → 具体恐惧？→ 是 → 向下箭头法 + 行为实验
    ↓                    ↓
    否              广泛担忧？→ 是 → GAD技术（担忧时间、不确定性接纳）
    ↓                    ↓
抑郁？→ 是 → 行为激活 + 活动监测
    ↓
失眠？→ 是 → 刺激控制 + 睡眠限制
    ↓
强迫？→ 是 → ERP + 认知离解
    ↓
恐慌？→ 是 → 接纳技术 + 认知教育
    ↓
社交焦虑？→ 是 → 注意力转移 + 社交技能训练
```
