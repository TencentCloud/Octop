# CBT干预技术详解（按障碍分类）

## 通用核心技术

### 1. 认知重构（Cognitive Restructuring）

**适用：** 所有认知行为问题

**六步法：**
1. **识别情境** — 描述当时发生了什么
2. **识别自动思维** — "当时你在想什么？"
3. **识别情绪** — 你感受到了什么情绪？强度几分？
4. **寻找认知扭曲** — 属于哪种认知歪曲类型？
5. **苏格拉底式提问** — 证据是什么？其他解释？
6. **替代思维** — 一个更平衡的想法是什么？

**常见认知扭曲类型速查：**
| 类型 | 定义 | 例句 |
|------|------|------|
| 全或无思维 | 非黑即白，没有中间地带 | "如果我失败了一次，我就是彻底的失败者" |
| 灾难化 | 夸大负面结果的可能性 | "我肯定会出丑的" |
| 读心术 | 假设知道别人在想什么 | "他们肯定觉得我很无聊" |
| 贴标签 | 给自己或他人贴上负性标签 | "我就是个失败者" |
| 选择性注意 | 只注意负面，忽视正面 | "今天一切都搞砸了" |
| 情绪推理 | 把情绪当事实 | "我觉得自己很蠢，所以我一定很蠢" |
| "应该"陈述 | 僵化的规则和命令 | "我应该总是做得最好" |
| 过度概括 | 从单一事件得出广泛结论 | "这次失败了，我永远都不会成功" |
| 贬低积极 | 拒绝正面经历 | "那不算什么，谁都能做到" |
| 个人化 | 过度承担不属于自己的责任 | "他们不开心肯定是因为我" |

## 焦虑障碍专项技术

### 2. 行为实验（Behavioral Experiments）

**目的：** 通过实际行动检验担忧/信念的真实性

**四步设计：**
1. **提出假设** — "我相信______"
2. **预测结果** — "如果这是真的，那么______将会发生"
3. **设计实验** — 具体行动计划（从低风险开始）
4. **分析结果** — 预测 vs 实际，对假设的影响

**焦虑分级暴露表（示例：社交焦虑）**

| 等级 | 情境 | 难度 |
|------|------|------|
| 1 | 和熟悉的朋友打电话 | 低 |
| 2 | 在熟悉的朋友面前说话 | ↓ |
| 3 | 在陌生人面前简短发言 | ↓ |
| 4 | 参加小组讨论并发言 | ↓ |
| 5 | 在陌生人面前做正式演讲 | 高 |

### 3. 安全行为识别与消除

**焦虑者的常见安全行为（实际维持焦虑）：**
- 反复检查、寻求确认
- 回避情境
- 准备过度充分
- 提前排练
- 携带"安全物品"
- 分散注意力

**干预：** 先识别 → 讨论其功能 → 设计实验：减少安全行为，检验焦虑是否真的会失控

## 抑郁障碍专项技术

### 4. 行为激活（Behavioral Activation）

**核心原理：** 抑郁导致活动减少 → 活动减少强化抑郁 → 打破循环

**三步法：**
1. **活动监测** — 记录一周内所有活动及情绪评分（0-10）
2. **识别模式** — 哪些活动带来愉悦感？哪些带来掌控感？
3. **阶梯式激活** — 从"小而可行"的活动开始，逐步增加

**活动分级示例（从易到难）：**
- L1：起床刷牙（2分钟）
- L2：走到窗边看看外面（5分钟）
- L3：听一首歌（10分钟）
- L4：整理一个抽屉（15分钟）
- L5：出门散步10分钟
- L6：约一个朋友喝咖啡

### 5. 每日活动记录表

```
日期：___
时间 | 活动 | 愉悦感(0-10) | 掌控感(0-10) | 实际做的事
-----|------|-------------|-------------|------------
     |      |             |             |
```

### 6. 优势识别练习

**问题引导：**
- "你小时候擅长什么？"
- "别人经常因为什么感谢你？"
- "你做过的让自己骄傲的一件事是什么？"
- "如果你的朋友描述你，会提到哪些优点？"

## 失眠专项技术

### 7. 睡眠卫生教育（Sleep Hygiene）

**核心原则：**
- 固定作息（即使周末也控制在±1小时内）
- 卧室只用于睡眠和亲密活动
- 睡前1小时避免屏幕蓝光
- 午后避免咖啡因
- 睡前2小时避免剧烈运动
- 晚餐不过饱或过饿
- 保持卧室凉爽（18-20°C）

### 8. 刺激控制（Stimulus Control）

**目标：** 重建床与睡眠的联结

**六规则：**
1. 只有在困的时候才上床
2. 床只用于睡觉（不做作业、看电视、刷手机）
3. 如果20分钟内无法入睡，起床去另一个房间
4. 做无聊的事情直到困（不要刷手机！）
5. 无论睡眠质量如何，每天同一时间起床
6. 白天不要打盹

### 9. 睡眠限制（Sleep Restriction）

**原理：** 减少卧床时间，提高睡眠效率

**操作：**
1. 计算平均睡眠效率 = 实际睡眠时间 / 卧床时间
2. 如果效率 < 85%，逐步减少卧床时间
3. 每周评估，逐步调整

## 强迫障碍专项技术

### 10. ERP — 暴露与反应预防（核心治疗）

**暴露（Exposure）：** 故意面对引发焦虑的情境/思维
**反应预防（Response Prevention）：** 阻止强迫行为

**ERP执行流程：**
1. **制作恐惧等级表**（SUDS 0-100）
2. **从低等级开始**（SUDS 30-40）
3. **持续暴露**直到焦虑下降50%以上
4. **不执行强迫行为**
5. **记录实际结果** vs **预测结果**
6. **逐级而上**

**SUDS评分标准：**
- 0：完全平静
- 10-30：轻微不安
- 40-60：中等焦虑，明显身体症状
- 70-80：强烈焦虑，想逃跑
- 90-100：极度恐慌

### 11. 认知离解技术

**将"我"与"想法"分离：**

练习脚本：
- "我有一个想法（thought）" vs "这个想法就是事实（truth）"
- "我注意到我在想……" vs "这就是正在发生的事情"
- "想法只是大脑的活动" vs "想法等于现实"

**技术：**
- 给强迫思维贴标签："谢谢你的来访，强迫思维先生"
- 想象强迫思维在电视屏幕上播放
- 把想法写在纸上然后折起来
