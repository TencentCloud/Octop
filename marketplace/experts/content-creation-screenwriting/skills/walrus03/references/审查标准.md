# 多轮审查标准细则

## 第一轮：结构审查（总分10分，≥8分通过）

### 1. 钩子强度（25%）

| 等级 | 得分 | 标准 |
|------|------|------|
| 优秀 | 9-10 | 开头3秒制造强烈冲突/悬念/反差，观众必看 |
| 良好 | 7-8 | 开头有吸引力，能引起好奇心 |
| 一般 | 5-6 | 开头平淡，需要耐心看下去 |
| 较差 | <5 | 开头无聊，容易弃剧 |

**加分项**：
- 开场有金句：+0.5分
- 开场有反转：+1分
- 开场有悬念：+0.5分

### 2. 节奏控制（20%）

| 等级 | 得分 | 标准 |
|------|------|------|
| 优秀 | 9-10 | 每30秒一个转折点，节奏紧凑 |
| 良好 | 7-8 | 有节奏变化，但偶有拖沓 |
| 一般 | 5-6 | 节奏较慢，有注水内容 |
| 较差 | <5 | 平铺直叙，毫无波澜 |

### 3. 三幕比例（15%）

| 幕 | 标准比例 | 允许误差 |
|----|----------|----------|
| 第一幕（铺垫） | 15% | 10%-20% |
| 第二幕（对抗） | 70% | 60%-80% |
| 第三幕（解决） | 15% | 10%-20% |

### 4. 场景连贯（15%）

| 等级 | 得分 | 标准 |
|------|------|------|
| 优秀 | 9-10 | 场景切换自然，有过渡，有逻辑 |
| 良好 | 7-8 | 场景基本连贯，偶有跳跃 |
| 一般 | 5-6 | 场景跳跃明显 |
| 较差 | <5 | 场景混乱，逻辑不通 |

### 5. 结局闭环（25%）

| 等级 | 得分 | 标准 |
|------|------|------|
| 优秀 | 9-10 | 所有伏笔回收，结局有升华 |
| 良好 | 7-8 | 主要伏笔回收，次要伏笔可忽略 |
| 一般 | 5-6 | 部分伏笔未回收 |
| 较差 | <5 | 大量伏笔烂尾 |

## 第二轮：情感审查（总分10分，≥7.5分通过）

### 1. 情感共鸣（25%）

| 检查点 | 说明 |
|--------|------|
| 共情点数量 | 至少3个能让观众产生共鸣的点 |
| 共鸣类型 | 亲情、友情、爱情、梦想、尊严等 |
| 代入感 | 观众能否代入主角视角 |

### 2. 人物弧光（20%）

| 检查点 | 说明 |
|--------|------|
| 成长变化 | 主角从开始到结束是否有成长 |
| 内心转变 | 主角的三观/态度是否有变化 |
| 行为动机 | 人物行为是否有合理动机支撑 |

### 3. 情绪曲线（20%）

| 检查点 | 说明 |
|--------|------|
| 起伏设计 | 是否有明确的情绪起伏 |
| 高潮点 | 是否有情绪释放的高潮点 |
| 压抑释放 | 压抑情绪后是否有爽感释放 |

### 4. 金句设计（15%）

| 检查点 | 说明 |
|--------|------|
| 金句数量 | 每集至少1句传播金句 |
| 金句质量 | 金句是否有传播力/共鸣力 |
| 位置设计 | 金句是否在情绪高点 |

### 5. 泪点/爽点（20%）

| 检查点 | 说明 |
|--------|------|
| 爽点数量 | 每集至少2个爽点 |
| 爽点分布 | 爽点是否分散在剧情中 |
| 泪点设计 | 是否有催泪情节（可选） |

---

## 第三轮：合规审查（必须全部通过）

### 1. 血腥暴力（必须通过）

| 禁止内容 | 替代表达 |
|----------|----------|
| 流血场面 | 用"受伤"、"红肿"代替 |
| 厮杀场景 | 用"激烈对抗"、"冲突"代替 |
| 殴打暴力 | 用"推搡"、"争吵"代替 |
| 死亡描写 | 用"离开"、"消失"代替 |

### 2. 色情低俗（必须通过）

| 禁止内容 | 标准 |
|----------|------|
| 擦边内容 | 无任何性暗示或性描写 |
| 不当暗示 | 无暧昧场景或暗示性描写 |
| 语言低俗 | 无粗口或不当用语 |

### 3. 政治敏感（必须通过）

| 禁止内容 |
|----------|
| 政治人物 |
| 政治事件 |
| 政治制度 |
| 敏感地区 |

### 4. 抄袭风险（必须通过）

| 标准 | 说明 |
|------|------|
| 查重率 | 与已知作品重复度<30% |
| 创新性 | 核心剧情/人物是否原创 |
| 套路化 | 是否过度使用老套剧情 |

### 5. 平台合规（必须通过）

| 平台 | 特殊要求 |
|------|----------|
| 抖音 | 时长1-3分钟，适合竖屏 |
| 快手 | 时长1-5分钟，贴近生活 |
| 微信视频号 | 时长1-10分钟，社交属性强 |
| B站 | 时长5-30分钟，可更长 |

### 6. 价值导向（必须通过）

| 检查点 | 说明 |
|--------|------|
| 正能量 | 传递积极向上的价值观 |
| 三观正 | 符合主流价值观 |
| 有意义 | 剧情有深层意义或启示 |
