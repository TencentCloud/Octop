# 各平台合规要求与规范

## 抖音平台

### 内容规范
- **时长**：单集1-3分钟
- **竖屏**：必须竖屏拍摄
- **开头**：前3秒必须有吸引力
- **完播率**：设计促进完播的内容

### 禁止内容
| 类别 | 禁止内容 |
|------|----------|
| 血腥暴力 | 血腥场面、暴力打斗、武器展示 |
| 色情低俗 | 暴露穿着、暧昧场景、擦边内容 |
| 政治敏感 | 政治人物、政治事件、敏感话题 |
| 虚假信息 | 谣言、虚假宣传、误导内容 |
| 违法犯罪 | 违法行为、犯罪过程、违规操作 |

### 违规后果
- 限流/下架
- 账号处罚
- 封禁处理

## 通用平台规范

### 版权要求
- 使用原创内容
- 获得授权的音乐/素材
- 避免侵犯他人版权
- 注明素材来源

### 肖像权
- 使用授权人物
- 避免暴露隐私
- 获得当事人同意

### 音乐/音效
- 使用正版音乐
- 避免未经授权使用热门歌曲
- 注意音量平衡

### 广告植入
- 明确标注广告内容
- 不得虚假宣传
- 遵守《广告法》

## 内容安全红线

### 绝对红线（零容忍）
1. **危害国家安全**：任何涉及国家安全的敏感内容
2. **分裂国家**：任何分裂国家统一的内容
3. **恐怖主义**：任何恐怖主义相关内容
4. **色情内容**：任何色情内容
5. **违法犯罪**：任何违法犯罪的指导或展示

### 严重违规（重点打击）
1. **血腥暴力**：过于血腥暴力的场面
2. **低俗内容**：色情擦边、低俗表演
3. **谣言传播**：传播虚假信息
4. **侵权盗版**：侵犯版权内容
5. **恶意营销**：虚假广告、诱导消费

### 一般违规（规范管理）
1. **质量低劣**：制作粗糙、内容无价值
2. **标题党**：标题与内容不符
3. **过度营销**：频繁推销商品
4. **引战内容**：挑拨粉丝对立
