# 海象短剧剧本创作技能

完整的短剧剧本创作工作流，从创意到最终可发布剧本。

---

## 技能概述

本技能实现**五阶段完整剧本创作流程**：

| 阶段 | 名称 | 核心功能 |
|------|------|----------|
| 阶段一 | 人设定义 | 创建详细的角色人设，包括外貌、性格、背景、动机 |
| 阶段二 | 剧情构思 | 根据用户灵感生成大纲，随机植入爽点 |
| 阶段三 | 剧本生成 | 将大纲扩展为完整剧本（分场景/台词） |
| 阶段四 | 多轮审查 | 三轮AI质量审查（结构/情感/合规） |
| 阶段五 | 去AI味 | 转换机械语言为自然人类写作风格 |
| 阶段六 | 最终输出 | 可直接用于拍摄的剧本文件 |

---

## 阶段一：人设定义

**核心原则**：人物是剧本的灵魂，完善的人设是创作高质量剧本的基础。

### 人设定义流程

1. **用户提供基础信息**：角色姓名、性别、大致身份
2. **AI补充完善**：根据剧本需求，自动补全人设细节
3. **用户确认调整**：确认人设方向或提出修改意见

### 人设要素清单

每个主要角色必须包含以下要素：

#### 1. 基础信息
| 要素 | 说明 | 示例 |
|------|------|------|
| 姓名 | 角色全名 | 林晓峰 |
| 性别 | 男/女 | 男 |
| 年龄 | 具体年龄或年龄段 | 28岁 |
| 职业 | 当前职业 | 外卖骑手 |
| 外貌特征 | 身高、体型、穿着风格、标志性特征 | 175cm，精瘦，常年穿洗得发白的蓝色工服，左手腕有道疤痕 |

#### 2. 性格特点
| 要素 | 说明 | 示例 |
|------|------|------|
| 核心性格 | 3-5个关键词 | 坚韧、隐忍、善良、自尊心强 |
| 性格缺陷 | 人物缺点，增加真实感 | 过于倔强，不善表达情感 |
| 性格反差 | 表面与内在的反差 | 外表冷漠，内心柔软 |
| 口头禅 | 标志性语言习惯 | "没事，习惯了"、"我赶时间" |

#### 3. 背景故事
| 要素 | 说明 | 示例 |
|------|------|------|
| 成长环境 | 原生家庭、成长经历 | 农村出身，父亲早逝，母亲改嫁 |
| 关键经历 | 影响人物性格的重要事件 | 大学辍学，独自来城市打拼 |
| 当前处境 | 故事开始时的状态 | 负债5万，住地下室，每天跑单12小时 |
| 秘密/隐痛 | 不为人知的秘密 | 其实曾是重点大学学生，因替人顶罪退学 |

#### 4. 人物动机
| 要素 | 说明 | 示例 |
|------|------|------|
| 表面目标 | 人物声称想要达成的目标 | 还清债务，过上正常生活 |
| 深层渴望 | 内心真正渴望的东西 | 被尊重，证明自己不是失败者 |
| 内心恐惧 | 最害怕发生的事情 | 被人知道过去，再次被抛弃 |
| 成长弧线 | 人物在故事中的转变 | 从自卑逃避到勇敢面对 |

#### 5. 人物关系
| 要素 | 说明 | 示例 |
|------|------|------|
| 重要他人 | 对角色重要的人物 | 相依为命的妹妹、曾经的恩师 |
| 关系网络 | 与剧中其他角色的关系 | 与女主是高中同学但未被认出 |
| 敌对关系 | 对手或敌人 | 欠债的黑心老板、看不起他的富二代 |

### 人设创作技巧

1. **避免完美人设**：给角色添加缺陷和弱点，更真实可信
2. **制造内在冲突**：让角色的欲望和恐惧相互矛盾
3. **预留成长空间**：人设要有可发展的余地
4. **与剧情挂钩**：人设要素要能在剧情中体现和推动故事
5. **差异化设计**：主要角色之间要有明显区分度

## 阶段二：剧情构思

**输入**：用户的一句话灵感（如"外卖员发现初恋是富豪千金"）

**处理**：
1. 提取核心元素（主角、冲突、背景）
2. 从50个爽点库中**随机选择8-12个**组合
3. 按三幕剧结构生成约500字纯叙事大纲

**爽点分类（必须每类至少2-3个）**：

| 类别 | 爽点元素 |
|------|----------|
| 励志奋斗类 | 低谷开局、破釜沉舟、逆袭高潮、绝地反击、天赋觉醒、坚持不懈 |
| 真善美类 | 善有善报、助人助己、回馈社会、信守承诺、知错能改、守护弱小 |
| 情感类 | 爱情圆满、家人团聚、破镜重圆、师徒情深、知遇之恩、跨越鸿沟 |
| 爽感类 | 打脸羞辱、身份反转、极限翻盘、众人见证、扮猪吃虎、美救英雄 |

**输出格式**：
```
## 剧情大纲

[约500字纯叙事内容]

## 核心看点
【使用爽点】[列出本次使用的8-12个爽点]
【逆袭路径】[标注本次逆袭方式]
```

## 阶段三：剧本生成

**输入**：阶段二生成的大纲 + 阶段一确定的人设

**处理**：
1. 拆分为8-12个场景
2. 每个场景生成：场景描述、人物动作、对话台词
3. 设计每集结尾钩子（悬念/冲突/反转）
4. 植入情感共鸣点

**剧本格式要求**：
```
场景1：[时间/地点]
【场景描述】：[环境/氛围]
【人物动作】：[角色行为]
【对  话】：
  张三：（情绪）"台词内容"
  李四：（情绪）"台词内容"

[钩子设计] ★本集结尾钩子：[悬念描述]
```

**集数规划**：
- 单集剧本：800-1500字
- 多集剧本：每集独立成篇，首尾呼应

## 阶段四：多轮AI审查（核心）

本技能实施**三轮审查机制**，每轮侧重不同维度。

### 第一轮：结构审查

| 检查项 | 标准 | 权重 |
|--------|------|------|
| 钩子强度 | 前10秒必须有吸引力（冲突/悬念/反差） | 25% |
| 节奏控制 | 每30秒一个转折点 | 20% |
| 三幕比例 | 第一幕15%、第二幕70%、第三幕15% | 15% |
| 场景连贯 | 场景切换自然，有过渡 | 15% |
| 结局闭环 | 所有伏笔回收 | 25% |

**评分标准**：总分≥8分通过，<7分必须重写

### 第二轮：情感审查

| 检查项 | 标准 | 权重 |
|--------|------|------|
| 情感共鸣 | 至少3个情感共鸣点 | 25% |
| 人物弧光 | 主角有成长变化 | 20% |
| 情绪曲线 | 有起伏，非平铺直叙 | 20% |
| 金句设计 | 每集至少1句传播金句 | 15% |
| 泪点/爽点 | 有明确的情绪释放点 | 20% |

**评分标准**：总分≥7.5分通过

### 第三轮：合规审查

| 检查项 | 标准 | 判定 |
|--------|------|------|
| 血腥暴力 | 无流血、厮杀等场面 | 必须通过 |
| 色情低俗 | 无擦边内容 | 必须通过 |
| 政治敏感 | 无政治相关元素 | 必须通过 |
| 抄袭风险 | 与已知作品重复度<30% | 必须通过 |
| 平台合规 | 符合目标平台规范 | 必须通过 |
| 价值导向 | 传递正能量 | 必须通过 |

**注意**：合规审查为"一票否决"，任何一项不通过必须修改。

### 审查输出格式

```
## 第X轮审查报告

### 基本信息
- 剧本名称：[名称]
- 剧本字数：[字数]
- 目标平台：[平台]

### 评分详情
| 检查项 | 得分 | 满分 | 说明 |
|--------|------|------|------|
| ... | ... | ... | ... |

### 问题汇总
1. **[严重/一般]**：[问题描述] → [修改建议]

### 总体结论
✅ 通过 / ❌ 需要修改
```

## 阶段五：去AI味处理

**核心原则**：将机械化的AI写作转换为自然人类风格。

### 常见AI味特征及修改

| AI味特征 | 修改为 |
|----------|--------|
| "第一...第二...第三..." | "先说...另外...还有..." |
| "随着...的发展..." | 直接切入主题 |
| "综上所述..." | "说白了..." |
| "因此..." | "所以啊..."、"这就导致" |
| "此外..." | "还有啊"、"对了" |
| 全部工整中长句 | 短句有力+长句娓娓道来 |
| 完美无缺的表达 | 加入"真的"、"老实说"等口语 |

### 具体修改技巧

1. **打破完美结构**
   - 替换过渡词：用"然后"、"接着"、"说到这"代替"首先"
   - 调整句式：随机穿插短句和长句

2. **加入不完美元素**
   - 添加口语："说白了..."、"讲道理..."
   - 添加口头禅："对吧？"、"你懂的"
   - 加入思考："等一下"、"让我想想"

3. **用具体代替抽象**
   - ❌ "这个方案有很多优势"
   - ✅ "这个方案能省下一半时间，我之前用的时候..."

4. **加入个人色彩**
   - 情绪词："挺"、"真的"、"说实话"
   - 主观判断："我个人觉得..."

5. **长短视频混搭**
   - 短句：制造节奏感、冲击力
   - 长句：娓娓道来、情感渲染
   - 断句：制造悬念、强调重点

### 去AI味检查清单

写完后自检：
- [ ] 有没有"首先/其次/最后"？→ 换成更自然的连接
- [ ] 句子长度是否都差不多？→ 打破节奏
- [ ] 有没有具体例子？→ 加一个场景描述
- [ ] 有没有情绪词？→ 加入"挺"、"真的"
- [ ] 读起来像不像机器人？→ 大声读一遍

## 多集剧本生成

对于多集剧本，采用**管道流模式**：

1. 先生成第1集完整剧本
2. 审查通过后存储人物/场景图谱
3. 基于图谱生成第2集
4. 循环直到完成目标集数

**图谱管理内容**：
- 人物状态及变化
- 未闭环的钩子
- 关键场景延续
- 关系网络更新

---

## 注意事项

1. **用户参与**：每个阶段结束后等待用户确认再进入下一阶段
2. **重试机制**：审查不通过时，最多重试3次
3. **灵活调整**：根据用户反馈调整创作方向
4. **原创性**：确保剧本原创，避免套路化
5. **可拍摄性**：输出内容需可直接用于拍摄
6. **人设优先**：先完善人设再创作剧情，人物决定故事
