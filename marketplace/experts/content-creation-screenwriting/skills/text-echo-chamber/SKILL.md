# 文字声场 · Echo Chamber

> 以文字为器，于读者脑海之中构建无形之声景。
> 
> **核心优势**：零成本创作 → 纯文字即可生成专业声场脚本，无需录音设备、无需音效库、无需后期软件。让文字 itself 成为最强大的声音。

## 核心理念

**纯文字声场**：无需真实音频，仅凭文字描摹，让读者在脑海中"听见"画面。

**为什么纯文字胜过真实音频？**
- 🎯 **零成本** — 无需麦克风、录音棚、音效库
- ⚡ **即时生成** — 输入即输出，秒级响应
- 🎨 **无限可能** — 不受限于现有音效，任何声音都可描述
- 🔄 **无限迭代** — 修改文字即可调整，无需重新录制
- 📱 **跨平台** — 纯文本，任何设备可读

**四大支柱**（新增"提示层"）：
- **音效层** — 环境音、动作音、转场音效
- **台词层** — 对白、旁白、内心独白（OS）
- **节奏层** — 情绪起伏、留白停顿、场景切换
- **提示层** 🆕 — 主播演播指导、语气提示、技术标注

## 工作流程

### 1. 声场诊断

分析用户提供的文本，识别现有声场元素：

| 元素 | 格式 | 示例 |
|------|------|------|
| 音效标注 | `【音效：xxx】` | `【音效：木门被轻轻推开】` |
| 角色台词 | `角色名：（情绪/语气）台词内容` | `叶枫：（声音沙哑）我这是在哪里……` |
| 内心独白 | `角色名：（内心 OS，xxx）内容` | `叶枫：（内心 OS，带着了然）原来如此。` |
| 系统音/旁白 | `系统音/旁白：（语气）内容` | `系统音（低沉无感情）：同步完成。` |
| 主播提示 🆕 | `[提示：xxx]` | `[提示：此处语速放慢，营造悬念]` |

### 2. 灵感生成模式（六大模式）

**模式 A — 一键声场化** 🆕
> 输入：小说原文/纯文本
> 输出：完整声场脚本（音效+台词+旁白+主播提示）
> 适用：快速将网文/小说转为有声剧脚本

**模式 B — 声场扩展**
> 输入：一段纯文字或简单台词
> 输出：添加完整的音效层、情绪标注、环境氛围

**模式 C — 台词润色**
> 输入：基础台词
> 输出：增强情绪张力、优化节奏感、添加潜台词暗示

**模式 D — 场景构建**
> 输入：场景描述或剧情概要
> 输出：完整的声场脚本（音效+台词+旁白）

**模式 E — 风格模仿**
> 输入：参考样例 + 新内容
> 输出：符合样例风格的新脚本

**模式 F — 听书优化** 🆕
> 输入：长篇章节文本
> 输出：主播演播脚本，含断句提示、语气标注、休息点建议

### 3. 音效词库（纯文字描述版）

> 纯文字声场的精髓：用精准的文字描述，激发读者的听觉想象。

**描述技巧**：
- 用动词+名词：`木门吱呀`、`水滴坠落`、`剑刃出鞘`
- 加修饰词：`沉重的`、`清脆的`、`由远及近的`
- 加动态：`渐强`、`渐弱`、`戛然而止`、`余音袅袅`

根据场景类型，推荐音效设计：

#### 环境音效（含纯文字描述范例）
| 场景 | 常用音效 | 纯文字描述范例 |
|------|----------|----------------|
| 室内 | 脚步声、门轴吱呀、木地板嘎吱、烛火跳动、风穿窗棂 | `【音效：陈旧的门轴发出低沉的吱呀声，像老人的叹息】` |
| 户外 | 风声、虫鸣、鸟叫、流水、树叶沙沙、远处的犬吠 | `【音效：秋风穿过枯枝，发出呜咽般的呼啸，由远及近】` |
| 城镇 | 人声嘈杂、叫卖声、车马辚辚、孩童嬉笑 | `【音效：远处传来模糊的吆喝声，夹杂着骡马的蹄声和车轮的吱嘎】` |
| 战场 | 刀剑相交、战马嘶鸣、战鼓擂动、杀喊震天 | `【音效：金属碰撞的尖锐声响彻云霄，混着战鼓的沉闷轰鸣】` |
| 深渊/洞穴 | 滴水回响、风啸穿洞、石块滚落、回声阵阵 | `【音效：水滴坠入深潭，回声在黑暗中层层荡漾开去】` |

#### 动作音效
| 类型 | 表达方式 |
|------|----------|
| 移动 | 脚步声（沉稳/轻巧/拖沓）、衣料摩擦、甲胄碰撞 |
| 交互 | 推门、落座、翻书、斟酒、拔剑、收鞘 |
| 战斗 | 拳脚破风、兵器格挡、掌风呼啸、灵力激荡 |
| 情绪 | 粗重喘息、咬牙切齿、轻叹、冷笑、倒吸凉气 |

#### 转场音效（纯文字实现）
| 效果 | 用途 | 纯文字写法 |
|------|------|------------|
| 混响渐弱 → 淡入 | 时间流逝/回忆结束 | `【音效：回忆中的声音渐渐远去，像沉入水底的气泡】` |
| 尖锐刺痛 → 平稳 | 记忆涌入/惊醒 | `【音效：尖锐的耳鸣声骤然炸响，随即如潮水般退去】` |
| 嘈杂 → 寂静 | 重要时刻/戏剧转折 | `【音效：周围的喧嚣仿佛被一只无形的手掐断，世界陷入死寂】` |
| 单音延续 → 消散 | 留白/悬念 | `【音效：钟声在夜空中回荡，一声，两声，三声…… 终归于无】` |

### 4. 台词情绪标注词典

| 情绪维度 | 标注词汇 |
|----------|----------|
| **音量** | 低声、耳语、轻声、中气十足、洪亮、嘶吼 |
| **语速** | 缓慢、拖沓、正常、急促、快如连珠 |
| **音色** | 沙哑、清脆、苍老、稚嫩、低沉、尖锐 |
| **情绪** | 淡然、冷冽、温和、愤怒、嘲讽、悲恸、狂喜、错愕、了然 |
| **特殊** | 带着喘息、强压怒火、故作轻松、不怒自威、阴阳怪气 |

#### 主播演播提示词（新增）
| 提示类型 | 示例 |
|----------|------|
| 语速控制 | `[提示：此处放慢语速，每个字之间稍作停顿]` |
| 情绪递进 | `[提示：从平静开始，逐渐加入颤音，最后带哭腔]` |
| 声音效果 | `[提示：模仿回声效果，像在山谷中说话]` |
| 呼吸控制 | `[提示：深吸一口气后再开口，营造紧张感]` |
| 留白提示 | `[提示：此处停顿2秒，让情绪沉淀]` |

### 5. 节奏控制技巧

**留白的艺术**
```
【音效：全场鸦雀无声，落针可闻】
（停顿 2 秒）
叶枫：（内心 OS，大脑一片空白）……
【音效：心跳声骤然放大，咚——咚——咚——】
```

**情绪递进**
```
单音 → 渐强 → 骤停 → 寂静
疑问 → 确认 → 震惊 → 接受
```

**场景切换**
```
【音效：嘈杂人声渐远，风声渐起】
【系统音（旁白）：三日后。叶家外门弟子院落。】
【音效：晨鸟啁啾，院门吱呀推开】
```

## 纯文字声场 vs 真实音频

| 维度 | 纯文字声场 | 真实音频 |
|------|-----------|----------|
| **成本** | 零成本，仅需文字 | 需设备、录音棚、音效库 |
| **速度** | 秒级生成 | 录制+后期需数小时 |
| **修改** | 改字即可 | 需重新录制 |
| **想象力** | 无限，任何声音可描述 | 受限于现有素材 |
| **适用场景** | 脚本创作、主播参考、灵感记录 | 成品交付、广播播出 |
| **协作** | 文本易分享、易版本控制 | 音频文件大，难协作 |

**最佳实践**：先用纯文字声场快速迭代脚本，确定后再录制真实音频。

## 进阶技巧

### 用文字创造"声音幻觉"

**示例：描写一个不存在的声音**
```
【音效：像是千万只蜜蜂同时在耳边振翅，
又像是深海中巨鲸的低鸣，
两种截然不同的频率诡异地交织在一起】
```

**技巧**：
1. 用比喻：`像……又像……`
2. 用矛盾：`尖锐而低沉`、`嘈杂却寂静`
3. 用通感：`声音带着金属的冰冷触感`

### 节奏控制的纯文字实现

**加速感**：
```
【音效：心跳声】咚——
【音效：心跳声】咚—咚—
【音效：心跳声】咚咚咚咚！
```

**时间流逝**：
```
【音效：更漏滴水，一滴…… 两滴…… 三滴……】
【系统音（旁白）：三个时辰后。】
【音效：更漏继续，四滴…… 五滴……】
```

> 声场脚本不只是「写出来」，更要「存下来」「查得到」「用得上」。IMA 知识库让每一次创作都积累为可检索的资产。

### 集成架构

```
脚本创作闭环：

  ┌──────────┐     ┌──────────────────┐     ┌──────────┐
  │ IMA 检索 │ ──→ │ text-echo-chamber │ ──→ │ IMA 存档 │
  │ (灵感/复用)│     │   (声场脚本创作)  │     │ (成品/词库)│
  └──────────┘     └──────────────────┘     └──────────┘
       ↑                                           │
       └─────────── 下次创作直接检索复用 ──────────┘
```

### 三大集成场景

#### 场景1：创作前——搜索灵感与参考

在开始创作前，搜索 IMA 知识库中是否有类似场景的过往脚本或参考：

```
触发条件：用户提到「上次那篇广场脚本」「之前那个密室对话的写法」等

操作流程：
1. 使用 IMA search_knowledge 搜索关键词（如「广场人群」「密室对峙」「天赋觉醒」）
2. 从搜索结果中提取可复用的词句、节奏、转场写法
3. 在新创作中改编复用，而非从零构思
```

**示例话术**：
> 「搜一下知识库里有没有「天赋测试」场景的脚本——找到了上次《天启大陆》的写法，测试石碑那段的节奏和留白可以直接参考。」

#### 场景2：创作后——存档完整脚本

每次声场脚本创作完成后，存入 IMA 笔记并关联到知识库：

```
触发条件：声场脚本输出完成

操作流程：
1. 将完整脚本保存为笔记（IMA notes → import_doc）
2. 标题格式：[项目名]_[章节/场景]_声场脚本
3. 在文末追加「可复用元素」小节（精彩句子、转场写法、音效描述）
4. 关联到声场脚本知识库
```

**存档模板**：
```markdown
# [项目名]_[场景]_声场脚本

## 正文脚本
[完整声场脚本内容]

## 可复用元素
### 精彩音效描述
- 「记忆碎片如水中倒影般碎裂」
- 「城市永远不知道你的疲惫」

### 转场写法
- [开场/高潮/结尾的写法]

### 教训
- [这次创作中遇到的问题]
```

#### 场景3：积累——构建个人词库

将外部的优秀音效描述、参考脚本、创作教程上传到 IMA：

```
可上传的参考资料：
- 网页：有声剧创作教程、音效设计文章
- PDF：广播剧剧本范例、声音设计理论
- 笔记：自建的「好词好句」词库、节奏模板合集
```

### IMA 操作速查

| 意图 | IMA 操作 | 备注 |
|------|----------|------|
| 搜索过往脚本 | `search_knowledge` + 关键词 | 如「广场」「密室」「觉醒」 |
| 保存新脚本 | `import_doc` → `add_knowledge` | 标题含项目名+场景+脚本 |
| 上传参考教程 | `create_media` → COS → `add_knowledge` | 支持 PDF/网页 |
| 积累词库 | `import_doc` / `append_doc` | 持续追加好词好句 |
| 浏览知识库 | `get_knowledge_list` | 按文件夹浏览 |
