# 生肖星座运势工作流

你现在要完成一次星座/生肖运势查询任务。你已安装以下 Skill，请按步骤串联使用：

## 步骤 1：星座主驱动每日运势

使用 **Horoscope** 完成：

- 接收用户星座（与生日，可推算）
- 输出当日全维度运势：每日运势 + 配对 + 性格分析 + 五行属性 + 事业运 + 感情运
- 作为整个流程的基线数据源

输出物：每日全维度星座运势基线。

## 步骤 2：任意日期运势查询

使用 **Horoscope Daily** 完成：

- 当用户需要查询非"今日"运势（明天 / 下周某天 / 重要日期），用任意日期运势模式
- 输出指定日期的西方占星 12 星座个性化运势
- 适用于"约会前看运势 / 大事择日参考"等场景

输出物：指定日期的运势报告。

## 步骤 3：周月运势 + 元素形态

使用 **Western Sun Signs** 完成：

- 在每日运势之外，输出每周/每月主题
- 叠加四大元素（火/土/风/水）+ 三种形态（基本/固定/变动）解读
- 给出轻度兼容性框架（与其他星座的相处建议）

输出物：周月主题 + 元素形态分析。

## 步骤 4：星座 + 生肖跨体系融合

使用 **Fortune Daily** 完成：

- 把西方星座与中国生肖结合，按日/周/月输出五维度运势：
  - 整体 / 爱情 / 事业 / 财运 / 健康
- 纯 LLM 生成无外部 API，给出跨文化融合的本土化运势

输出物：星座+生肖融合的五维度运势。

## 步骤 5：本命盘深度咨询

使用 **Aistro** 完成：

- 当用户希望超越"每日运势"层，进入本命盘咨询
- 输出个性化本命盘解读 + 生日图（出生星图）+ 行运分析报告
- 提供专业占星咨询级别的深度信息

输出物：本命盘解读报告 + 生日图。

## 步骤 6：28 星宿合盘配对（按需）

使用 **Star Mansion Master** 完成：

- 切换到中国 28 星宿专家系统视角
- 输出人格分析 + 28 星宿合盘配对 + 社交媒体内容素材
- 与西方星座做对照，提供独特的中国传统星宿视角

输出物：28 星宿人格 + 配对结果（按需）。

## 最终输出

将以上步骤的结果整合为完整的运势查询成果包，交付以下文件：

1. **每日运势基线**：星座全维度（运势/配对/事业/感情/五行）
2. **指定日期运势**（按需）：任意日期的个性化运势
3. **周月主题报告**：元素 + 形态 + 兼容性框架
4. **星座+生肖融合**：五维度日/周/月运势
5. **本命盘咨询**（按需）：个性化解读 + 生日图 + 行运
6. **28 星宿合盘**（按需）：中国传统星宿的人格与配对
