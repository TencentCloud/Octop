# 行业专用口径

> 用法：拿到标的先判断行业，读对应小节。**通用指标套到特殊行业上会得出错误结论**，必须换成行业口径。
> 未覆盖的行业：按通用口径分析，并在报告里注明「未使用行业专用口径」。

## 1. 银行

**别用**：资产负债率、流动比率、毛利率、ROIC（口径不适用）。
**改用**：

| 指标 | 公式 / 口径 |
|---|---|
| 净息差 NIM | 利息净收入 / 平均生息资产 |
| 净利差 Spread | 生息资产收益率 − 计息负债成本率 |
| 不良率 NPL | 不良贷款 / 贷款总额 |
| 拨备覆盖率 | 贷款减值准备 / 不良贷款 |
| 拨贷比 | 贷款减值准备 / 贷款总额 |
| 关注类贷款占比 | 关注类 / 贷款总额（不良的前瞻指标） |
| 核心一级资本充足率 | 核心一级资本净额 / 风险加权资产 |
| 成本收入比 | 业务及管理费 / 营业收入 |
| ROE / RORWA | 归母净利润 / 平均归母净资产；净利润 / 风险加权资产 |

**要点**：看「不良 + 关注」合计、逾期 90 天以上贷款与不良的剪刀差（剪刀差 >100% 说明不良认定偏松）、拨备是否反哺利润。

## 2. 保险

**别用**：营业收入（保费收入不等于营收）、经营现金流（口径差异极大）。
**改用**：

| 指标 | 公式 / 口径 |
|---|---|
| 新业务价值 NBV 及增速 | 内含价值报告披露 |
| 新业务价值率 NBV Margin | NBV / 首年保费 |
| 内含价值 EV、剩余边际 | 内含价值报告披露 |
| 综合成本率 COR（财险） | (赔付支出 + 费用) / 已赚保费，<100% 承保盈利 |
| 退保率、继续率 | 13/25 个月保单继续率 |
| 偿付能力充足率 | 综合/核心偿付能力充足率（偿二代二期） |
| 投资收益率 | 净/总/综合投资收益率 |

**要点**：寿险看 NBV 与 EV 增长，财险看 COR；利润受投资收益与折现率假设影响极大，易波动。

## 3. 券商

**改用**：代理买卖证券款、客户资金余额、两融余额、自营投资规模、承销保荐收入、资管规模 AUM。
**关键指标**：净资产收益率、风险覆盖率、流动性覆盖率 LCR、净稳定资金率 NSFR、自营权益/固收占比。
**要点**：业绩与市场成交额、指数涨跌高度相关，需做β归因；信用减值（两融、股质）是主要风险源。

## 4. 房地产

**别用**：资产负债率（合同负债/预收被计为负债，会严重高估）、流动比率（存货含在建，周转极慢）。
**改用**：

| 指标 | 公式 / 口径 |
|---|---|
| 净负债率 | (有息负债 − 货币资金) / 净资产（剔除永续债影响需说明） |
| 剔除预收后的资产负债率 | (负债合计 − 合同负债) / (资产总计 − 合同负债) |
| 现金短债比 | 货币资金 / (短期借款 + 一年内到期非流动负债)，受限资金需剔除 |
| 权益口径销售额 / 并表回款率 | 拿地权益比、销售权益比 |
| 存货/总资产、去化率、已售未结 | 已售未结转金额是未来收入的先行指标 |

**要点**：三道红线口径要写明；结转毛利下行与减值计提是主要利润杀手；合作开发带来的少数股东权益占比需单列。

## 5. 医药 / 生物科技

| 类型 | 关键口径 |
|---|---|
| 创新药 | 研发费用（含资本化）、管线进度、License-out 首付款与里程碑确认方式、商业化放量曲线 |
| 仿制药/原料药 | 集采降价幅度、价格联动、产能利用率、原料药价格周期 |
| CXO | 在手订单/Backlog、产能利用率、新增订单增速、海外订单占比 |
| 医疗器械 | 集采/DRG 影响、装机量、耗材复购、出海占比、经销商模式下的收入确认 |
| 未盈利 Biotech | 现金储备/年化现金消耗（Cash Runway），比净利润重要得多 |

**要点**：政府补助与投资收益占比高；销售费用率异常高需查学术推广合规性；两票制下的收入确认口径。

## 6. SaaS / 软件

**别用**：单纯看净利润（高投入期必然亏损）、传统 PE。
**改用**：ARR/MRR、净收入留存率 NDR（>120% 为优秀）、客户流失率 Churn、CAC 回收期、LTV/CAC、毛利率（云业务 60%+ 为健康）、销售费用率与收入增速的剪刀差、Rule of 40（收入增速% + 利润率% ≥ 40）。
**要点**：订阅收入 vs 一次性实施收入要分开；递延收入/合同负债是先行指标；人均创收。

## 7. 重资产制造 / 周期

**改用**：单位产品毛利（价差）、产能利用率、在建工程转固节奏、吨/台折旧、EBITDA、吨市值或重置成本法、行业开工率与库存周期位置。
**要点**：周期顶部看现金流不看利润（利润高点往往是估值低点）；大额资本开支后的折旧压力要在投产当年就提示；固定资产减值测试。

## 8. 零售 / 消费

**改用**：同店销售增长 SSSG、坪效、门店净开店数、库存周转天数、会员复购率、单客价、渠道结构（线上占比）、经销商打款意愿（合同负债）、预收账款变化。
**要点**：合同负债/预收是渠道信心的先行指标；存货跌价与经销商压货是主要风险；促销力度看毛利率与销售费用率同步变化。

## 9. 新能源 / 高端制造（光伏、锂电、电动车链）

**改用**：出货量、单瓦/单Wh/单车盈利、单位成本下降曲线、产能利用率、在手订单、海外收入占比与关税影响、产业链一体化程度。
**要点**：价格战阶段看单位盈利而非收入增速；应收账款受下游账期拉长影响大；补贴退坡与碳关税。

## 10. 跨行业对比纪律

- 只在同一商业模式下横向比（代工 vs 品牌不可直接比毛利率）。
- 会计口径差异（总额法 vs 净额法、经销商买断 vs 代理）会让收入不可比，必须先对齐口径。
- 没有可比公司时，用**自身历史分位**代替行业对比，并说明「用历史分位替代行业基准」。
