# 指标公式与口径速查

> 用法：算指标前先查公式；口径有歧义时以本文件的「口径约定」为准，并在报告里注明采用哪种口径。

## 1. 盈利能力

| 指标 | 公式 | 备注 |
|---|---|---|
| 毛利率 | (营业收入 − 营业成本) / 营业收入 | 分母用营业收入，不是营业总收入中的其他业务收入 |
| 营业利润率 | 营业利润 / 营业收入 | 含投资收益、减值、公允价值变动 |
| 净利率 | 净利润 / 营业收入 | 分子含少数股东损益 |
| 归母净利率 | 归母净利润 / 营业收入 | **与净利率不同，别混用** |
| 扣非净利率 | 扣非净利润 / 营业收入 | 判断主业真实盈利的首选 |
| 销售/管理/研发/财务费用率 | 各费用 / 营业收入 | 研发资本化会低估研发费用率，需看附注 |
| EBIT | 利润总额 + 利息费用 | 利息费用取财务费用中的利息支出，非财务费用全额 |
| EBITDA | EBIT + 折旧 + 摊销 | 重资产行业常用，但**不能替代现金流** |

## 2. 回报与杜邦分解

| 指标 | 公式 | 口径 |
|---|---|---|
| ROE | 归母净利润 / 平均归母权益 | 平均 = (期初 + 期末)/2；无期初用期末并标注 |
| ROE（摊薄/期末） | 归母净利润 / 期末归母权益 | 与证监会口径（加权平均）会有差异 |
| ROA | 净利润 / 平均总资产 | 分子含少数股东损益，与总资产匹配 |
| ROIC | NOPAT / 投入资本 | NOPAT ≈ (净利润 + 利息×(1−税率))；投入资本 = 有息负债 + 归母权益 |
| 杜邦三因子 | ROE = 净利率 × 总资产周转率 × 权益乘数 | 净利率用归母净利率才能严格还原归母 ROE |
| 总资产周转率 | 营业收入 / 平均总资产 | 轻资产公司天然高，跨行业不可比 |
| 权益乘数 | 平均总资产 / 平均归母权益 | = 1/(1−资产负债率) 仅在无少数股东权益时成立 |

**杜邦归因**：ROE 变动 = 净利率效应 + 周转率效应 + 杠杆效应。报告里要说明「ROE 提升主要来自哪一根」，是提价、放量还是加杠杆——三者含金量完全不同。

## 3. 营运效率

| 指标 | 公式 | 备注 |
|---|---|---|
| 应收账款周转率 | 营业收入 / 平均应收账款 | 应收含应收账款+合同资产更贴近实际 |
| 应收周转天数 | 365 / 周转率 | 看账龄结构比看天数更重要 |
| 存货周转率 | 营业成本 / 平均存货 | 分子用**营业成本**不是营业收入 |
| 存货周转天数 | 365 / 周转率 | 房地产/白酒适用长周期，勿用通用阈值套 |
| 应付周转天数 | 营业成本 / 平均应付账款 | 延长应付是对上下游议价力的体现，也是流动性风险 |
| 现金转换周期 CCC | 应收天数 + 存货天数 − 应付天数 | 越短越好；为负说明占用上下游资金 |
| 固定资产周转率 | 营业收入 / 平均固定资产 | 判断产能利用率的粗 proxy |

## 4. 偿债与资本结构

| 指标 | 公式 | 备注 |
|---|---|---|
| 资产负债率 | 负债合计 / 资产总计 | 含合同负债，地产/预收模式会被高估 |
| 有息资产负债率 | (短借+一年内到期+长借+应付债券+租赁负债) / 总资产 | 剔除经营性负债，比资产负债率更能反映真实杠杆 |
| 净现金 | 货币资金 + 交易性金融资产 − 有息负债 | **受限资金必须剔除**（保证金、质押存单） |
| 流动比率 | 流动资产 / 流动负债 | <1 需预警，但零售/快消可低至 0.8 仍健康 |
| 速动比率 | (流动资产 − 存货) / 流动负债 | 保守口径再减预付款项 |
| 利息保障倍数 | EBIT / 利息费用 | <1.5 需关注，<1 说明经营利润不够付利息 |
| 商誉/归母权益 | 商誉 / 归母股东权益 | >30% 必须单列减值风险 |

## 5. 现金流质量

| 指标 | 公式 | 判读 |
|---|---|---|
| 现金流匹配度 | 经营活动现金流净额 / 净利润 | ≥1 健康；0.5–1 需解释；<0.5 红牌；连续多年 <0.8 高度警惕 |
| OCF/营业收入 | 经营活动现金流净额 / 营业收入 | 与净利率对比，看收现质量 |
| 自由现金流 FCF | OCF − 资本开支 | 资本开支取「购建固定资产、无形资产和其他长期资产支付的现金」 |
| 资本开支/OCF | 资本开支 / OCF | >100% 说明靠融资扩产；<50% 说明进入收获期 |
| 收现比 | 销售商品、提供劳务收到的现金 / 营业收入 | 含税口径，正常 >1.13（考虑 13% 增值税）；明显低于 1 需查票据与应收 |
| 付现比 | 购买商品、接受劳务支付的现金 / 营业成本 | 与收现比配合看议价能力 |
| 筹资依赖度 | (筹资净额 + OCF) 判断 | OCF 长期为负 + 筹资持续为正 = 靠输血活着 |

**现金流三型画像**（用于第 2 段现金流量表解读）：
- OCF +、ICF −、FCF −：成熟扩张型，最健康
- OCF −、ICF −、FCF +：靠融资扩张，看项目是否投产
- OCF −、ICF +、FCF ±：变卖资产求生，高危
- OCF +、ICF +、FCF −：收缩还债，看是否主动去杠杆

## 6. 口径约定（本技能统一标准）

| 项 | 约定 |
|---|---|
| ROE 分子 | 一律用**归母净利润**；用净利润需明确标注为「全口径 ROE」 |
| 周转类分母 | 一律用**平均余额**，有期初数据就必须用平均；无期初退回期末并标注 |
| 有息负债 | 短期借款 + 一年内到期的非流动负债 + 长期借款 + 应付债券 + 租赁负债 |
| 净现金 | 货币资金 + 交易性金融资产 − 有息负债；受限资金剔除 |
| 资本开支 | 仅「购建固定资产、无形资产和其他长期资产支付的现金」，不含并购 |
| 同比基数 | 追溯调整后优先用**重述后**的上期数；未重述需说明不可比 |
| 单季数据 | 季报为累计数时，单季 = 本期累计 − 上期累计，必须标注「测算单季」 |
| 天数基准 | 统一 365 天，不做闰年调整；半年报年化需注明 |

## 7. 常见误算陷阱

1. **归母 vs 净利润 vs 扣非**：三者混用是最高频错误。ROE 用归母，毛利率看主营，含金量看扣非。
2. **同比 vs 环比**：同比 = 与上年同期比；环比 = 与上一期比。季报做同比必须说明是否重述、是否单季。
3. **负数同比不可算百分比**：上期为负时，同比 % 无意义，改用「扭亏 / 亏损扩大 X 万元」表述。
4. **单位不一致**：万元与亿元混用会让比率错 10000 倍。抽取数据时先统一单位，并在表头标注。
5. **追溯调整**：同一控制下企业合并、会计政策变更会让上期数被重述，直接用当期披露的上期数，不要用旧报告里的数。
6. **并表范围变化**：新收购子公司当年并表会让同比虚增，需拆分内生增长与外延增长。
7. **汇率折算**：海外收入占比高的公司，要区分「固定汇率口径」与「报表口径」增速。
8. **一次性因素**：政府补助、资产处置收益、公允价值变动、汇兑损益要单列，不能直接算进趋势。
9. **季节性**：Q1、Q4 往往不可比（春节、年终结算、计提集中），需提示。
10. **税率的坑**：有效税率 = 所得税费用 / 利润总额，与名义税率差异大时要查递延所得税与亏损弥补。
11. **少数股东损益占比**：占比骤升说明利润被少数股东分走，或亏损集中在并表子公司。
12. **经营性 vs 金融性负债**：合同负债、应付账款是经营性负债，不计入有息负债，别把地产的负债率直接横向比制造业。
